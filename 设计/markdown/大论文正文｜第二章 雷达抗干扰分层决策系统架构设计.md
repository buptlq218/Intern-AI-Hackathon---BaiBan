## 2.1 FMCW 雷达基础

### 2.1.1 FMCW 雷达信号模型与解调

FMCW 雷达是指发射频率受特定信号调制的连续波雷达，其连续发射调频信号并接收目标反射的回波，通过对回波解调解算目标的距离与速度信息。FMCW 雷达系统如图 2-1 所示，雷达由波形发生器生成基带调制波形，经数模转换器（Digital-to-Analog Converter，DAC）与压控振荡器（Voltage-Controlled Oscillator，VCO）生成射频 FMCW 波形，该波形一路作为参考信号送至混频器，另一路经功率放大器（Power Amplifier，PA）放大后由发射天线发射。发射的电磁波遇到目标后被反射形成目标回波，由接收天线接收，经低噪声放大器（Low-Noise Amplifier，LNA）放大后与参考信号混频以完成解调（Dechirp），再通过低通滤波器（Low-Pass Filter，LPF）滤除有效探测范围之外的频率成分，得到拍频信号（Beat Signal）。拍频信号经模数转换器（Analog-to-Digital Converter，ADC）采样后进入数字信号处理流程，通过快速傅里叶变换（Fast Fourier Transform，FFT）与恒虚警率（Constant False Alarm Rate，CFAR）检测解算目标的距离与速度。
> 【图 2-1 FMCW 雷达系统框图】
图源：需新绘（发射器：波形发生器—DAC—VCO—PA—发射天线；接收器：接收天线—LNA—混频器—LPF—ADC—数字信号处理；VCO 输出同时作为参考信号引入混频器）   

FMCW 信号的频率随时间按预设规律变化，常见的调制波形有三角波、锯齿波与正弦波。本文采用锯齿波调制，如图 2-2 所示，其在一次扫频周期内频率由起始频率线性变化至终止频率，这样的一次扫频称为一个 chirp。相邻两个 chirp 之间通常留有一段空闲时间，一个 chirp 的扫频时长 T\_sw 与该空闲时长 T\_icd 之和称为 chirp 重复周期 T\_c，亦称脉冲重复间隔（Pulse Repetition Interval，PRI）。
> 【图 2-2 锯齿波调频的频率—时间示意图】
图源：提纲 2.1.1.2 相关示意（需补画 PRI、T\_sw、发射信号与接收信号的时频关系）   

不考虑幅度（此处及后续推导均默认信号为单位幅度）时，单个 chirp 内的参考信号可表示为

x\_T(t) = exp\{ j2π\[ f\_c·t \+ ½·K·(t − T\_sw/2)² \] \}, 0 ≤ t ≤ T\_sw (2-1)

其中 f\_c、K 与 T\_sw 分别表示中心频率、调频斜率与单个 chirp 的扫频时长，j 为虚数单位。则信号带宽为

B = K·T\_sw (2-2)

当最大探测距离 d\_max 确定后，目标回波相对参考信号的最大延迟时间为

τ\_max = 2·d\_max / c (2-3)

其中 c 为光速。Dechirp 处理之后所对应的最大拍频（Beat Frequency）为

f\_bmax = K·τ\_max (2-4)

本文仿真在 Dechirp 后采用截止频率为 f\_bmax 的理想低通模型。与参考信号频率差超过该阈值的分量在仿真中被置零；这一截断关系是本文时、频域参数调整机制的直接建模依据，但不是实际雷达抗干扰的唯一物理机制。实际系统还会受到滤波器过渡带、射频前端非线性、相位噪声与多径等因素影响。

设某点目标直接反射的回波信号为

x\_R(t) = exp\{ j2π\[ f\_c·(t − τ) \+ ½·K·(t − τ − T\_sw/2)² \] \}, τ ≤ t ≤ τ \+ T\_sw (2-5)

其中 τ 为该回波相对参考信号的延迟时间。若该目标与雷达的距离为 d，则由运动学关系可得

τ = 2d / c (2-6)

目标回波与参考信号做 Dechirp 后的信号为

x\_s(t) = x\_T(t)·conj\[x\_R(t)\] = exp\{ j2π\[ f\_c·τ \+ K·τ·(t − τ/2 − T\_sw/2) \] \}, τ ≤ t ≤ T\_sw (2-7)

其中 conj\[·\] 表示复共轭。该信号的频率，也即参考信号与目标回波的频率差为

Δf = d\[phase of x\_s(t)\] / dt = K·τ (2-8)

联立式(2-6)与式(2-8)，即可建立目标距离与拍频之间的关系

d = c·Δf / (2K) (2-9)

当 τ \< τ\_max，即 K·τ \< f\_bmax 时，该频率成分经低通滤波器后被保留至拍频信号中，故原理上可依据式(2-9)从拍频信号中解算目标距离。对于运动目标，其相对雷达的径向运动会引起多普勒频移，理论上可根据多普勒频率 f\_D 推算目标的相对径向速率

v = f\_D·c / (2·f\_c) (2-10)

然而实际中单个 chirp 的持续时间很短，多普勒频率在单个 chirp 的拍频信号中难以体现，需要多个 chirp 累积。如图 2-3 所示，FMCW 雷达通常连续发射 L 个 chirp 构成一帧（Frame），相邻两帧之间存在帧间间隔（Inter Frame Time），自当前帧起始时刻至下一帧起始时刻的时间称为帧周期（Frame Period）。雷达测量目标的距离与速度通常以一帧为操作单位。本文不额外设置帧间间隔，故帧周期为

T\_frame = L·T\_c = 128 × 60 μs = 7.68 ms (2-11)
> 【图 2-3 典型的帧结构示意图】
图源：需新绘（标注单帧内 L 个 chirp、帧间间隔与帧周期）   

设一帧内包含 L 个 chirp，则参考信号与接收信号可分别表示为各 chirp 信号之和

x\_T(t; L) = Σ\_\{l=1..L\} x\_T(t; l) (2-12)

x\_R(t; L) = Σ\_\{l=1..L\} x\_R(t; l) (2-13)

经 Dechirp 与低通滤波后的拍频信号为

x\_b(t; L) = Σ\_\{l=1..L\} \{ x\_T(t; l)·conj\[x\_R(t; l)\] \} ∗ h\_lp(t) (2-14)

其中 ∗ 表示卷积，h\_lp(t) 表示低通滤波器的冲激响应。此处称 t 这一维为快时间维，l 这一维为慢时间维。由快时间维的 FFT 结果可解算目标距离；而目标在快时间维对应峰值处的相位在慢时间维上的角频率 ω 则对应目标的相对径向速率

ω = 4π·v·T\_c·f\_c / c ⟹ v = ω·c / (4π·T\_c·f\_c) (2-15)

对拍频信号在快时间维与慢时间维各做一次 FFT，即得到距离多普勒图（Range-Doppler Map，RDM）。RDM 上的峰值位置对应可能的目标，再对 RDM 施加 CFAR 检测即可给出目标的距离与速率估计。

将表 2-3（见第 2.4.1 节）所列参数代入上述关系，可得本文雷达配置下的若干关键指标：每个 chirp 的 ADC 采样点数 N = f\_s·T\_sw = 1000；距离分辨力 ΔR = c/(2B) = 0.3 m，与最大探测距离 120 m 相对应的距离单元数为 400；由采样率决定的最大无模糊拍频为 f\_s/2 = 10 MHz，大于 f\_bmax = 8 MHz，满足奈奎斯特采样要求；速度分辨力 Δv = λ/(2·L·T\_c) ≈ 0.25 m/s，最大无模糊速度 v\_max = λ/(4·T\_c) ≈ 16.3 m/s，其中波长 λ = c/f\_c ≈ 3.91 mm。上列 v\_max ≈ 16.3 m/s 与后文 2.4.1 节中目标相对速度的取值范围 U(−16, 16) m/s 相匹配，仿真中所有目标的径向速度均落在雷达的无模糊测速范围之内，速度维观测因而有效。

本文以一帧作为决策单位：在一个时间步内固定中心频率与发射时延，接收完整一帧后由该帧 RDM 估计 SINR，并为下一帧选参。该设定能保留帧内各 chirp 的一致参数与慢时间处理条件，不会在帧内引入参数切换；但不能据此证明跨帧相干积累、检测概率、多普勒估计或工程波形连续性完全不受影响。“不牺牲目标检测性能”需用检测概率、虚警率和速度估计误差等指标另行验证。本文的 SINR 定义为

SINR = 10·log10( ‖x\_t‖² / ‖x\_i \+ n‖² ) (2-16)

其中 x\_t、x\_i 与 n 分别表示接收信号在经过 Dechirp 与低通滤波之后所残留的目标回波、干扰与噪声成分。本文假设接收信号的 SINR 可以被准确估计，其估计方法不在本文讨论范畴。

### 2.1.2 运动场景下的目标回波与干扰信号推导

实际中雷达的接收信号除了目标直接反射的回波，还包含多径反射回波、杂波以及其他汽车雷达的发射信号（即干扰）。汽车雷达间相互干扰的成因主要有两种：一种是**直接入射干扰**，即干扰雷达的发射信号直接射入受扰雷达的接收机；另一种是**反射干扰**，即干扰雷达的发射信号经其他物体反射后射入受扰雷达的接收机。本文在场景设定中专注于点目标的回波与直接入射干扰，不考虑反射干扰、多径效应与杂波。本节推导后续用于运动场景信号仿真的目标回波与干扰信号的解析形式。

#### 2.1.2.1 运动目标的回波信号推导

以一帧为单位，设单帧含 L 个 chirp，chirp 重复周期 T\_c = T\_sw \+ T\_icd，一帧的时间 t ∈ \[0, L·T\_c\]。设目标与雷达的初始距离为 R₀，目标相对雷达的径向速率为 v\_re = v\_target − v\_radar。此处假定在一帧时间内目标匀速运动，且目标相对雷达的距离与速率均在雷达的有效测量范围之内。则雷达与目标的距离为

R(t) = R₀ \+ v\_re·t (2-17)

接下来计算目标回波到达雷达接收机相对其对应发射信号的延迟时间 τ。以雷达为参考系，则目标的速率即为 v\_re。设雷达发射电磁波时与目标的距离为 R₁，电磁波自雷达发射至抵达目标用时 Δt₁；电磁波到达目标时目标与雷达的距离为 R₂，电磁波由目标反射后返回雷达用时 Δt₂。依据光速不变原理有

τ = Δt₁ \+ Δt₂， c·Δt₁ = R₂， c·Δt₂ = R₂， R₂ = R₁ \+ v\_re·Δt₁

联立可得

Δt₁ = Δt₂ = R₁ / (c − v\_re)， τ = 2·(R₁ \+ v\_re·Δt₁) / c = 2·R₁ / (c − v\_re) (2-18)

设目标回波在 t 时刻到达雷达，则发射该回波所对应信号的时刻为 t − τ(t)，故有 R₁ = R(t − τ(t)) = R₀ \+ v\_re·\[t − τ(t)\]。将其代入式(2-18)并整理，得

τ(t)·(c − v\_re) = 2·\[R₀ \+ v\_re·t − v\_re·τ(t)\]

⟹ τ(t) = 2·(R₀ \+ v\_re·t) / (c \+ v\_re) (2-19)

⟹ R₁ = (R₀ \+ v\_re·t)·(c − v\_re) / (c \+ v\_re) (2-20)

式(2-19)即为运动目标的回波相对参考信号的时变延迟。对延迟求导可得

τ′(t) = dτ(t)/dt = 2·v\_re / (c \+ v\_re)， 1 − τ′(t) = (c − v\_re) / (c \+ v\_re) (2-21)

对于第 k 个 chirp（1 ≤ k ≤ L），时间 t ∈ \[(k−1)T\_c, k·T\_c\]，记该 chirp 的起始时刻 t₀ = (k−1)·T\_c，则参考信号的频率为

f\_ref(t) = f\_c \+ K·\[t − t₀ − T\_sw/2\]， t₀ ≤ t ≤ t₀ \+ T\_sw； f\_ref(t) = 0，其他 (2-22)

实际中在 chirp 间空闲时间内，雷达参考信号的频率将回落至 (f\_c − ½·K·T\_sw)，由于雷达系统对该段时间的接收信号不作 ADC 采样，故此处作上述简化。现代 FMCW 雷达可以精确控制每个 chirp 的起始相位，在不考虑相位编码的情况下，本文认为每个 chirp 的起始相位保持一致，用固定值 φ₀ 表示。于是对于 t₀ ≤ t ≤ t₀ \+ T\_sw，参考信号的相位为

φ\_ref(t) = 2π·\[ (f\_c − ½·K·T\_sw)·(t − t₀) \+ ½·K·(t − t₀)² \] \+ φ₀ (2-23)

回波信号的相位由参考信号相位在时变延迟处取值并叠加反射相移得到

φ\_echo(t) = φ\_ref(t − τ(t)) \+ φ\_r
 = 2π·\[ (f\_c − ½·K·T\_sw)·(t − τ(t) − t₀) \+ ½·K·(t − τ(t) − t₀)² \] \+ φ₀ \+ φ\_r (2-24)

其中 φ\_r 为目标反射引起的相位改变。对相位求导并代入式(2-21)，得回波信号的频率

f\_echo(t) = \[1 − τ′(t)\]·\{ (f\_c − ½·K·T\_sw) \+ K·\[t − τ(t) − t₀\] \}
 = \[(c − v\_re)/(c \+ v\_re)\]·\{ (f\_c − ½·K·T\_sw) \+ K·\[t − τ(t) − t₀\] \} (2-25)

至此已得到运动场景下一帧内每个 chirp 的参考信号频率、目标回波相位与频率的解析形式。信号仿真时可直接依据解析式生成信号，并在 Dechirp 后的低通滤波环节直接依据 f\_ref(t) 与 f\_echo(t) 的差值作频率截断，以此实现理想低通滤波。若考虑直接生成拍频信号，则其相位为

φ\_beat(t) = φ\_ref(t) − φ\_echo(t)
 = 2π·\[ (f\_c − ½·K·T\_sw)·τ(t) \+ ½·K·τ(t)·(2t − τ(t) − 2t₀) \] (2-26)

对应的拍频为

f\_beat(t) = (1/2π)·dφ\_beat(t)/dt
 = \[2·v\_re/(c \+ v\_re)\]·\{ (f\_c − ½·K·T\_sw) \+ K·\[t − τ(t) − t₀\] \} \+ K·τ(t) (2-27)

仿真时将拍频超过低通滤波器截止频率 f\_bmax 的部分直接置零即可。式(2-27)右端两项的物理含义是清楚的：第二项 K·τ(t) 即式(2-8)所给出的距离对应拍频，第一项则是目标径向运动引起的多普勒贡献，二者共同确定 RDM 上目标峰值的位置。

#### 2.1.2.2 运动干扰源的干扰信号推导

由于干扰在时域上的扫频参数（如 PRI、chirp 间间隔等）与受扰雷达的参考信号并不一定一致（相干干扰一致，非相干干扰则差异较大），此处不以干扰信号的帧长作为仿真样本长度。若受扰雷达的一帧长度可以容纳的干扰 chirp 数为 (M − 1)，则将干扰信号的仿真样本补长为 M 个 chirp 的长度；仿真中先生成完整的 M 个 chirp 的信号，之后再依据延迟时间进行截断。

设干扰的中心频率为 f\_c^intf、调频斜率为 K\_intf、扫频时长为 T\_sw^intf、chirp 重复周期为 T\_c^intf。设干扰信号被受扰雷达接收到的起始时刻，相对于受扰雷达参考信号最近一个 chirp 起始时刻的延迟时间为 t\_d^intf(0)。该初始延迟时间实际由干扰源的相对距离与两部雷达的发射时间差共同决定：以受扰雷达为参考系，设干扰发射的起始时刻两部雷达的发射时间差为 τ\_transmit、干扰源的相对距离为 R^intf(0)，则

t\_d^intf(0) ≈ τ\_transmit \+ R^intf(0) / c (2-28)

本文对 t = 0 时刻之前发生的运动过程不作考察，故此处忽略雷达与干扰源在此之前的运动。仿真中该初始延迟将自给定范围内的均匀分布中采样得到。对于 t \> 0，设干扰源相对速度为 v\_re^intf = v\_intf − v\_radar，则

t\_d^intf(t) = τ\_transmit \+ R^intf(t)/c， R^intf(t) = R^intf(0) \+ v\_re^intf·t

整理得

t\_d^intf(t) = t\_d^intf(0) \+ v\_re^intf·t / c = t\_d^intf(0) \+ t\_doppler^intf(t) (2-29)

其中 t\_doppler^intf(t) = v\_re^intf·t/c 表示干扰源相对受扰雷达的运动所导致的附加时移。与式(2-19)相比，此处分母为 c 而非 (c \+ v\_re^intf)，因为干扰信号只经单程传播而非往返传播。仿真时，先将干扰仿真的时间序列补长至 M 个 chirp，然后计算 t\_doppler^intf(t)，再逐 chirp 地生成干扰在时频域与时域上的序列，最后按 t\_d^intf(0) 作整体平移。

以下给出时移前干扰样本的解析式，之后整体时移 t\_d^intf(0) 即可。对于干扰样本的第 k 个 chirp（1 ≤ k ≤ M），时间 t ∈ \[(k−1)·T\_c^intf, k·T\_c^intf\]，所发射的干扰信号频率为

f\_intf,tx(t) = f\_c^intf \+ K\_intf·\[ t − (k−1)·T\_c^intf − ½·T\_sw^intf \]，
 (k−1)·T\_c^intf ≤ t ≤ (k−1)·T\_c^intf \+ T\_sw^intf； 否则为 0 (2-30)

每一段扫频的起始相位以固定值 φ₁ 表示，则所发射的干扰信号相位为

φ\_intf,tx(t) = 2π·\[ (f\_c^intf − ½·K\_intf·T\_sw^intf)·(t − (k−1)·T\_c^intf) \+ ½·K\_intf·(t − (k−1)·T\_c^intf)² \] \+ φ₁ (2-31)

被受扰雷达接收到的干扰信号相位为发射相位在附加时移处的取值

φ\_intf,rx(t) = φ\_intf,tx( t − t\_doppler^intf(t) ) (2-32)

对相位求导，得接收到的干扰信号频率

f\_intf,rx(t) = \[1 − (t\_doppler^intf)′(t)\]·\{ (f\_c^intf − ½·K\_intf·T\_sw^intf) \+ K\_intf·\[ t − t\_doppler^intf(t) − (k−1)·T\_c^intf \] \} (2-33)

其中

1 − (t\_doppler^intf)′(t) = 1 − v\_re^intf / c (2-34)

至此，干扰信号仿真所需的频率与相位解析式亦已得到。式(2-22)～(2-27)与式(2-30)～(2-34)共同构成了 2.4.1 节仿真平台的信号级模型基础。

### 2.1.3 相干干扰的成因与危害

依据干扰雷达与受扰雷达发射信号波形参数的相似程度，FMCW 雷达间的相互干扰可分为相干干扰与非相干干扰。当两者的波形参数相同或非常接近时，雷达间的干扰为**相干干扰**；当两者波形参数差异较大时，则为**非相干干扰**。本文聚焦于相干干扰，即干扰源与受扰雷达具有相同的调频斜率 K 与脉冲重复周期 T\_c。

如图 2-4(a) 所示，在时频域上，相干干扰的频率—时间曲线与受扰雷达的参考信号及目标回波完全平行。当干扰的中心频率与受扰雷达参考信号相近，且二者的相对延迟时间很小时，干扰将全部进入受扰雷达的通带，形成窄带干扰。由式(2-33)可见，在 K\_intf = K 的条件下干扰的瞬时频率与参考信号保持恒定的频率差，Dechirp 之后该恒定频率差表现为一个单频分量，其在快时间维 FFT 之后聚集为一个尖锐的峰值，与真实目标回波在处理域上的样式完全一致。

更严重的是能量上的不对等。目标回波经历自雷达至目标再返回雷达的往返传播，其接收功率按雷达方程与距离的四次方成反比；而干扰信号自干扰雷达发射后仅经单程传播直接射入受扰雷达接收机，其接收功率与距离的平方成反比。因此在相当的距离上，干扰的接收功率通常远高于目标回波。二者叠加的后果是相干干扰极易在 RDM 及 CFAR 检测中形成强度很大的虚假目标，如图 2-5 所示；当干扰在距离维上与真实目标邻近时，其旁瓣亦可能掩盖真实目标而造成漏检。虚假目标会使后续的跟踪与决策模块对不存在的障碍物作出响应，在自动驾驶场景中可能触发不必要的紧急制动，构成直接的安全隐患。

高相干干扰可能在时域、频域、时频域或距离多普勒域中与目标回波高度相似，使仅依赖处理域样式差异的接收端分离方法面临困难。但这不等于接收端重建、联合估计、多通道或学习型方法在原理上全部无效。本文选择在发射中心频率与发射时延层面主动规避，是本文的研究范围与技术路线，而不是由上述现象推出的唯一方案。

### 2.1.4 时域与频域干扰避免机制

基于 2.1.1 节所给出的低通滤波器截止特性，本节说明两条使干扰无法进入拍频信号的机制。

**频域机制（调整中心频率）。** 如图 2-4(c) 所示，调整受扰雷达的中心频率 f\_c 可以增大干扰信号与参考信号之间的频率差，当该频率差大于低通滤波器截止频率 f\_bmax 时，干扰在时频域上落在受扰雷达通带之外，从而被滤除。该方法亦称频谱分配或频分复用，通常将一段共享频带划分为若干互不重叠的子带，每部雷达在每个时间单元内选取一个子带作为工作频带。该方法实现直接，但缺点亦显然：可用频谱资源有限，当同一区域内雷达数量较多时，为保证互不干扰需划分更多子带，而子带带宽的减小又会依据 ΔR = c/(2B) 削弱雷达的距离分辨力。

**时域机制（调整发射时延）。** 依据式(2-3)与式(2-4)所给出的 τ\_max 与 f\_bmax 的对应关系，若干扰接收信号与参考信号之间的相对延迟时间不落在 \[0, τ\_max\] 范围内，则该干扰与参考信号的频率差亦将大于 f\_bmax，Dechirp 后同样被低通滤波器滤除。如图 2-4(b) 所示，受扰雷达将发射信号延迟 t\_d 发出，即改变了发射信号与干扰之间的相对延迟，从而使干扰在 Dechirp 后被滤除。该方法亦称时分复用。为便于表述，本文设置一个参考时刻，雷达的发射时延 t\_d 与干扰的到达延迟 τ\_intf 均相对该参考时刻给出。

**联合机制。** 将中心频率与发射时延的调整结合，可缓解单一频域策略下频谱资源受限的问题：在频谱子带数量不变的前提下，时域维度提供了额外的自由度，使可用的“避干扰配置”数量由 n 增至 m·n。然而现有的联合时、频域方法多为合作式实现，需要额外的通信与计算资源来完成资源分配，这既降低了抗干扰的实时性，也可能引入通信系统与雷达系统之间的干扰。因此，本文提出**非合作式**的时、频域联合干扰避免策略：在每一帧发射之前，受扰雷达仅基于自身的状态——包括相对参考时刻的发射时延、当前中心频率以及从自身接收信号中感知到的干扰情况——决定下一帧的时域与频域参数，不与其他车辆交换任何信息。

据此，本文定义联合动作空间为

A = \{ (f\_c^(i), t\_d^(j)) \| i ∈ \{0,1,2\}, j ∈ \{0,1,2\} \} (2-35)

其中三个可选中心频点为 f\_c ∈ \{76.25, 76.75, 77.25\} GHz，相邻频点间隔 500 MHz 恰等于雷达带宽 B，故三个工作子带互不重叠；三个可选发射时延为 t\_d ∈ \{0, τ\_max, 2τ\_max\} = \{0, 0.8, 1.6\} μs。联合动作空间的规模为 3 × 3 = 9。

## 2.2 抗干扰策略的马尔可夫决策过程建模

### 2.2.1 马尔可夫决策过程

马尔可夫决策过程（Markov Decision Process，MDP）为“以交互式学习实现目标”这一类问题提供了形式化的描述框架。在该框架中，学习者与决策者被统称为智能体（Agent），智能体以外所有与之交互的事物被称为环境（Environment）。如图 2-7 所示，二者持续交互：智能体选择动作，环境对动作作出响应并向智能体呈现新的状态，同时给出一个数值化的收益（亦称奖励）；智能体选择动作的目标即为最大化累积收益。
> 【图 2-7 智能体—环境交互示意图】
图源：需新绘（智能体与环境两个方框，状态 s\_t、奖励 r\_t 自环境指向智能体，动作 a\_t 自智能体指向环境）   

一般地，一个马尔可夫决策过程可用五元组 ⟨S, A, p, r, γ⟩ 描述：S 表示状态空间（State Space），A 表示动作空间（Action Space），p 表示状态转移概率函数（Transition Probability Function），r 表示奖励函数（Reward Function），γ 表示未来回报的折扣率（Discount Rate）。

对于一系列离散时刻 t = 0, 1, 2, …，在每个时间步 t 上智能体通过观测更新环境状态的某种表征 s\_t ∈ S，并基于该状态选择一个动作 a\_t ∈ A(s\_t)（A(s) 表示状态 s 下可用的动作集合；当所有状态的可用动作集合相同时可简记为 A）。在下一个时间步，作为该动作的结果，智能体收到数值奖励 r\_\{t\+1\} ∈ ℝ，同时观测到新的状态 s\_\{t\+1\}。如此持续交互，得到一条轨迹（Trajectory）

s₀, a₀, r₁, s₁, a₁, r₂, s₂, a₂, r₃, s₃, … (2-36)

其中任意一组 (s\_t, a\_t, r\_\{t\+1\}, s\_\{t\+1\}) 称为一次转移（Transition）。奖励 r\_\{t\+1\} 与后继状态 s\_\{t\+1\} 均可视为随机变量，它们服从的概率分布只依赖于前继状态 s\_t 与动作 a\_t，即对任意 s, s′ ∈ S，a ∈ A(s)，r ∈ ℝ 有

p(s′, r \| s, a) = Pr\{ s\_\{t\+1\} = s′, r\_\{t\+1\} = r \| s\_t = s, a\_t = a \}
 = Pr\{ s\_\{t\+1\} = s′, r\_\{t\+1\} = r \| s\_t = s, a\_t = a, s\_\{t−1\}, a\_\{t−1\}, …, s₀, a₀ \} (2-37)

上式既是状态转移概率函数 p 的定义，也给出了 MDP 的马尔可夫性：后继状态与奖励的分布只由当前状态与动作决定，与更早的历史无关。p 由此完全刻画了环境的动态特性。将 p 对奖励求和可得三参数形式

p(s′ \| s, a) = Pr\{ s\_\{t\+1\} = s′ \| s\_t = s, a\_t = a \} = Σ\_r p(s′, r \| s, a) (2-38)

奖励函数的“状态—动作—后继状态”三参数表示为

r(s, a, s′) = E\[ r\_\{t\+1\} \| s\_t = s, a\_t = a, s\_\{t\+1\} = s′ \] = Σ\_r r·p(s′, r \| s, a) / p(s′ \| s, a) (2-39)

当 s、a、r 的取值不可数时，将上述求和替换为相应的定积分即可。

对于式(2-36)所描述的轨迹，给定终止时刻 t\_∞，自时刻 t 之后所获得的累积回报可表示为奖励之和

G\_t = r\_\{t\+1\} \+ r\_\{t\+2\} \+ … \+ r\_\{t\_∞\} (2-40)

对于具有自然终止状态的任务（如一盘对弈或一次走迷宫），终止时刻显而易见，所得轨迹称为一幕（Episode），此类任务称为分幕式任务，其 t\_∞ 有限。然而有些任务不能自然地划分为独立的幕，而是持续不断地进行，称为持续式任务；此时 t\_∞ → ∞，G\_t 可能趋于无穷。为此引入折扣率 γ ∈ \[0, 1\] 对未来回报作折扣

G\_t = Σ\_\{k=0..t\_∞−t−1\} γ^k·r\_\{t\+k\+1\} = r\_\{t\+1\} \+ γ·G\_\{t\+1\} (2-41)

设 \|r\_t\| 的上界为 r\_sup，则

\|G\_t\| ≤ Σ\_\{k=0..∞\} γ^k·r\_sup = r\_sup / (1 − γ) (2-42)

故对 t\_∞ → ∞ 的情况，只需取 γ \< 1 即可保证折扣后的累积回报有界。γ 的大小表示未来收益对当前动作的重要程度：γ 越大则越重视长期收益；当 γ = 0 时智能体只考虑当前动作的即时奖励。

智能体自状态到动作（或到各动作选择概率）的映射称为策略（Policy），记为 π。对确定性策略，策略直接给出当前状态下所选的动作

a\_t = π(s\_t) (2-43)

对随机策略，则给出该状态下动作的概率分布

π(a \| s) = p(a\_t = a \| s\_t = s) (2-44)

并自该分布中采样具体动作。将智能体在执行策略 π 时于状态 s 下采取动作 a 的价值记为 q\_π(s, a)，称为状态—动作价值函数，它表示依据策略 π 自状态 s 出发、执行动作 a 之后所有可能轨迹的期望回报

q\_π(s, a) = E\_π\[ G\_t \| s\_t = s, a\_t = a \]
 = Σ\_\{s′∈S\} p(s′ \| s, a)·\{ r(s, a, s′) \+ γ·E\_π\[ G\_\{t\+1\} \| s\_\{t\+1\} = s′ \] \} (2-45)

为最大化累积回报需要找到最优策略。最优策略可能不唯一，但它们共享同一个最优状态—动作价值函数

q\_\*(s, a) = max\_π q\_π(s, a) (2-46)

从而将“最大化累积回报”转化为“求解最优状态—动作价值函数”这一等价问题。

### 2.2.2 干扰避免的马尔可夫决策过程建模

本节将 2.1.4 节所提出的非合作式时、频域联合干扰避免策略的执行过程建模为 MDP。依据 2.1.1 节的说明，MDP 的一个时间步对应雷达的一帧，时长 7.68 ms，即在每个时间步内雷达以当前参数发射并接收一帧信号、由该帧 RDM 估计 SINR，并据此决定下一帧所使用的参数。

记雷达的可调参数组合为参数状态 s\_param = \[f\_c, t\_d\]，所有参数状态的集合记为 S\_param。动作定义为参数状态之间的切换，即 a: s\_param → s′\_param，s\_param, s′\_param ∈ S\_param。本章中频域状态与时域状态均离散化，若给定 n 个可用频域状态与 m 个可用时域状态，则 \|S\_param\| = m·n；由于动作直接以“切换至哪一个参数状态”来定义（而非以“相对当前状态如何变化”来定义），故动作空间大小亦为 \|A\| = m·n = 9，而不是 (m·n)²。动作索引 a ∈ \{0, 1, …, 8\} 与参数状态的映射关系为

f\_c 的索引 = ⌊a / 3⌋， t\_d 的索引 = a mod 3 (2-47)

为便于神经网络学习，参数状态以独热（one-hot）编码表示，各参数状态的编号与编码列于表 2-1。采用独热编码而非直接使用标量索引的原因在于：频点与时延的索引之间不存在有意义的序关系与距离关系，若以标量输入会向网络引入虚假的数值序结构。

表 2-1 雷达参数状态编码

| 索引 a | 参数状态 (f\_c \[GHz\], t\_d \[μs\]) | one-hot 编码 |

时间步 t 的基础状态定义为

s\_t = \[ onehot(a(t−1)), SINR(t) \] ∈ ℝ¹⁰ (2-48)

其中 onehot(a(t−1)) 为上一帧动作的 9 维独热编码，SINR(t) 为当前帧由 RDM 估计得到的标量，两者合计 10 维。该定义与第 3.2.3.3 节的网络输入及专利说明书所列动作通道、SINR 通道保持一致，不再把上一帧奖励 r(t−1) 重复作为输入；奖励已经由动作与当前 SINR 确定，额外输入会造成状态定义与实现维度不一致。

即时奖励由信号质量奖励 r\_S 与动作切换代价奖励 r\_AC 两部分构成

r\_t = r\_S \+ r\_AC (2-49)

其中 r\_S 依据当前 SINR 计算，用于激励智能体避开干扰；r\_AC 依据本帧相对上一帧的参数切换次数计算，用于抑制不必要的参数抖动。定义动作代价（Action Cost，AC）为

AC = 频域切换次数 \+ 时域切换次数 ∈ \{0, 1, 2\} (2-50)

即 AC = 0 表示 f\_c 与 t\_d 均未改变，AC = 1 表示二者之一改变，AC = 2 表示二者均改变。实际中动作代价亦可依据实现该切换的复杂度或硬件负担来设定。两部分奖励的具体分段形式与权重设置涉及执行层的训练效率设计，将在第 3.3.1 节详细给出，此处不再展开。

本文场景中每一幕开始时对目标与干扰作随机初始化，且干扰源在幕内持续相对运动，因此显式的状态转移概率函数 p 难以获得。所幸后文所采用的时序差分类强化学习算法属于无模型（Model-Free）方法，无需显式的状态转移概率，故本文在 MDP 建模中不再讨论 p，相关论证见第 3.2.2 节。折扣率取 γ = 0.95，其取值依据将在第 3.2.4 节说明。

### 2.2.3 部分可观测性与时序扩展状态

为不增加额外的硬件要求，雷达在每个时间步只能感知当前通带之内的干扰情况，即只能获得一个标量 SINR，而无法直接观测到干扰源在频域与时域上的完整分布。这使得式(2-48)所定义的基础状态并不满足马尔可夫性：同一个基础状态可能对应完全不同的真实干扰分布，其最优动作也就不同。因此，本文的抗干扰问题实质上是一个部分可观测马尔可夫决策过程（Partially Observable Markov Decision Process，POMDP）。

处理部分可观测性的一般思路是以历史观测序列近似真实状态。为此，本文将基础状态在时间上扩展，将最近 k 步的基础状态级联为时序扩展状态

h\_t = GRU(s\_t, h\_\{t−1\}) (2-51)

本文采用“单步观测 \+ 循环隐状态”的实现路径：每帧输入式(2-48)的 10 维观测，历史信息由隐状态 h\_t 在幕内递推承载，并在每幕开始时重置。因此，原稿中固定 k = 20、再把最近 k 步状态显式级联为 ℝ^\{k×3\} 的表述与网络实现不一致，现予删除；记忆范围由训练时的序列长度、隐状态初始化与截断反向传播设置共同决定，不能仅用 k = 20 概括。

循环网络与经验回放结合时必须保持时序对应关系：训练批次应由连续序列组成，并在序列起点重置或正确恢复隐状态；若从经验池随机抽取彼此独立的单步转移，却继续沿用 stateful 隐状态，则 h\_t 与样本历史不匹配，训练结论不成立。当前正文缺少这部分实现证据，需以代码确认回放单元、序列长度、burn-in、隐状态重置方式及目标网络输入。完成核对前，第三章关于 GRU 时序收益的因果解释应视为待确认。

## 2.3 基于分层强化学习的抗干扰决策系统架构设计

### 2.3.1 分层强化学习理论基础

标准强化学习将决策视为在单一时间粒度上的平坦（Flat）序贯过程：智能体在每个时间步观测状态、选择原子动作、接收奖励。当任务的时间跨度较长、奖励较为稀疏，或环境中同时存在多个时间尺度上的规律时，平坦结构会暴露出三个困难。首先是探索效率低下，智能体需要在原子动作空间中通过随机试探才能偶然发现有价值的长序列行为。其次是信用分配困难，一个决策的后果可能在许多步之后才显现，时序差分的自举传播需要大量样本才能把回报正确地归因到当初的决策上。最后是知识难以复用，在一种情形下学到的行为片段无法作为整体迁移到另一情形。

分层强化学习（Hierarchical Reinforcement Learning，HRL）通过引入**时间抽象**（Temporal Abstraction）来缓解上述困难：将决策过程分解为若干层，高层以较粗的时间粒度选择“做哪一类事”，低层以原子时间粒度选择“具体怎么做”。这样，高层的一次决策对应低层的多步动作，高层所面对的等效决策序列被显著缩短，其探索与信用分配的难度随之下降。

HRL 最具代表性的形式化是选项（Option）框架。一个选项定义为三元组

ω = ⟨ I\_ω, π\_ω, β\_ω ⟩ (2-52)

其中 I\_ω ⊆ S 为该选项的初始集合，即在哪些状态下允许启用该选项；π\_ω 为该选项的内部策略，即启用之后在原子动作空间中如何行动；β\_ω: S → \[0,1\] 为终止条件，给出在各状态下结束该选项的概率。引入选项后，高层在选项集合 Ω 上作决策，而每个选项一旦启用便持续若干个原子时间步直至终止。由于选项的持续时长不固定，高层所面对的决策过程不再是标准 MDP，而是**半马尔可夫决策过程**（Semi-Markov Decision Process，SMDP）。在 SMDP 上，高层的价值函数更新需要对选项执行期间的多步折扣回报作累加

Q(s, ω) ← Q(s, ω) \+ β·\[ Σ\_\{i=0..κ−1\} γ^i·r\_\{t\+i\+1\} \+ γ^κ·max\_\{ω′\} Q(s\_\{t\+κ\}, ω′) − Q(s, ω) \] (2-53)

其中 κ 为该选项本次实际执行的时间步数，β 为学习率。将式(2-53)与标准的 Q-Learning 更新式（即第 3.2.2 节的式(3-2)与式(3-3)）相比可以看出，标准 Q-Learning 只累加一步即时奖励且后继价值的折扣因子为 γ，而 SMDP 上的更新需累加选项执行期间的 κ 步折扣奖励，且后继价值的折扣因子为 γ^κ。折扣因子的指数由 1 变为 κ，这正是时间抽象在数学形式上的表现。此后，研究者进一步提出了将高层目标以状态子目标形式下发的 FeUdal 结构、以及可端到端学习选项内部策略与终止条件的 option-critic 等方法，使分层结构的构造由人工设计逐步走向自动学习。

本文的抗干扰问题适合分层处理，根据在于问题本身存在客观的时间尺度分离结构。抗干扰决策中同时存在两类性质不同的判断：
- **战术尺度（单帧，7.68 ms）**：在每一帧内，瞬时 SINR 由当前所采用的 (f\_c, t\_d) 配置直接决定。一旦干扰进入通带，SINR 立即恶化；一旦换到干净的配置，SINR 立即改善。这类因果关系是即时的、局部的，要求以帧为粒度快速响应。
- **战略尺度（数十帧，数百毫秒）**：干扰源的分布模式（例如“三个干扰源在频域上聚集而时域相对稀疏”还是“五个干扰源在时域上密集分布”）是由多个干扰车辆的相对位置、相对速度与各自的发射时序共同决定的统计特征。这类特征只有在数十帧的跨度上累积足够的观测之后才呈现稳定形态。以本文的窗口设置 W = 50 帧为例，其时间跨度为 384 ms，与单帧 7.68 ms 相差约 50 倍。

单帧观测适合快速响应，窗口统计适合提取慢变特征，这一差异为分层设计提供了动机，但并不能证明单一决策器“无法”同时处理两个尺度。循环网络、注意力或多时间尺度状态编码也可能在单一策略中同时建模快慢信息。本文采用两层结构是一项可解释性与模块化取舍，其必要性和相对优势须通过与具备同等时序建模能力的单层基线比较。

单帧与窗口尺度的差异说明该问题具有进行分层设计的可能性，但不能仅凭车辆位移推出干扰配置会在一幕内显著改变。以相对速度 32 m/s、30 帧计，车辆约移动 7.4 m；按直接入射单程传播计算，到达延迟变化约 24.6 ns，仅为 τ\_max = 0.8 μs 的约 3.1%。该变化是否足以使干扰跨越通带边界取决于其初始位置，不能一概而论。因此，本文把时间尺度分离作为待实验验证的架构假设；第四章 Exp-D 通过人为设定的集体跳频事件检验突变场景下的恢复能力，而不以正常车辆运动本身证明快速非平稳性。

本文的两层结构与经典 HRL 存在本质差别：高层不是通过强化学习学习选项价值或终止条件，而是依据仿真 oracle 生成的标签训练随机森林分类器；只有执行层采用强化学习。因此，严格来说，本文属于“借鉴 HRL 时间抽象思想的监督学习 \+ 强化学习混合分层架构”，而不是高、低两层均由强化学习端到端训练的标准 HRL。保留“分层强化学习”这一题名时，正文需始终明确这一边界。选择轻量分类器的原因是当前任务为固定三分类且需要可检查的特征贡献；端到端训练高层策略以及消除 oracle 标签依赖留待后续研究。

### 2.3.2 两层决策系统架构与动态动作掩码接口设计

基于 2.3.1 节的论证，本文提出如图 2-8 所示的两层抗干扰决策系统架构。系统自上而下由**元策略控制器**（Meta-Policy Controller）与**深度强化学习执行器**（DRL Executor）构成，二者通过**动态动作掩码**（Dynamic Action Masking，DAM）接口交互，共同作用于由目标与干扰构成的雷达工作环境。
> 【图 2-8 抗干扰分层决策系统架构图】
图源：参照专利附图 2 重绘（自上而下：元策略控制器（滑动窗口特征提取 → 随机森林分类器 → 策略标签\+置信度）—— DAM 接口（Q 值偏置向量）—— DRL 执行器（Double DQN \+ GRU）—— 雷达收发与环境（目标、干扰）；环境的 SINR 反馈同时上行至两层）   

执行层（战术层）以帧为粒度运行，在每一帧内完成“发射—接收—Dechirp—RDM—SINR 估计—状态更新—动作选择”的完整闭环（详见第 3.2.1 节），输出下一帧所使用的参数状态 (f\_c, t\_d)。其决策依据是式(2-48)所定义的基础状态及由 GRU 隐状态所承载的历史记忆，优化目标是式(2-49)所定义的即时奖励的折扣累积。执行层不感知干扰源的数量、分布等场景级信息，只对自身观测到的 SINR 序列作出反应。

元策略层（战略层）以 K 帧为决策周期运行，在每个决策周期内自最近 W 帧的 SINR 序列与动作记录中提取场景语义特征，判别当前所处的干扰场景类型，并输出三种元策略标签之一（频域优先、时域优先、联合探索）及相应的置信度。元策略层不直接选择 (f\_c, t\_d)，而只规定执行层应当在哪个维度上重点搜索。

DAM 是两层之间唯一的接口契约。两层只通过 DAM 交换信息，且交换的内容被严格限定：元策略层向下只输出“策略标签 \+ 置信度”这一对量，DAM 将其转换为一个长度为 \|A\| = 9 的 Q 值偏置向量，执行层向上只消费该偏置向量，并将其叠加至自身网络输出的原始 Q 值之上。形式化地，设执行层网络输出的原始动作价值为 Q(S\_t, a)，元策略层输出的标签为 ℓ ∈ \{freq\_only, time\_only, joint\}、置信度为 p ∈ \[0, 1\]，则执行层实际用于动作选择的价值为

Q̃(S\_t, a) = Q(S\_t, a) \+ bonus(a; ℓ, p)， a ∈ A (2-54)

其中 bonus(·) 的具体形式将在第 4.1.3 节给出。该设计的作用有三个方面。

其一是层间解耦。执行层无需感知偏置向量的来源，元策略层的具体实现方式因而可以自由替换：本文采用随机森林，原则上亦可替换为任何分类器乃至大语言模型，而不需要对执行层作任何修改，更不需要重新训练执行层网络。第三章与第四章的工作由此可以独立开展、独立验证。

其二是训练与推理的形式统一。DAM 在训练阶段用于将单维度智能体的动作空间裁剪至相应子空间，在推理阶段用于承载元策略的下发指令，二者使用同一套接口机制（详见第 3.3.2 节），避免了训练与推理之间的实现分歧。

其三是容错性可控。偏置叠加在原始 Q 值之上而非替换原始 Q 值，元策略层的错误判断只会改变各动作之间的相对优势，不会将任何动作从候选集合中彻底排除；偏置幅度还可通过置信度连续调节。这一性质是第 4.1.3 节所述软引导机制的基础，也是本架构在分类器误判率约 15%～20% 的条件下仍不发生性能退化的原因。

### 2.3.3 异步协同与低延迟控制机制

2.3.1 节自问题性质出发论证了分层的必要性。在系统实现层面，两层的时间尺度分离还带来一个具体的工程矛盾：执行层必须在一帧（7.68 ms）之内完成动作选择，否则雷达无法按时发射下一帧；而元策略层需要完成 12 维特征提取与分类器推理，其耗时并不天然地小于帧周期。若采用同步实现，即执行层在每个决策周期到来时阻塞等待元策略层返回结果，则一旦元策略层的推理耗时超过帧周期，雷达的发射时序即被破坏。

为此，本文采用双线程非阻塞的异步协同机制，如图 2-9 所示。执行层与元策略层运行于两个独立的执行线程：
- **执行线程**按帧周期严格定时运行，每帧读取一次配置缓冲区中的当前偏置向量，与自身网络输出叠加后选择动作并发射，全程不等待元策略层；
- **元策略线程**按 K 帧的决策周期被触发，自共享的观测历史缓冲区中读取最近 W 帧的 SINR 与动作记录，完成特征提取与分类器推理，将新的策略标签与置信度换算为偏置向量后写入配置缓冲区。

两个线程通过配置缓冲区解耦。实现时必须保证执行线程读取到的是一份完整快照，可采用不可变对象的原子引用替换，或用极短临界区完成加锁读写；不能在缺少并发语义证明的情况下直接声称“无锁读取”必然安全。若元策略线程未在当前周期内完成，执行线程继续使用上一份完整偏置向量，使控制循环不因等待上层结果而阻塞。该设计只能保证控制流连续，不能保证过期偏置不会降低性能；过期时间及其影响仍需在目标运行平台上测试。

本文设置的帧周期为 7.68 ms，元策略每 K = 3 帧触发一次，因此名义决策周期为 3 × 7.68 = 23.04 ms（文中取 23.0 ms）；最小策略保持时间为 5 帧，即 38.4 ms。三者描述的是执行、判别与切换约束，不能据此推出元策略结果一定能在一个周期内更新：当前端到端实测约 99.6 ms，已超过 23.0 ms，异步实现只是不阻塞执行线程，实际生效时延仍需如实计入。

## 2.4 仿真实验平台与性能评估指标

本节介绍支撑第三、四章实验的仿真平台与评估指标。两章的实验共用同一套信号级仿真平台与同一套指标定义，仅在干扰密度的设置上有所区别。

### 2.4.1 仿真平台搭建与动态干扰建模

本文的仿真平台工作在信号级：不直接生成“目标已被检测到”的抽象观测，而是依据 2.1.2 节所推导的解析式逐 chirp 地生成射频信号，并完整走通雷达的信号处理链路。每一帧的仿真流程如下：
1. 场景初始化（每幕开始时执行一次）：依据表 2-4 所给定的分布随机生成若干点目标与干扰源，确定各自的幅度、距离（或到达延迟）、相对速度与反射相位；
2. 信号生成：依据式(2-22)～(2-25)逐 chirp 地生成参考信号与各目标回波，依据式(2-30)～(2-34)生成各干扰信号并按各自的 t\_d^intf(0) 作整体时移，将所有目标回波与干扰按幅度加权叠加；
3. 加噪：向接收信号加入加性高斯白噪声以模拟雷达系统噪声，噪声等级依表 2-4 所列 SNR 确定；
4. 解调与滤波：将接收信号与参考信号混频完成 Dechirp，并依据 f\_ref(t) 与各分量瞬时频率之差作理想低通滤波，即将频率差超过 f\_bmax 的成分直接置零；
5. 距离多普勒处理：对拍频信号在快时间维与慢时间维各作一次 FFT 得到 RDM；
6. SINR 估计与指标统计：依据式(2-16)由 RDM 上目标分量与干扰噪声分量的能量之比估计本帧 SINR，并统计本帧的干扰重叠情况等信息，作为强化学习的观测与奖励依据。

d(t\_n) = d(t\_\{n−1\}) \+ v\_target·Δt (2-55)

### 2.4.2 性能评估指标设计

为刻画抗干扰策略在稳态性能、鲁棒性、资源代价、收敛速度与非平稳适应能力五个维度上的表现，本文定义如下六项评估指标，第三、四章共用这一套定义。

**（1）平均 SINR 及其标准差。** 对测试中所有幕的所有帧求 SINR 的均值与标准差。均值反映策略的稳态抗干扰性能；标准差反映策略在不同干扰分布下性能的一致性，标准差大意味着策略的表现依赖于干扰恰好落在何处，带有较强的偶然性。

**（2）避开率。** 定义为一幕之内 SINR 大于 0 dB 的帧数占总帧数的比例

r\_avoid = ( SINR \> 0 的帧数 ) / ( 总帧数 ) (2-57)

由于 SINR = 0 dB 意味着目标能量与干扰噪声能量相当，该阈值可近似视为目标可被稳定检测的临界条件，故避开率直接反映策略完全避开干扰的能力。平均 SINR 与避开率共同使用可以区分两类不同的失效：避开率高而平均 SINR 不高，说明策略能避开干扰但未能优选最干净的配置；避开率低而平均 SINR 尚可，说明策略在无法完全避开时能够避重就轻，优先避开强度大的干扰。

**（3）动作代价总和。** 对一幕之内各帧的动作代价（式(2-50)）求和，反映策略实施所需的参数切换开销。该指标衡量的是抗干扰增益的成本：频繁的参数切换会带来硬件负担（如锁相环重新锁定的时间开销），也会使雷达输出的距离—速度估计在帧间缺乏一致性，不利于后续的目标跟踪。

**（4）T80 收敛帧数。** 定义为自一幕开始至 SINR 首次达到该幕最终稳态 SINR 的 80% 所需的帧数，反映策略面对新的干扰分布时的收敛速度。该指标对性能本身很差的方案不具备可比性：若某方案全程维持在低水平，其最终稳态值本身很低，达到该低值的 80% 自然很快，T80 反而显得很小。因此使用该指标时必须与平均 SINR 联合解读，本文在 4.4.2 节报告固定参数基线的 T80 时将明确指出这一点。

**（5）早期 AUC。** 定义为一幕前 10 帧的 SINR 时序曲线下面积，即

AUC\_early = Σ\_\{n=1..10\} SINR(t\_n) (2-58)

该指标是对收敛速度的另一种度量，相比 T80 的优势在于它同时反映了上升速度与上升过程中的累积收益，且不依赖于最终稳态值这一需要事后确定的量，因而对不同性能水平的方案具有更好的可比性。

**（6）跳频恢复帧数。** 用于非平稳场景的专项评估。在一幕的中途令全部干扰源同时重新分配其中心频点，记录自该扰动发生至 SINR 恢复到扰动前稳态水平所需的帧数。该指标直接刻画策略对干扰模式突变的适应能力，是第四章 Exp-D 实验的核心指标。

## 2.5 本章小结

本章完成了面向相干干扰的雷达抗干扰分层决策系统的建模与架构设计，主要工作包括四个方面。

其一，建立了 FMCW 雷达与干扰的仿真模型，给出参考信号、目标回波、拍频信号以及运动场景下时变延迟、相位与频率的表达。在本文采用理想 LPF 的仿真模型中，超出截止频率的差频成分被滤除，这为时、频域参数调整提供了一个关键机理；该结论依赖理想滤波与信号模型。高相干干扰使仅依赖样式差异的接收端处理更困难，但不能推出全部接收端方法失效或发射参数调整是唯一方案。

其二，以帧为单位设置决策粒度。帧内中心频率与发射时延保持不变，有助于维持该帧慢时间处理的一致条件；SINR 由该帧 RDM 估计。当前材料尚未以检测概率、虚警率、多普勒误差或跨帧处理实验验证参数切换不影响目标检测，因此不再使用“不牺牲目标检测性能”的结论。

其三，将抗干扰策略的执行过程建模为部分可观测马尔可夫决策过程。给出了状态、动作与奖励的设定；论证了由于雷达只能感知当前通带内的标量 SINR、无法直接观测干扰的完整时频分布，问题实质上是 POMDP，并据此引入时序扩展状态以历史观测近似真实状态。

其四，构造监督学习元策略控制器与深度强化学习执行器组成的混合分层架构，并以 DAM 统一策略标签到动作偏置的接口。该接口降低了模块耦合，但不意味着两层在数据、时序和性能上完全独立，也不能仅凭接口形式证明上层可自由替换。双线程与缓冲区可避免同步阻塞发射线程；然而当前端到端约 99.6 ms 高于 23.0 ms 元决策周期，仍存在策略陈旧与工程实时性问题。

本章所建立的模型、架构与仿真平台是后续两章工作的共同基础。第三章将实现并优化其中的深度强化学习执行层，第四章将实现并优化其中的元策略控制器。
