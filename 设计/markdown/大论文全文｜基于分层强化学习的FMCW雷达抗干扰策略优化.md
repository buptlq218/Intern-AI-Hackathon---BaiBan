# 摘 要

随着汽车毫米波雷达的日益普及，雷达之间的相互干扰正在成为一个重要的安全问题。在各类干扰中，相干干扰尤为棘手：当干扰雷达与受扰雷达采用相同或相近的调频斜率、脉冲重复周期等参数时，干扰经 Dechirp 处理后可形成窄带分量，并在距离多普勒域产生与目标峰值相似的虚假目标。对于依赖干扰与目标回波在某个处理域上具有可分辨差异的接收端抑制方法，这类情形尤其困难。因此，本文重点研究通过自适应调整发射参数实现的非合作式干扰避免。针对本文调研的典型单层深度强化学习方案在统一时间粒度下同时承担场景判断与具体动作选择的问题，本文构建了由监督学习元策略控制器与深度强化学习执行器组成的两层混合决策框架。该框架借鉴分层强化学习的时间抽象思想，但并非高、低两层均由强化学习端到端训练。本文主要研究内容如下：
1. 面向相干干扰的分层抗干扰决策架构与时间尺度分离机制

针对场景判断与具体动作选择具有不同时间尺度的问题，本文推导运动场景下目标回波与干扰信号的解析形式并搭建信号级仿真平台；以一帧为决策单位，使参数切换仅发生在帧间，避免破坏帧内慢时间相干积累；将抗干扰过程建模为部分可观测序贯决策问题；借鉴分层强化学习的时间抽象思想，设计由随机森林元策略控制器与深度强化学习执行器构成的两层混合架构，并以 Q 值偏置作为层间接口。为避免上层计算阻塞逐帧控制，本文进一步给出异步协同的设计方案。需要说明的是，当前 Python 仿真实现的元策略端到端耗时尚未满足设定的决策周期，因此本文的实时性结论限于架构设计与分类器单次推理环节，工程部署仍需优化与实测。
2. 基于 Double DQN 与门控循环单元的抗干扰策略执行层

针对雷达仅能观测标量信干噪比所导致的部分可观测问题，本文采用“单帧观测输入 \+ GRU 隐状态承载历史信息”的网络结构；设计自适应分段奖励与动作切换代价，并使用动作范围约束/引导机制兼顾训练阶段的探索空间裁剪与推理阶段的层间调控。在当前场景 A 的仿真设置下，时、频域联合策略取得 9.50 ± 0.57 dB 的平均信干噪比与 91% 的干扰避开率，数值上高于仅频域与仅时域方案，其标准差分别约为后两者的 1/5.6 与 1/8.1。现有消融记录显示移除 GRU 后平均信干噪比约下降 2.3 dB，但确切均值、标准差及重复试验统计仍需由原始实验结果补齐。
3. 基于场景语义特征与随机森林的元策略控制器

针对标量反馈难以直接揭示干扰在时、频域分布结构的问题，本文设计十二维场景语义特征与随机森林元策略控制器，并以置信度缩放的 Q 值偏置实现软引导。软引导不会把未优先动作从候选集合中删除，因此保留了执行层纠正元策略误判的通道；但它仍可能改变动作排序，不能据此推出“性能必不低于纯深度强化学习”的下界保证。在当前仿真、oracle 初始化条件下，Meta-RF 相比使用相同执行层权重的 Pure DRL，平均信干噪比提高约 5.1 dB、避开率提高 4.5 个百分点，并在干扰源集体跳频实验中将恢复帧数由约 8 帧降至约 5 帧。由于测试阶段使用了仿真 oracle 对 9 个配置的信号质量估计进行初始化，上述结果应视为元策略机制的 oracle 辅助仿真验证或性能上界；在无 oracle 条件下的冷启动、长期未访问配置的估计陈旧及各内部机制的独立贡献仍需补充实验。

综上，本文提出了一种无需车间通信的两层混合抗干扰决策方法，并在两组仿真场景中验证其可行性。现有结果表明，元策略引导在所设密集干扰与集体跳频场景下改善了平均性能与恢复速度；但实验依赖理想低通、可准确获得的信干噪比以及测试初始时刻的 oracle 种子，且尚未完成无 oracle、硬件在环和实车验证。因此，本文结论应限定在给定仿真模型与实验设置内，不直接等同于工程实时性或实车可部署性证明。

关键词：汽车毫米波雷达；抗干扰；分层强化学习；元策略控制器；随机森林

# ABSTRACT

With the growing use of automotive millimeter-wave radar, mutual interference has become an important safety concern. Coherent or near-coherent interference is particularly difficult because, when the interfering and victim radars use identical or similar chirp slopes and pulse repetition intervals, narrowband components after dechirping may produce ghost peaks resembling target returns in the range-Doppler domain. This is especially challenging for receiver-side mitigation methods that rely on separability between interference and target echoes. This thesis therefore focuses on non-cooperative interference avoidance through adaptive transmission-parameter selection. To separate coarse scene assessment from frame-level action selection, a hybrid two-layer decision framework is developed, comprising a supervised random-forest meta-controller and a deep-reinforcement-learning executor. The framework is inspired by temporal abstraction in hierarchical reinforcement learning, but its two layers are not trained end-to-end by reinforcement learning. The main contributions are as follows.
1. A hierarchical anti-interference decision architecture and time-scale separation mechanism for coherent interference

Analytical expressions for target echoes and interference signals in moving scenarios are derived and a signal-level simulation platform is constructed. One frame is used as the decision unit so that parameter changes occur only between frames and do not disrupt coherent integration within a frame. The anti-interference task is formulated as a partially observable sequential decision problem. A hybrid two-layer architecture, consisting of a random-forest meta-controller and a deep-reinforcement-learning executor, is then designed using Q-value biasing as the inter-layer interface. An asynchronous coordination scheme is also proposed to prevent upper-layer computation from blocking frame-level control. The current Python implementation, however, does not yet meet the configured end-to-end meta-decision period; real-time deployment therefore remains to be demonstrated.
2. An anti-interference policy execution layer based on Double DQN and gated recurrent units

To address partial observability when the radar observes only scalar SINR feedback, the executor uses single-frame observations together with a GRU hidden state carrying historical information. A piecewise reward with an action-switching cost and an action-range constraint/guidance mechanism are used for exploration control and inter-layer coordination. Under the current Scenario-A simulation settings, the joint time-frequency strategy achieves an average SINR of 9.50 ± 0.57 dB and an interference-avoidance rate of 91%, with numerical results higher than the frequency-only and time-only schemes. Existing ablation records indicate an approximately 2.3 dB decrease after removing the GRU, but the exact mean, standard deviation, and repeated-trial statistics still require confirmation from the original experimental outputs.
3. A meta-policy controller based on scenario semantic features and random forests

Twelve scenario-semantic features and a random-forest meta-controller are designed to expose structure that cannot be read directly from scalar SINR feedback. Confidence-scaled Q-value biasing provides soft guidance while retaining non-preferred actions as candidates; because the bias may still change action rankings, it does not constitute a formal lower-bound guarantee relative to pure DRL. Under the current simulation with oracle initialization, Meta-RF improves average SINR by about 5.1 dB and the avoidance rate by 4.5 percentage points over Pure DRL with identical executor weights, and reduces recovery from about eight frames to about five frames after collective frequency hopping. Because the evaluation initializes the nine configuration-quality estimates from a simulation oracle, these results should be interpreted as an oracle-assisted validation or upper bound. Cold start without oracle information, stale estimates for rarely visited configurations, and the independent contributions of the internal mechanisms remain to be evaluated.

In summary, this thesis proposes a communication-free hybrid two-layer anti-interference method and demonstrates its feasibility in two simulation scenarios. The current results show improvements in average performance and recovery speed under the configured dense-interference and collective-frequency-hopping settings. However, the experiments rely on ideal filtering, accurately available SINR, and oracle seeding at the beginning of evaluation, and they do not yet include oracle-free, hardware-in-the-loop, or on-road validation. The conclusions are therefore limited to the stated simulation model and settings and should not be treated as evidence of real-time deployability in production vehicles.

KEY WORDS: automotive millimeter-wave radar; anti-interference; hierarchical reinforcement learning; meta-policy controller; random forest

# 第一章 绪论

## 1.1 研究背景

近二十年来，传感器、深度学习算法、高精度地图与车载计算平台的进展共同推动了自动驾驶技术的发展。L2 级辅助驾驶功能（如自适应巡航控制、车道保持辅助）已在大量量产车型上普及，L3、L4 级有条件自动驾驶与高度自动驾驶车辆的研发与道路测试正在推进，部分地区已开始试点无人驾驶出租车服务\[1\]\[2\]。

感知系统通过毫米波雷达、激光雷达、摄像头、超声波传感器、惯性导航系统与全球导航卫星系统等采集环境信息，使车辆实时掌握周围的静态与动态环境要素，为路径规划、行为决策与车辆控制提供输入。与其他传感器相比，毫米波雷达不受光照与雾、雨、雪等天气条件的显著影响，距离与速度测量精度高，探测范围大，是恶劣天气下少数仍能稳定工作的传感器。调频连续波（Frequency-Modulated Continuous Wave，FMCW）雷达距离分辨率高、体积小、成本低、发射功率低且易于集成，已成为汽车毫米波雷达的主流选择\[3\]。

但车载毫米波雷达共享同一频段（我国规定为 76 ～ 79 GHz\[4\]），且以非合作方式各自发射探测信号。为获得高距离分辨力，单部雷达往往占用很大的射频带宽：依据距离分辨力 ΔR = c/(2B) 的关系，欲达到 0.3 m 的距离分辨力即需 500 MHz 带宽，而整个共享频段仅有 3 GHz 可用。与此同时，为在不同距离上提供 360° 全方位态势感知，单车所装配的雷达数量不断增加，一辆具备 L2\+ 级功能的车辆通常配备一部前向长程雷达与四部角雷达，共计五部以上。频谱资源有限、工作方式非合作、雷达数量增长，三者叠加使雷达之间产生相互干扰的概率大幅上升。雷达间的相互干扰会掩盖弱目标或产生虚假目标，影响探测结果的正确性，构成安全隐患\[5\]。

依据干扰雷达与受扰雷达发射信号波形参数的相似程度，FMCW 雷达间的相互干扰可分为相干干扰与非相干干扰\[6\]。当两者的调频斜率、脉冲重复周期等波形参数相同或非常接近时，雷达间的干扰为**相干干扰**；当两者波形参数差异较大时，则为**非相干干扰**。二者的危害方式不同：非相干干扰经 Dechirp 处理后能量分散于频谱，主要影响是抬高噪声门限、掩盖真实目标，导致漏检；相干干扰经 Dechirp 后能量集中于窄带，其在频域、时频域与距离多普勒域上的样式与真实目标回波高度一致，在目标检测时形成虚假目标。

本文聚焦于相干干扰，主要因为这类干扰在 Dechirp 与距离多普勒处理后可能形成与目标峰值相似的窄带分量，容易引起虚警或掩盖弱目标。需要限定的是，这并不意味着所有接收端方法在任何相干干扰条件下都必然失效；结论只针对本文所建模的同斜率、同 PRI、直接入射干扰与理想处理链。在该模型下，仅依赖处理域可分性的接收端方法面临明显困难，因而本文选择从发射参数自适应角度研究干扰避免。

## 1.2 国内外研究现状

目前研究人员已提出多种方法来消除汽车雷达之间的相互干扰。依据抗干扰的作用环节与原理，可将其归纳为**接收端信号处理**与**发射端波形与参数调整**两大类；在后者之中，依据是否利用实时环境信息与是否需要车间通信，又可进一步区分为随机化方法、合作式方法与基于认知的自适应方法。本节依此脉络展开综述，各类方法的对照汇总于表 1-1。

### 1.2.1 接收端信号处理类方法

该类方法不改变雷达的发射行为，而是对接收信号进行后处理以消除干扰，其共同原理是利用干扰与目标回波在某个处理域上的差异。

在时域上，Muhammad Rameez 等人对接收信号构建自回归模型，以估计并重建被干扰破坏的目标回波\[7\]。在频域上，Feng Jin 等人自接收信号的 FFT 结果中提取主样本与参考样本进行自适应噪声消除\[8\]；Seongwook Lee 等人使用小波变换对受扰信号进行分解并重构出干扰信号，再以重构的干扰去消除原信号中的干扰\[9\]。在时频域上，Jianping Wang 在短时傅里叶变换所得的时频图上使用恒虚警率（Constant False Alarm Rate，CFAR）检测器估计干扰的掩膜，并分别以置零、幅度修正与基于 Burg 的外推法重建信号\[10\]。近期，J. Li 等人系统评估了时域门限与时频域门限两类方法的性能，指出时频域门限的效果优于时域门限\[11\]；M. Toth 等人提出基于变分推断的信号分离方法，以稀疏贝叶斯框架配合逐次干扰消除实现干扰与目标的分离\[12\]。

深度学习方法在该方向亦取得成功。Jiwoo Mun 等人使用带自注意力机制的循环神经网络处理接收信号的时间序列以消除干扰\[13\]。Johanna Rock 等人使用卷积神经网络对接收信号的一维距离像与距离多普勒图进行处理以抑制干扰\[14\]。Yuan He 等人使用复数卷积神经网络、对比学习与空洞卷积，并引入基于先验信息的正则项，在时频图上抑制干扰\[15\]\[16\]\[17\]\[18\]。C. Oswald 等人进一步提出角度等变卷积神经网络，通过构造对到达角具有等变性的卷积核提升模型在不同到达角下的泛化能力\[19\]。

也有借助硬件手段的思路。S. P. Maruthi 等人提出在车载端部署智能反射面，通过提升目标的有效散射截面积来改善信干比\[20\]。

这一大类方法的优点是不需要改变雷达前端结构，只需增加信号后处理模块，较易实现与部署。其不足有二：一是额外的处理环节降低了目标探测的时效性，深度学习类方法尤甚；二是如 1.1 节所述，相干干扰在上述各处理域上均与目标回波具有相同的样式，该类方法在原理上无法将其区分并消除，虚假目标问题依然存在。

### 1.2.2 发射端波形与参数调整类方法

该类方法通过调整雷达发射信号的参数，使接收到的干扰在后续常规信号处理中被滤除，或使其能量在检测域上分散，从而消除或降低干扰对目标检测的影响。由于其作用于发射环节而不依赖处理域上的差异，该类方法既可避开非相干干扰，也能对抗相干干扰，这正是本文选择该技术路线的原因。依据参数选择方式的不同，可分为三支。

（1）**随机化方法**。Tang-Nian Luo 等人率先提出具备抗干扰特性的集成 77 GHz 汽车雷达收发器设计及其硬件实现，通过随机调整中心频率与调频斜率来避开相干干扰或使其转化为噪声\[21\]。Yusuke Kitsukawa 等人提出使用脉冲重复间隔随机变化的 FMCW 发射波形，将相干干扰的能量在频域分散\[22\]。Faruk Uysal 等人提出了实现脉内相位编码的 FMCW 雷达系统，将相干干扰的能量分散至整个距离多普勒域\[23\]\[24\]。Bo Tang 等人提出慢时间维（即脉间）二进制编码，改变相干干扰在多普勒维的能量分布以避免虚警与漏检\[25\]。Sian Jin 等人在一个 FMCW 雷达网络中非合作地使用随机跳频、时分复用、二进制脉间相位编码及其组合，并分析了各组合的多址接入容量与目标误检测概率\[26\]。A. Bazzi 等人近期系统分析了帧级与 chirp 级随机载波跳频等前摄式非协调抗干扰技术，并结合方位信息给出改进方案\[27\]。O. Longman 等人则在多干扰源环境下对多种抗干扰技术作了对比评估，其结论指出时频联合编码在各类条件下的表现最为稳健\[28\]。

随机化方法实现简单，无需任何环境信息，但其参数选择是盲目的：它降低了干扰发生的概率，却不能针对当前的具体干扰情况作出应对。在干扰源数量较多、频谱资源紧张时，随机选择恰好落入被占用配置的概率显著上升，抗干扰效率有待提高。

（2）**合作式方法**。Joud Khoury 等人提出雷达媒介访问控制系统架构 RadarMAC 及其配套算法，区域内所有车辆将行驶信息与雷达参数上传至中心控制器，由控制器统一分配各雷达下一时刻的工作参数（包括中心频率与发射时间）\[29\]。Canan Aydogdu 等人提出基于分布式网络协议的雷达与通信协作系统 RadChat，每辆车仅与周围车辆通信并协商雷达与通信的工作参数\[30\]。Arindam Bose 等人提出在互联汽车信息共享的条件下进行相位编码，并以循环迭代方法最小化交叉模糊函数\[31\]。L. Xu 等人近期进一步提出利用建设性干扰的协同感知方案，通过车间交换优化后的加权矩阵提升整体感知性能\[32\]。

合作式方法利用了周围的环境信息，因而能够获得更好的抗干扰效果，但需要额外的通信开销，增加了系统复杂度与部署门槛，并引入了通信系统与雷达系统之间相互干扰的可能。

（3）**基于认知的自适应方法**。这一支介于前两者之间：它不依赖车间通信，因而是非合作式的；但利用雷达自身对环境的观测来指导参数选择，因而不是盲目的。其理论源头是 Simon Haykin 于 2006 年提出的认知雷达（Cognitive Radar）概念\[33\]。如图 1-2 所示，认知雷达系统具有自适应能力与智能决策功能，能够通过学习、理解并动态适应环境变化来优化性能，其核心包括：智能信息处理，即实时分析接收回波并基于先验知识库与对当前环境的学习更新自身算法；闭环自适应，即形成自发射机到接收机再到信息处理器的闭环反馈，使雷达能够根据接收到的信息调整发射信号特性（如波形、频率、带宽、极化等）与工作模式；环境感知与理解；资源最优分配；以及自主学习与进化\[34\]。此后一系列研究表明，认知雷达技术可用于减少雷达与其他射频系统间的干扰，涵盖频谱感知、频谱共享、干扰感知与天线配置等方面\[35\]\[36\]\[37\]。

本文所属的技术路线正是这一支，其后续发展与不足详见 1.2.3 节。

### 1.2.3 基于强化学习的认知抗干扰方法

在很多场景下，通过调整雷达参数来抗干扰可以视为一个序贯决策问题，而基于认知雷达的抗干扰过程通常可以建模为马尔可夫决策过程（Markov Decision Process，MDP）。强化学习（Reinforcement Learning，RL）是求解序贯决策问题的常用方法，近年来已被引入认知雷达抗干扰。

传统强化学习方法方面，Ersin Selvi 等人使用策略迭代与 Q-Learning 优化自适应带宽雷达在通信干扰下的目标追踪性能\[38\]\[39\]。Qinhao Wu 等人使用双学习技巧优化无人机网络雷达系统的抗干扰策略，自天线配置、频率选择与位置布局三个维度对抗干扰\[40\]。Ailiya 等人提出联合调整跳频与脉冲宽度的抗干扰策略，并在奖励中加入惩罚项以约束雷达切换参数的频率，使用 Q-Learning 得到抗干扰性能与探测效率均较优的策略\[41\]。上述方法均采用传统强化学习的表格型求解法，而表格型方法难以处理大规模搜索空间与连续取值，只能解决简单场景下干扰样式相对固定的问题，无法应对复杂场景与多样多变的干扰。

深度强化学习方法则可处理大规模、高维、连续的搜索空间，从而求解更复杂的决策问题。分别在围棋与星际争霸中战胜顶尖职业选手的 AlphaGo\[42\]\[43\]与 AlphaStar\[44\]即为典型例证。近年来，研究人员亦将深度强化学习应用于汽车雷达抗干扰。

Pengfei Liu 等人提出双车道多车动态场景下的汽车雷达抗干扰建模，车辆自身雷达的接收信号中提取频谱环境信息，并使用加入长短期记忆（Long Short-Term Memory，LSTM）网络的深度 Q 网络（Deep Q Network，DQN）处理历史观测以应对部分可观测问题，实现了多智能体场景下分布式训练—分布式执行的频谱分配\[45\]。该方法仅在频域上调整参数，未利用时域、时频域、相位域等其他操作域的资源，故当干扰数量较多时避开干扰的效果明显恶化。刘飞鹏提出调整中心频率与调频斜率的策略，并使用 Double DQN 优化，取得了优于单独调整中心频率的性能\[46\]，但其干扰设置较为简单，避开干扰的难度不大，且受限于 DQN 无法输出连续动作。Mario Coutino 等人提出自脉冲时长、脉冲间隔与调制模式三个维度进行波形设计的策略，并使用近端策略优化算法优化\[47\]，但脉冲重复间隔的频繁变化严重降低了相干累积的效率。Graeme E. Smith 等人提出使用深度确定性策略梯度算法优化脉间相位编码以实现频谱陷波\[48\]\[49\]\[50\]，尽管取得了较好的陷波定位精度、宽度与深度，但并未开展雷达抗干扰实验，未实现端到端的抗干扰验证。Charles E. Thornton 等人提出基于在线学习的波形选择方法，以满意化汤普森采样在自适应带宽与慢时间维编码之间作权衡，同时优化目标识别性能\[51\]，其决策仍以单层的在线选择为形式，未涉及不同时间尺度上决策的分离。

现有基于深度强化学习的抗干扰方法存在一项共同不足，它出在决策结构上。尽管所调整的参数维度与所采用的算法各不相同，上述工作均为单一智能体以统一的时间粒度处理全部决策。这一结构带来三项彼此关联的问题。

其一，时间尺度矛盾。FMCW 雷达的参数决策必须在很短的周期内完成，属于战术级决策；而干扰源的分布模式（如"频域集中若干干扰源"还是"时域密集分布"）需要在数十至数百个决策周期的跨度上才呈现稳定的统计特征，属于战略级判断。单一智能体以相同粒度处理两类决策，无法同时满足两个尺度的要求：若为积累统计信息而增大决策间隔，则丧失快速响应能力；若以最细粒度作全部决策，则场景级信息淹没在瞬时噪声之中。

其二，标量反馈的信息不足。现有方法多以信干噪比等标量作为环境反馈。标量反馈可以告知"当前配置好不好"，但无法揭示干扰在各操作域上的分布结构，即无法回答"当前性能差是因为频域被占满还是时延不匹配"。智能体只能通过切换参数后观测新的反馈来间接推断，表现为动作序列的频繁振荡与大量无效试错。

其三，非平稳环境下探索—利用矛盾的加剧。干扰环境具有非平稳性：干扰车辆的相对运动、新干扰源的进入、既有干扰源的频率跳变都使环境分布持续改变。此时 ε-贪心等探索机制面临两难，探索率过小则无法适应环境变化，过大则稳态性能持续振荡。其根本原因在于单层结构把"是否需要改变搜索策略"与"具体选择哪个动作"绑定在同一个价值网络上，而这两类决策所需的信息基础与决策频率截然不同。

### 1.2.4 分层强化学习与轻量模式识别

上述三项不足指向同一个方向：需要在决策结构上引入时间尺度的分离。分层强化学习（Hierarchical Reinforcement Learning，HRL）正是为此而提出的框架。

Richard Sutton、Doina Precup 与 Satinder Singh 于 1999 年提出选项（Option）框架，将时间抽象引入强化学习：一个选项由初始集合、内部策略与终止条件三者构成，高层在选项集合上决策而每个选项对应低层的多步动作，高层所面对的决策过程因而成为半马尔可夫决策过程\[52\]。Thomas Dietterich 提出的 MAXQ 值函数分解则自另一角度实现分层，将整体价值函数递归地分解为子任务价值之和\[53\]。此后，Alexander Vezhnevets 等人提出 FeUdal Networks，由管理者网络产生抽象的方向性目标、由工作者网络执行原子动作\[54\]；Ofir Nachum 等人提出 HIRO，以高层下发状态子目标的方式实现数据高效的分层学习\[55\]；Pierre-Luc Bacon 等人提出 option-critic 架构，使选项的内部策略与终止条件可以端到端地学习，摆脱了对人工设计选项的依赖\[56\]。针对非平稳环境下强化学习的困难，已有系统的综述与方法梳理\[57\]，其结论之一是：在环境分布持续变化的条件下，显式地检测变化并切换策略往往优于依赖单一策略的被动适应。

分层结构与雷达抗干扰问题在结构上是契合的：干扰环境本身就具有"瞬时信干噪比快速变化"与"干扰分布模式缓慢演变"两个天然分离的时间尺度。然而据本文所查，将分层强化学习的思想用于汽车雷达抗干扰的工作尚不多见，现有的雷达抗干扰研究几乎全部采用单层决策结构。

分层结构的高层判别可以由强化学习习得，亦可由监督学习实现。就雷达抗干扰这一具体应用而言，高层判别面临两项工程约束：推理必须足够快，以适应雷达的决策周期；决策依据必须可解释，因为抗干扰系统属于行车安全相关部件。在这两项约束下，轻量的模式识别方法更为合适。Leo Breiman 提出的随机森林\[58\]以分类回归树\[59\]为基学习器，通过自助采样与特征随机化抑制方差，其推理为树路径遍历，耗时在亚毫秒量级；它还能给出基于不纯度下降的特征重要性度量，使决策依据可被定量审视。该度量对相关特征存在稀释与偏置效应，需谨慎解读\[60\]，配合 SHAP 等事后解释方法可获得更完整的归因\[61\]。相比之下，神经网络分类器虽然表达能力更强，但其 Softmax 输出的置信度往往过度自信、校准性较差\[62\]，而在本文的软引导机制中置信度被直接用作引导强度的调节量，其可靠性对系统行为有实质影响。

大语言模型可用于开放式知识推理，但本文没有构建或复现大模型雷达决策基线，也缺少同一硬件、同一输入输出条件下的时延与准确率对比。因此，本文不对“大模型方案必然更慢或更不可解释”作定量结论。本文选择随机森林，是因为当前任务是固定的三分类问题，输入为结构化低维特征，且随机森林便于在现有数据规模下训练并检查特征贡献；大模型方案仅作为后续可选方向，不纳入本文实验结论。

### 1.2.5 本文的研究目标

基于上述研究现状，本文拟研究面向相干干扰的 FMCW 雷达分层抗干扰决策方法：在不需要任何车间通信开销的前提下，通过引入决策结构上的时间尺度分离，弥补单层深度强化学习方案在标量反馈信息不足与非平稳环境适应能力上的缺陷。具体从三个方面展开：其一，建立信号模型与仿真平台，将抗干扰过程建模为部分可观测马尔可夫决策过程，并设计两层决策架构与层间接口；其二，实现并优化底层的深度强化学习执行器，使其具备时序感知能力与较高的样本学习效率；其三，实现并优化上层的元策略控制器，通过场景语义特征的显式提取与轻量模式识别，将执行器的盲目搜索转化为定向搜索。

## 1.3 本论文的主要内容及结构安排

### 1.3.1 总体思路与主要创新点

本文的总体思路是，把"判断当前处于什么干扰场景"与"在该场景下选择哪个参数配置"这两类时间尺度截然不同的决策，从单一智能体中拆分开来，分别交由两个层次处理，并设计一个具有容错能力的接口把它们连接起来。

依此思路，本文的主要创新点有三，三者之间存在递进与协同关系。

创新点一：面向相干干扰的混合分层决策架构与时间尺度设计。本文受分层强化学习时间抽象思想启发，设置监督学习元策略控制器与深度强化学习执行器，并以 DAM 统一层间接口。双线程和配置缓冲区能够避免上层计算同步阻塞发射线程，但不能保证信息始终及时：当前端到端约 99.6 ms，高于 23.0 ms 元决策周期，仍存在策略陈旧与工程实时性问题。

**创新点二：基于 Double DQN 与门控循环单元的抗干扰策略执行层及其训练效率机制。** 以"单帧观测输入 \+ stateful 隐状态承载记忆"的网络结构获得时序感知能力；设计自适应分段激励的奖励函数与动态动作掩码机制以提升训练效率。该创新点确立了系统的性能基线与调控接口。

创新点三：基于场景语义特征与随机森林的元策略控制器及软引导协同机制。设计十二维场景语义特征，其中维度敏感性特征用于估计“哪个维度存在更大优化空间”；以 Q 值正偏置实现软引导，在不删除候选动作的前提下保留执行层纠错通道。需要强调，正偏置仍可能改变动作排序，因此不能据此推出“最坏情况下性能不低于纯 DRL”的理论保证。当前增量结果成立于使用逐配置仿真信息生成特征与初始化的 oracle 辅助实验设置，工程部署前还需以可在线观测特征重做训练与评估。

本文预期达到的性能指标如下。在密集干扰场景下，相比共用同一执行层权重的单层深度强化学习方案，系统级平均信干噪比提升 5 dB 量级、干扰避开率达到 90%；在训练分布之外的干扰密度下仍保持 2 dB 以上的领先；在干扰源集体跳频的非平稳场景下，恢复所需时间减少约三分之一。

## 2.1 FMCW 雷达基础

### 2.1.1 FMCW 雷达信号模型与解调

FMCW 雷达是指发射频率受特定信号调制的连续波雷达，其连续发射调频信号并接收目标反射的回波，通过对回波解调解算目标的距离与速度信息。FMCW 雷达系统如图 2-1 所示，雷达由波形发生器生成基带调制波形，经数模转换器（Digital-to-Analog Converter，DAC）与压控振荡器（Voltage-Controlled Oscillator，VCO）生成射频 FMCW 波形，该波形一路作为参考信号送至混频器，另一路经功率放大器（Power Amplifier，PA）放大后由发射天线发射。发射的电磁波遇到目标后被反射形成目标回波，由接收天线接收，经低噪声放大器（Low-Noise Amplifier，LNA）放大后与参考信号混频以完成解调（Dechirp），再通过低通滤波器（Low-Pass Filter，LPF）滤除有效探测范围之外的频率成分，得到拍频信号（Beat Signal）。拍频信号经模数转换器（Analog-to-Digital Converter，ADC）采样后进入数字信号处理流程，通过快速傅里叶变换（Fast Fourier Transform，FFT）与恒虚警率（Constant False Alarm Rate，CFAR）检测解算目标的距离与速度。
> 【图 2-1 FMCW 雷达系统框图】
图源：需新绘（发射器：波形发生器—DAC—VCO—PA—发射天线；接收器：接收天线—LNA—混频器—LPF—ADC—数字信号处理；VCO 输出同时作为参考信号引入混频器）   

FMCW 信号的频率随时间按预设规律变化，常见的调制波形有三角波、锯齿波与正弦波。本文采用锯齿波调制，如图 2-2 所示，其在一次扫频周期内频率由起始频率线性变化至终止频率，这样的一次扫频称为一个 chirp。相邻两个 chirp 之间通常留有一段空闲时间，一个 chirp 的扫频时长 T\_sw 与该空闲时长 T\_icd 之和称为 chirp 重复周期 T\_c，亦称脉冲重复间隔（Pulse Repetition Interval，PRI）。
> 【图 2-2 锯齿波调频的频率—时间示意图】
图源：提纲 2.1.1.2 相关示意（需补画 PRI、T\_sw、发射信号与接收信号的时频关系）   

不考虑幅度（此处及后续推导均默认信号为单位幅度）时，单个 chirp 内的参考信号可表示为

x\_T(t) = exp\{ j2π\[ f\_c·t \+ ½·K·(t − T\_sw/2)² \] \}, 0 ≤ t ≤ T\_sw (2-1)

其中 f\_c、K 与 T\_sw 分别表示中心频率、调频斜率与单个 chirp 的扫频时长，j 为虚数单位。则信号带宽为

B = K·T\_sw (2-2)

当最大探测距离 d\_max 确定后，目标回波相对参考信号的最大延迟时间为

τ\_max = 2·d\_max / c (2-3)

其中 c 为光速。Dechirp 处理之后所对应的最大拍频（Beat Frequency）为

f\_bmax = K·τ\_max (2-4)

本文仿真在 Dechirp 后采用截止频率为 f\_bmax 的理想低通模型。与参考信号频率差超过该阈值的分量在仿真中被置零；这一截断关系是本文时、频域参数调整机制的直接建模依据，但不是实际雷达抗干扰的唯一物理机制。实际系统还会受到滤波器过渡带、射频前端非线性、相位噪声与多径等因素影响。

设某点目标直接反射的回波信号为

x\_R(t) = exp\{ j2π\[ f\_c·(t − τ) \+ ½·K·(t − τ − T\_sw/2)² \] \}, τ ≤ t ≤ τ \+ T\_sw (2-5)

其中 τ 为该回波相对参考信号的延迟时间。若该目标与雷达的距离为 d，则由运动学关系可得

τ = 2d / c (2-6)

目标回波与参考信号做 Dechirp 后的信号为

x\_s(t) = x\_T(t)·conj\[x\_R(t)\] = exp\{ j2π\[ f\_c·τ \+ K·τ·(t − τ/2 − T\_sw/2) \] \}, τ ≤ t ≤ T\_sw (2-7)

其中 conj\[·\] 表示复共轭。该信号的频率，也即参考信号与目标回波的频率差为

Δf = d\[phase of x\_s(t)\] / dt = K·τ (2-8)

联立式(2-6)与式(2-8)，即可建立目标距离与拍频之间的关系

d = c·Δf / (2K) (2-9)

当 τ \< τ\_max，即 K·τ \< f\_bmax 时，该频率成分经低通滤波器后被保留至拍频信号中，故原理上可依据式(2-9)从拍频信号中解算目标距离。对于运动目标，其相对雷达的径向运动会引起多普勒频移，理论上可根据多普勒频率 f\_D 推算目标的相对径向速率

v = f\_D·c / (2·f\_c) (2-10)

然而实际中单个 chirp 的持续时间很短，多普勒频率在单个 chirp 的拍频信号中难以体现，需要多个 chirp 累积。如图 2-3 所示，FMCW 雷达通常连续发射 L 个 chirp 构成一帧（Frame），相邻两帧之间存在帧间间隔（Inter Frame Time），自当前帧起始时刻至下一帧起始时刻的时间称为帧周期（Frame Period）。雷达测量目标的距离与速度通常以一帧为操作单位。本文不额外设置帧间间隔，故帧周期为

T\_frame = L·T\_c = 128 × 60 μs = 7.68 ms (2-11)
> 【图 2-3 典型的帧结构示意图】
图源：需新绘（标注单帧内 L 个 chirp、帧间间隔与帧周期）   

设一帧内包含 L 个 chirp，则参考信号与接收信号可分别表示为各 chirp 信号之和

x\_T(t; L) = Σ\_\{l=1..L\} x\_T(t; l) (2-12)

x\_R(t; L) = Σ\_\{l=1..L\} x\_R(t; l) (2-13)

经 Dechirp 与低通滤波后的拍频信号为

x\_b(t; L) = Σ\_\{l=1..L\} \{ x\_T(t; l)·conj\[x\_R(t; l)\] \} ∗ h\_lp(t) (2-14)

其中 ∗ 表示卷积，h\_lp(t) 表示低通滤波器的冲激响应。此处称 t 这一维为快时间维，l 这一维为慢时间维。由快时间维的 FFT 结果可解算目标距离；而目标在快时间维对应峰值处的相位在慢时间维上的角频率 ω 则对应目标的相对径向速率

ω = 4π·v·T\_c·f\_c / c ⟹ v = ω·c / (4π·T\_c·f\_c) (2-15)

对拍频信号在快时间维与慢时间维各做一次 FFT，即得到距离多普勒图（Range-Doppler Map，RDM）。RDM 上的峰值位置对应可能的目标，再对 RDM 施加 CFAR 检测即可给出目标的距离与速率估计。

将表 2-3（见第 2.4.1 节）所列参数代入上述关系，可得本文雷达配置下的若干关键指标：每个 chirp 的 ADC 采样点数 N = f\_s·T\_sw = 1000；距离分辨力 ΔR = c/(2B) = 0.3 m，与最大探测距离 120 m 相对应的距离单元数为 400；由采样率决定的最大无模糊拍频为 f\_s/2 = 10 MHz，大于 f\_bmax = 8 MHz，满足奈奎斯特采样要求；速度分辨力 Δv = λ/(2·L·T\_c) ≈ 0.25 m/s，最大无模糊速度 v\_max = λ/(4·T\_c) ≈ 16.3 m/s，其中波长 λ = c/f\_c ≈ 3.91 mm。上列 v\_max ≈ 16.3 m/s 与后文 2.4.1 节中目标相对速度的取值范围 U(−16, 16) m/s 相匹配，仿真中所有目标的径向速度均落在雷达的无模糊测速范围之内，速度维观测因而有效。

本文以一帧作为决策单位：在一个时间步内固定中心频率与发射时延，接收完整一帧后由该帧 RDM 估计 SINR，并为下一帧选参。该设定能保留帧内各 chirp 的一致参数与慢时间处理条件，不会在帧内引入参数切换；但不能据此证明跨帧相干积累、检测概率、多普勒估计或工程波形连续性完全不受影响。“不牺牲目标检测性能”需用检测概率、虚警率和速度估计误差等指标另行验证。本文的 SINR 定义为

SINR = 10·log10( ‖x\_t‖² / ‖x\_i \+ n‖² ) (2-16)

其中 x\_t、x\_i 与 n 分别表示接收信号在经过 Dechirp 与低通滤波之后所残留的目标回波、干扰与噪声成分。本文假设接收信号的 SINR 可以被准确估计，其估计方法不在本文讨论范畴。

### 2.1.2 运动场景下的目标回波与干扰信号推导

实际中雷达的接收信号除了目标直接反射的回波，还包含多径反射回波、杂波以及其他汽车雷达的发射信号（即干扰）。汽车雷达间相互干扰的成因主要有两种：一种是**直接入射干扰**，即干扰雷达的发射信号直接射入受扰雷达的接收机；另一种是**反射干扰**，即干扰雷达的发射信号经其他物体反射后射入受扰雷达的接收机。本文在场景设定中专注于点目标的回波与直接入射干扰，不考虑反射干扰、多径效应与杂波。本节推导后续用于运动场景信号仿真的目标回波与干扰信号的解析形式。

#### 2.1.2.1 运动目标的回波信号推导

以一帧为单位，设单帧含 L 个 chirp，chirp 重复周期 T\_c = T\_sw \+ T\_icd，一帧的时间 t ∈ \[0, L·T\_c\]。设目标与雷达的初始距离为 R₀，目标相对雷达的径向速率为 v\_re = v\_target − v\_radar。此处假定在一帧时间内目标匀速运动，且目标相对雷达的距离与速率均在雷达的有效测量范围之内。则雷达与目标的距离为

R(t) = R₀ \+ v\_re·t (2-17)

接下来计算目标回波到达雷达接收机相对其对应发射信号的延迟时间 τ。以雷达为参考系，则目标的速率即为 v\_re。设雷达发射电磁波时与目标的距离为 R₁，电磁波自雷达发射至抵达目标用时 Δt₁；电磁波到达目标时目标与雷达的距离为 R₂，电磁波由目标反射后返回雷达用时 Δt₂。依据光速不变原理有

τ = Δt₁ \+ Δt₂， c·Δt₁ = R₂， c·Δt₂ = R₂， R₂ = R₁ \+ v\_re·Δt₁

联立可得

Δt₁ = Δt₂ = R₁ / (c − v\_re)， τ = 2·(R₁ \+ v\_re·Δt₁) / c = 2·R₁ / (c − v\_re) (2-18)

设目标回波在 t 时刻到达雷达，则发射该回波所对应信号的时刻为 t − τ(t)，故有 R₁ = R(t − τ(t)) = R₀ \+ v\_re·\[t − τ(t)\]。将其代入式(2-18)并整理，得

τ(t)·(c − v\_re) = 2·\[R₀ \+ v\_re·t − v\_re·τ(t)\]

⟹ τ(t) = 2·(R₀ \+ v\_re·t) / (c \+ v\_re) (2-19)

⟹ R₁ = (R₀ \+ v\_re·t)·(c − v\_re) / (c \+ v\_re) (2-20)

式(2-19)即为运动目标的回波相对参考信号的时变延迟。对延迟求导可得

τ′(t) = dτ(t)/dt = 2·v\_re / (c \+ v\_re)， 1 − τ′(t) = (c − v\_re) / (c \+ v\_re) (2-21)

对于第 k 个 chirp（1 ≤ k ≤ L），时间 t ∈ \[(k−1)T\_c, k·T\_c\]，记该 chirp 的起始时刻 t₀ = (k−1)·T\_c，则参考信号的频率为

f\_ref(t) = f\_c \+ K·\[t − t₀ − T\_sw/2\]， t₀ ≤ t ≤ t₀ \+ T\_sw； f\_ref(t) = 0，其他 (2-22)

实际中在 chirp 间空闲时间内，雷达参考信号的频率将回落至 (f\_c − ½·K·T\_sw)，由于雷达系统对该段时间的接收信号不作 ADC 采样，故此处作上述简化。现代 FMCW 雷达可以精确控制每个 chirp 的起始相位，在不考虑相位编码的情况下，本文认为每个 chirp 的起始相位保持一致，用固定值 φ₀ 表示。于是对于 t₀ ≤ t ≤ t₀ \+ T\_sw，参考信号的相位为

φ\_ref(t) = 2π·\[ (f\_c − ½·K·T\_sw)·(t − t₀) \+ ½·K·(t − t₀)² \] \+ φ₀ (2-23)

回波信号的相位由参考信号相位在时变延迟处取值并叠加反射相移得到

φ\_echo(t) = φ\_ref(t − τ(t)) \+ φ\_r
 = 2π·\[ (f\_c − ½·K·T\_sw)·(t − τ(t) − t₀) \+ ½·K·(t − τ(t) − t₀)² \] \+ φ₀ \+ φ\_r (2-24)

其中 φ\_r 为目标反射引起的相位改变。对相位求导并代入式(2-21)，得回波信号的频率

f\_echo(t) = \[1 − τ′(t)\]·\{ (f\_c − ½·K·T\_sw) \+ K·\[t − τ(t) − t₀\] \}
 = \[(c − v\_re)/(c \+ v\_re)\]·\{ (f\_c − ½·K·T\_sw) \+ K·\[t − τ(t) − t₀\] \} (2-25)

至此已得到运动场景下一帧内每个 chirp 的参考信号频率、目标回波相位与频率的解析形式。信号仿真时可直接依据解析式生成信号，并在 Dechirp 后的低通滤波环节直接依据 f\_ref(t) 与 f\_echo(t) 的差值作频率截断，以此实现理想低通滤波。若考虑直接生成拍频信号，则其相位为

φ\_beat(t) = φ\_ref(t) − φ\_echo(t)
 = 2π·\[ (f\_c − ½·K·T\_sw)·τ(t) \+ ½·K·τ(t)·(2t − τ(t) − 2t₀) \] (2-26)

对应的拍频为

f\_beat(t) = (1/2π)·dφ\_beat(t)/dt
 = \[2·v\_re/(c \+ v\_re)\]·\{ (f\_c − ½·K·T\_sw) \+ K·\[t − τ(t) − t₀\] \} \+ K·τ(t) (2-27)

仿真时将拍频超过低通滤波器截止频率 f\_bmax 的部分直接置零即可。式(2-27)右端两项的物理含义是清楚的：第二项 K·τ(t) 即式(2-8)所给出的距离对应拍频，第一项则是目标径向运动引起的多普勒贡献，二者共同确定 RDM 上目标峰值的位置。

#### 2.1.2.2 运动干扰源的干扰信号推导

由于干扰在时域上的扫频参数（如 PRI、chirp 间间隔等）与受扰雷达的参考信号并不一定一致（相干干扰一致，非相干干扰则差异较大），此处不以干扰信号的帧长作为仿真样本长度。若受扰雷达的一帧长度可以容纳的干扰 chirp 数为 (M − 1)，则将干扰信号的仿真样本补长为 M 个 chirp 的长度；仿真中先生成完整的 M 个 chirp 的信号，之后再依据延迟时间进行截断。

设干扰的中心频率为 f\_c^intf、调频斜率为 K\_intf、扫频时长为 T\_sw^intf、chirp 重复周期为 T\_c^intf。设干扰信号被受扰雷达接收到的起始时刻，相对于受扰雷达参考信号最近一个 chirp 起始时刻的延迟时间为 t\_d^intf(0)。该初始延迟时间实际由干扰源的相对距离与两部雷达的发射时间差共同决定：以受扰雷达为参考系，设干扰发射的起始时刻两部雷达的发射时间差为 τ\_transmit、干扰源的相对距离为 R^intf(0)，则

t\_d^intf(0) ≈ τ\_transmit \+ R^intf(0) / c (2-28)

本文对 t = 0 时刻之前发生的运动过程不作考察，故此处忽略雷达与干扰源在此之前的运动。仿真中该初始延迟将自给定范围内的均匀分布中采样得到。对于 t \> 0，设干扰源相对速度为 v\_re^intf = v\_intf − v\_radar，则

t\_d^intf(t) = τ\_transmit \+ R^intf(t)/c， R^intf(t) = R^intf(0) \+ v\_re^intf·t

整理得

t\_d^intf(t) = t\_d^intf(0) \+ v\_re^intf·t / c = t\_d^intf(0) \+ t\_doppler^intf(t) (2-29)

其中 t\_doppler^intf(t) = v\_re^intf·t/c 表示干扰源相对受扰雷达的运动所导致的附加时移。与式(2-19)相比，此处分母为 c 而非 (c \+ v\_re^intf)，因为干扰信号只经单程传播而非往返传播。仿真时，先将干扰仿真的时间序列补长至 M 个 chirp，然后计算 t\_doppler^intf(t)，再逐 chirp 地生成干扰在时频域与时域上的序列，最后按 t\_d^intf(0) 作整体平移。

以下给出时移前干扰样本的解析式，之后整体时移 t\_d^intf(0) 即可。对于干扰样本的第 k 个 chirp（1 ≤ k ≤ M），时间 t ∈ \[(k−1)·T\_c^intf, k·T\_c^intf\]，所发射的干扰信号频率为

f\_intf,tx(t) = f\_c^intf \+ K\_intf·\[ t − (k−1)·T\_c^intf − ½·T\_sw^intf \]，
 (k−1)·T\_c^intf ≤ t ≤ (k−1)·T\_c^intf \+ T\_sw^intf； 否则为 0 (2-30)

每一段扫频的起始相位以固定值 φ₁ 表示，则所发射的干扰信号相位为

φ\_intf,tx(t) = 2π·\[ (f\_c^intf − ½·K\_intf·T\_sw^intf)·(t − (k−1)·T\_c^intf) \+ ½·K\_intf·(t − (k−1)·T\_c^intf)² \] \+ φ₁ (2-31)

被受扰雷达接收到的干扰信号相位为发射相位在附加时移处的取值

φ\_intf,rx(t) = φ\_intf,tx( t − t\_doppler^intf(t) ) (2-32)

对相位求导，得接收到的干扰信号频率

f\_intf,rx(t) = \[1 − (t\_doppler^intf)′(t)\]·\{ (f\_c^intf − ½·K\_intf·T\_sw^intf) \+ K\_intf·\[ t − t\_doppler^intf(t) − (k−1)·T\_c^intf \] \} (2-33)

其中

1 − (t\_doppler^intf)′(t) = 1 − v\_re^intf / c (2-34)

至此，干扰信号仿真所需的频率与相位解析式亦已得到。式(2-22)～(2-27)与式(2-30)～(2-34)共同构成了 2.4.1 节仿真平台的信号级模型基础。

### 2.1.3 相干干扰的成因与危害

依据干扰雷达与受扰雷达发射信号波形参数的相似程度，FMCW 雷达间的相互干扰可分为相干干扰与非相干干扰。当两者的波形参数相同或非常接近时，雷达间的干扰为**相干干扰**；当两者波形参数差异较大时，则为**非相干干扰**。本文聚焦于相干干扰，即干扰源与受扰雷达具有相同的调频斜率 K 与脉冲重复周期 T\_c。

如图 2-4(a) 所示，在时频域上，相干干扰的频率—时间曲线与受扰雷达的参考信号及目标回波完全平行。当干扰的中心频率与受扰雷达参考信号相近，且二者的相对延迟时间很小时，干扰将全部进入受扰雷达的通带，形成窄带干扰。由式(2-33)可见，在 K\_intf = K 的条件下干扰的瞬时频率与参考信号保持恒定的频率差，Dechirp 之后该恒定频率差表现为一个单频分量，其在快时间维 FFT 之后聚集为一个尖锐的峰值，与真实目标回波在处理域上的样式完全一致。

更严重的是能量上的不对等。目标回波经历自雷达至目标再返回雷达的往返传播，其接收功率按雷达方程与距离的四次方成反比；而干扰信号自干扰雷达发射后仅经单程传播直接射入受扰雷达接收机，其接收功率与距离的平方成反比。因此在相当的距离上，干扰的接收功率通常远高于目标回波。二者叠加的后果是相干干扰极易在 RDM 及 CFAR 检测中形成强度很大的虚假目标，如图 2-5 所示；当干扰在距离维上与真实目标邻近时，其旁瓣亦可能掩盖真实目标而造成漏检。虚假目标会使后续的跟踪与决策模块对不存在的障碍物作出响应，在自动驾驶场景中可能触发不必要的紧急制动，构成直接的安全隐患。

高相干干扰可能在时域、频域、时频域或距离多普勒域中与目标回波高度相似，使仅依赖处理域样式差异的接收端分离方法面临困难。但这不等于接收端重建、联合估计、多通道或学习型方法在原理上全部无效。本文选择在发射中心频率与发射时延层面主动规避，是本文的研究范围与技术路线，而不是由上述现象推出的唯一方案。

### 2.1.4 时域与频域干扰避免机制

基于 2.1.1 节所给出的低通滤波器截止特性，本节说明两条使干扰无法进入拍频信号的机制。

**频域机制（调整中心频率）。** 如图 2-4(c) 所示，调整受扰雷达的中心频率 f\_c 可以增大干扰信号与参考信号之间的频率差，当该频率差大于低通滤波器截止频率 f\_bmax 时，干扰在时频域上落在受扰雷达通带之外，从而被滤除。该方法亦称频谱分配或频分复用，通常将一段共享频带划分为若干互不重叠的子带，每部雷达在每个时间单元内选取一个子带作为工作频带。该方法实现直接，但缺点亦显然：可用频谱资源有限，当同一区域内雷达数量较多时，为保证互不干扰需划分更多子带，而子带带宽的减小又会依据 ΔR = c/(2B) 削弱雷达的距离分辨力。

**时域机制（调整发射时延）。** 依据式(2-3)与式(2-4)所给出的 τ\_max 与 f\_bmax 的对应关系，若干扰接收信号与参考信号之间的相对延迟时间不落在 \[0, τ\_max\] 范围内，则该干扰与参考信号的频率差亦将大于 f\_bmax，Dechirp 后同样被低通滤波器滤除。如图 2-4(b) 所示，受扰雷达将发射信号延迟 t\_d 发出，即改变了发射信号与干扰之间的相对延迟，从而使干扰在 Dechirp 后被滤除。该方法亦称时分复用。为便于表述，本文设置一个参考时刻，雷达的发射时延 t\_d 与干扰的到达延迟 τ\_intf 均相对该参考时刻给出。

**联合机制。** 将中心频率与发射时延的调整结合，可缓解单一频域策略下频谱资源受限的问题：在频谱子带数量不变的前提下，时域维度提供了额外的自由度，使可用的“避干扰配置”数量由 n 增至 m·n。然而现有的联合时、频域方法多为合作式实现，需要额外的通信与计算资源来完成资源分配，这既降低了抗干扰的实时性，也可能引入通信系统与雷达系统之间的干扰。因此，本文提出**非合作式**的时、频域联合干扰避免策略：在每一帧发射之前，受扰雷达仅基于自身的状态——包括相对参考时刻的发射时延、当前中心频率以及从自身接收信号中感知到的干扰情况——决定下一帧的时域与频域参数，不与其他车辆交换任何信息。

据此，本文定义联合动作空间为

A = \{ (f\_c^(i), t\_d^(j)) \| i ∈ \{0,1,2\}, j ∈ \{0,1,2\} \} (2-35)

其中三个可选中心频点为 f\_c ∈ \{76.25, 76.75, 77.25\} GHz，相邻频点间隔 500 MHz 恰等于雷达带宽 B，故三个工作子带互不重叠；三个可选发射时延为 t\_d ∈ \{0, τ\_max, 2τ\_max\} = \{0, 0.8, 1.6\} μs。联合动作空间的规模为 3 × 3 = 9。

## 2.2 抗干扰策略的马尔可夫决策过程建模

### 2.2.1 马尔可夫决策过程

马尔可夫决策过程（Markov Decision Process，MDP）为“以交互式学习实现目标”这一类问题提供了形式化的描述框架。在该框架中，学习者与决策者被统称为智能体（Agent），智能体以外所有与之交互的事物被称为环境（Environment）。如图 2-7 所示，二者持续交互：智能体选择动作，环境对动作作出响应并向智能体呈现新的状态，同时给出一个数值化的收益（亦称奖励）；智能体选择动作的目标即为最大化累积收益。
> 【图 2-7 智能体—环境交互示意图】
图源：需新绘（智能体与环境两个方框，状态 s\_t、奖励 r\_t 自环境指向智能体，动作 a\_t 自智能体指向环境）   

一般地，一个马尔可夫决策过程可用五元组 ⟨S, A, p, r, γ⟩ 描述：S 表示状态空间（State Space），A 表示动作空间（Action Space），p 表示状态转移概率函数（Transition Probability Function），r 表示奖励函数（Reward Function），γ 表示未来回报的折扣率（Discount Rate）。

对于一系列离散时刻 t = 0, 1, 2, …，在每个时间步 t 上智能体通过观测更新环境状态的某种表征 s\_t ∈ S，并基于该状态选择一个动作 a\_t ∈ A(s\_t)（A(s) 表示状态 s 下可用的动作集合；当所有状态的可用动作集合相同时可简记为 A）。在下一个时间步，作为该动作的结果，智能体收到数值奖励 r\_\{t\+1\} ∈ ℝ，同时观测到新的状态 s\_\{t\+1\}。如此持续交互，得到一条轨迹（Trajectory）

s₀, a₀, r₁, s₁, a₁, r₂, s₂, a₂, r₃, s₃, … (2-36)

其中任意一组 (s\_t, a\_t, r\_\{t\+1\}, s\_\{t\+1\}) 称为一次转移（Transition）。奖励 r\_\{t\+1\} 与后继状态 s\_\{t\+1\} 均可视为随机变量，它们服从的概率分布只依赖于前继状态 s\_t 与动作 a\_t，即对任意 s, s′ ∈ S，a ∈ A(s)，r ∈ ℝ 有

p(s′, r \| s, a) = Pr\{ s\_\{t\+1\} = s′, r\_\{t\+1\} = r \| s\_t = s, a\_t = a \}
 = Pr\{ s\_\{t\+1\} = s′, r\_\{t\+1\} = r \| s\_t = s, a\_t = a, s\_\{t−1\}, a\_\{t−1\}, …, s₀, a₀ \} (2-37)

上式既是状态转移概率函数 p 的定义，也给出了 MDP 的马尔可夫性：后继状态与奖励的分布只由当前状态与动作决定，与更早的历史无关。p 由此完全刻画了环境的动态特性。将 p 对奖励求和可得三参数形式

p(s′ \| s, a) = Pr\{ s\_\{t\+1\} = s′ \| s\_t = s, a\_t = a \} = Σ\_r p(s′, r \| s, a) (2-38)

奖励函数的“状态—动作—后继状态”三参数表示为

r(s, a, s′) = E\[ r\_\{t\+1\} \| s\_t = s, a\_t = a, s\_\{t\+1\} = s′ \] = Σ\_r r·p(s′, r \| s, a) / p(s′ \| s, a) (2-39)

当 s、a、r 的取值不可数时，将上述求和替换为相应的定积分即可。

对于式(2-36)所描述的轨迹，给定终止时刻 t\_∞，自时刻 t 之后所获得的累积回报可表示为奖励之和

G\_t = r\_\{t\+1\} \+ r\_\{t\+2\} \+ … \+ r\_\{t\_∞\} (2-40)

对于具有自然终止状态的任务（如一盘对弈或一次走迷宫），终止时刻显而易见，所得轨迹称为一幕（Episode），此类任务称为分幕式任务，其 t\_∞ 有限。然而有些任务不能自然地划分为独立的幕，而是持续不断地进行，称为持续式任务；此时 t\_∞ → ∞，G\_t 可能趋于无穷。为此引入折扣率 γ ∈ \[0, 1\] 对未来回报作折扣

G\_t = Σ\_\{k=0..t\_∞−t−1\} γ^k·r\_\{t\+k\+1\} = r\_\{t\+1\} \+ γ·G\_\{t\+1\} (2-41)

设 \|r\_t\| 的上界为 r\_sup，则

\|G\_t\| ≤ Σ\_\{k=0..∞\} γ^k·r\_sup = r\_sup / (1 − γ) (2-42)

故对 t\_∞ → ∞ 的情况，只需取 γ \< 1 即可保证折扣后的累积回报有界。γ 的大小表示未来收益对当前动作的重要程度：γ 越大则越重视长期收益；当 γ = 0 时智能体只考虑当前动作的即时奖励。

智能体自状态到动作（或到各动作选择概率）的映射称为策略（Policy），记为 π。对确定性策略，策略直接给出当前状态下所选的动作

a\_t = π(s\_t) (2-43)

对随机策略，则给出该状态下动作的概率分布

π(a \| s) = p(a\_t = a \| s\_t = s) (2-44)

并自该分布中采样具体动作。将智能体在执行策略 π 时于状态 s 下采取动作 a 的价值记为 q\_π(s, a)，称为状态—动作价值函数，它表示依据策略 π 自状态 s 出发、执行动作 a 之后所有可能轨迹的期望回报

q\_π(s, a) = E\_π\[ G\_t \| s\_t = s, a\_t = a \]
 = Σ\_\{s′∈S\} p(s′ \| s, a)·\{ r(s, a, s′) \+ γ·E\_π\[ G\_\{t\+1\} \| s\_\{t\+1\} = s′ \] \} (2-45)

为最大化累积回报需要找到最优策略。最优策略可能不唯一，但它们共享同一个最优状态—动作价值函数

q\_\*(s, a) = max\_π q\_π(s, a) (2-46)

从而将“最大化累积回报”转化为“求解最优状态—动作价值函数”这一等价问题。

### 2.2.2 干扰避免的马尔可夫决策过程建模

本节将 2.1.4 节所提出的非合作式时、频域联合干扰避免策略的执行过程建模为 MDP。依据 2.1.1 节的说明，MDP 的一个时间步对应雷达的一帧，时长 7.68 ms，即在每个时间步内雷达以当前参数发射并接收一帧信号、由该帧 RDM 估计 SINR，并据此决定下一帧所使用的参数。

记雷达的可调参数组合为参数状态 s\_param = \[f\_c, t\_d\]，所有参数状态的集合记为 S\_param。动作定义为参数状态之间的切换，即 a: s\_param → s′\_param，s\_param, s′\_param ∈ S\_param。本章中频域状态与时域状态均离散化，若给定 n 个可用频域状态与 m 个可用时域状态，则 \|S\_param\| = m·n；由于动作直接以“切换至哪一个参数状态”来定义（而非以“相对当前状态如何变化”来定义），故动作空间大小亦为 \|A\| = m·n = 9，而不是 (m·n)²。动作索引 a ∈ \{0, 1, …, 8\} 与参数状态的映射关系为

f\_c 的索引 = ⌊a / 3⌋， t\_d 的索引 = a mod 3 (2-47)

为便于神经网络学习，参数状态以独热（one-hot）编码表示，各参数状态的编号与编码列于表 2-1。采用独热编码而非直接使用标量索引的原因在于：频点与时延的索引之间不存在有意义的序关系与距离关系，若以标量输入会向网络引入虚假的数值序结构。

其中 onehot(a(t−1)) 为上一帧动作的 9 维独热编码，SINR(t) 为当前帧由 RDM 估计得到的标量，两者合计 10 维。该定义与第 3.2.3.3 节的网络输入及专利说明书所列动作通道、SINR 通道保持一致，不再把上一帧奖励 r(t−1) 重复作为输入；奖励已经由动作与当前 SINR 确定，额外输入会造成状态定义与实现维度不一致。

即时奖励由信号质量奖励 r\_S 与动作切换代价奖励 r\_AC 两部分构成

r\_t = r\_S \+ r\_AC (2-49)

其中 r\_S 依据当前 SINR 计算，用于激励智能体避开干扰；r\_AC 依据本帧相对上一帧的参数切换次数计算，用于抑制不必要的参数抖动。定义动作代价（Action Cost，AC）为

AC = 频域切换次数 \+ 时域切换次数 ∈ \{0, 1, 2\} (2-50)

即 AC = 0 表示 f\_c 与 t\_d 均未改变，AC = 1 表示二者之一改变，AC = 2 表示二者均改变。实际中动作代价亦可依据实现该切换的复杂度或硬件负担来设定。两部分奖励的具体分段形式与权重设置涉及执行层的训练效率设计，将在第 3.3.1 节详细给出，此处不再展开。

本文场景中每一幕开始时对目标与干扰作随机初始化，且干扰源在幕内持续相对运动，因此显式的状态转移概率函数 p 难以获得。所幸后文所采用的时序差分类强化学习算法属于无模型（Model-Free）方法，无需显式的状态转移概率，故本文在 MDP 建模中不再讨论 p，相关论证见第 3.2.2 节。折扣率取 γ = 0.95，其取值依据将在第 3.2.4 节说明。

### 2.2.3 部分可观测性与时序扩展状态

为不增加额外的硬件要求，雷达在每个时间步只能感知当前通带之内的干扰情况，即只能获得一个标量 SINR，而无法直接观测到干扰源在频域与时域上的完整分布。这使得式(2-48)所定义的基础状态并不满足马尔可夫性：同一个基础状态可能对应完全不同的真实干扰分布，其最优动作也就不同。因此，本文的抗干扰问题实质上是一个部分可观测马尔可夫决策过程（Partially Observable Markov Decision Process，POMDP）。

处理部分可观测性的一般思路是以历史观测序列近似真实状态。为此，本文将基础状态在时间上扩展，将最近 k 步的基础状态级联为时序扩展状态

h\_t = GRU(s\_t, h\_\{t−1\}) (2-51)

本文采用“单步观测 \+ 循环隐状态”的实现路径：每帧输入式(2-48)的 10 维观测，历史信息由隐状态 h\_t 在幕内递推承载，并在每幕开始时重置。因此，原稿中固定 k = 20、再把最近 k 步状态显式级联为 ℝ^\{k×3\} 的表述与网络实现不一致，现予删除；记忆范围由训练时的序列长度、隐状态初始化与截断反向传播设置共同决定，不能仅用 k = 20 概括。

循环网络与经验回放结合时必须保持时序对应关系：训练批次应由连续序列组成，并在序列起点重置或正确恢复隐状态；若从经验池随机抽取彼此独立的单步转移，却继续沿用 stateful 隐状态，则 h\_t 与样本历史不匹配，训练结论不成立。当前正文缺少这部分实现证据，需以代码确认回放单元、序列长度、burn-in、隐状态重置方式及目标网络输入。完成核对前，第三章关于 GRU 时序收益的因果解释应视为待确认。

## 2.3 基于分层强化学习的抗干扰决策系统架构设计

### 2.3.1 分层强化学习理论基础

标准强化学习将决策视为在单一时间粒度上的平坦（Flat）序贯过程：智能体在每个时间步观测状态、选择原子动作、接收奖励。当任务的时间跨度较长、奖励较为稀疏，或环境中同时存在多个时间尺度上的规律时，平坦结构会暴露出三个困难。首先是探索效率低下，智能体需要在原子动作空间中通过随机试探才能偶然发现有价值的长序列行为。其次是信用分配困难，一个决策的后果可能在许多步之后才显现，时序差分的自举传播需要大量样本才能把回报正确地归因到当初的决策上。最后是知识难以复用，在一种情形下学到的行为片段无法作为整体迁移到另一情形。

分层强化学习（Hierarchical Reinforcement Learning，HRL）通过引入**时间抽象**（Temporal Abstraction）来缓解上述困难：将决策过程分解为若干层，高层以较粗的时间粒度选择“做哪一类事”，低层以原子时间粒度选择“具体怎么做”。这样，高层的一次决策对应低层的多步动作，高层所面对的等效决策序列被显著缩短，其探索与信用分配的难度随之下降。

HRL 最具代表性的形式化是选项（Option）框架。一个选项定义为三元组

ω = ⟨ I\_ω, π\_ω, β\_ω ⟩ (2-52)

其中 I\_ω ⊆ S 为该选项的初始集合，即在哪些状态下允许启用该选项；π\_ω 为该选项的内部策略，即启用之后在原子动作空间中如何行动；β\_ω: S → \[0,1\] 为终止条件，给出在各状态下结束该选项的概率。引入选项后，高层在选项集合 Ω 上作决策，而每个选项一旦启用便持续若干个原子时间步直至终止。由于选项的持续时长不固定，高层所面对的决策过程不再是标准 MDP，而是**半马尔可夫决策过程**（Semi-Markov Decision Process，SMDP）。在 SMDP 上，高层的价值函数更新需要对选项执行期间的多步折扣回报作累加

Q(s, ω) ← Q(s, ω) \+ β·\[ Σ\_\{i=0..κ−1\} γ^i·r\_\{t\+i\+1\} \+ γ^κ·max\_\{ω′\} Q(s\_\{t\+κ\}, ω′) − Q(s, ω) \] (2-53)

其中 κ 为该选项本次实际执行的时间步数，β 为学习率。将式(2-53)与标准的 Q-Learning 更新式（即第 3.2.2 节的式(3-2)与式(3-3)）相比可以看出，标准 Q-Learning 只累加一步即时奖励且后继价值的折扣因子为 γ，而 SMDP 上的更新需累加选项执行期间的 κ 步折扣奖励，且后继价值的折扣因子为 γ^κ。折扣因子的指数由 1 变为 κ，这正是时间抽象在数学形式上的表现。此后，研究者进一步提出了将高层目标以状态子目标形式下发的 FeUdal 结构、以及可端到端学习选项内部策略与终止条件的 option-critic 等方法，使分层结构的构造由人工设计逐步走向自动学习。

本文的抗干扰问题适合分层处理，根据在于问题本身存在客观的时间尺度分离结构。抗干扰决策中同时存在两类性质不同的判断：
- **战术尺度（单帧，7.68 ms）**：在每一帧内，瞬时 SINR 由当前所采用的 (f\_c, t\_d) 配置直接决定。一旦干扰进入通带，SINR 立即恶化；一旦换到干净的配置，SINR 立即改善。这类因果关系是即时的、局部的，要求以帧为粒度快速响应。
- **战略尺度（数十帧，数百毫秒）**：干扰源的分布模式（例如“三个干扰源在频域上聚集而时域相对稀疏”还是“五个干扰源在时域上密集分布”）是由多个干扰车辆的相对位置、相对速度与各自的发射时序共同决定的统计特征。这类特征只有在数十帧的跨度上累积足够的观测之后才呈现稳定形态。以本文的窗口设置 W = 50 帧为例，其时间跨度为 384 ms，与单帧 7.68 ms 相差约 50 倍。

单帧观测适合快速响应，窗口统计适合提取慢变特征，这一差异为分层设计提供了动机，但并不能证明单一决策器“无法”同时处理两个尺度。循环网络、注意力或多时间尺度状态编码也可能在单一策略中同时建模快慢信息。本文采用两层结构是一项可解释性与模块化取舍，其必要性和相对优势须通过与具备同等时序建模能力的单层基线比较。

单帧与窗口尺度的差异说明该问题具有进行分层设计的可能性，但不能仅凭车辆位移推出干扰配置会在一幕内显著改变。以相对速度 32 m/s、30 帧计，车辆约移动 7.4 m；按直接入射单程传播计算，到达延迟变化约 24.6 ns，仅为 τ\_max = 0.8 μs 的约 3.1%。该变化是否足以使干扰跨越通带边界取决于其初始位置，不能一概而论。因此，本文把时间尺度分离作为待实验验证的架构假设；第四章 Exp-D 通过人为设定的集体跳频事件检验突变场景下的恢复能力，而不以正常车辆运动本身证明快速非平稳性。

本文的两层结构与经典 HRL 存在本质差别：高层不是通过强化学习学习选项价值或终止条件，而是依据仿真 oracle 生成的标签训练随机森林分类器；只有执行层采用强化学习。因此，严格来说，本文属于“借鉴 HRL 时间抽象思想的监督学习 \+ 强化学习混合分层架构”，而不是高、低两层均由强化学习端到端训练的标准 HRL。保留“分层强化学习”这一题名时，正文需始终明确这一边界。选择轻量分类器的原因是当前任务为固定三分类且需要可检查的特征贡献；端到端训练高层策略以及消除 oracle 标签依赖留待后续研究。

执行层（战术层）以帧为粒度运行，在每一帧内完成“发射—接收—Dechirp—RDM—SINR 估计—状态更新—动作选择”的完整闭环（详见第 3.2.1 节），输出下一帧所使用的参数状态 (f\_c, t\_d)。其决策依据是式(2-48)所定义的基础状态及由 GRU 隐状态所承载的历史记忆，优化目标是式(2-49)所定义的即时奖励的折扣累积。执行层不感知干扰源的数量、分布等场景级信息，只对自身观测到的 SINR 序列作出反应。

元策略层（战略层）以 K 帧为决策周期运行，在每个决策周期内自最近 W 帧的 SINR 序列与动作记录中提取场景语义特征，判别当前所处的干扰场景类型，并输出三种元策略标签之一（频域优先、时域优先、联合探索）及相应的置信度。元策略层不直接选择 (f\_c, t\_d)，而只规定执行层应当在哪个维度上重点搜索。

DAM 是两层之间唯一的接口契约。两层只通过 DAM 交换信息，且交换的内容被严格限定：元策略层向下只输出“策略标签 \+ 置信度”这一对量，DAM 将其转换为一个长度为 \|A\| = 9 的 Q 值偏置向量，执行层向上只消费该偏置向量，并将其叠加至自身网络输出的原始 Q 值之上。形式化地，设执行层网络输出的原始动作价值为 Q(S\_t, a)，元策略层输出的标签为 ℓ ∈ \{freq\_only, time\_only, joint\}、置信度为 p ∈ \[0, 1\]，则执行层实际用于动作选择的价值为

Q̃(S\_t, a) = Q(S\_t, a) \+ bonus(a; ℓ, p)， a ∈ A (2-54)

其中 bonus(·) 的具体形式将在第 4.1.3 节给出。该设计的作用有三个方面。

其一是层间解耦。执行层无需感知偏置向量的来源，元策略层的具体实现方式因而可以自由替换：本文采用随机森林，原则上亦可替换为任何分类器乃至大语言模型，而不需要对执行层作任何修改，更不需要重新训练执行层网络。第三章与第四章的工作由此可以独立开展、独立验证。

其二是训练与推理的形式统一。DAM 在训练阶段用于将单维度智能体的动作空间裁剪至相应子空间，在推理阶段用于承载元策略的下发指令，二者使用同一套接口机制（详见第 3.3.2 节），避免了训练与推理之间的实现分歧。

其三是容错性可控。偏置叠加在原始 Q 值之上而非替换原始 Q 值，元策略层的错误判断只会改变各动作之间的相对优势，不会将任何动作从候选集合中彻底排除；偏置幅度还可通过置信度连续调节。这一性质是第 4.1.3 节所述软引导机制的基础，也是本架构在分类器误判率约 15%～20% 的条件下仍不发生性能退化的原因。

### 2.3.3 异步协同与低延迟控制机制

2.3.1 节自问题性质出发论证了分层的必要性。在系统实现层面，两层的时间尺度分离还带来一个具体的工程矛盾：执行层必须在一帧（7.68 ms）之内完成动作选择，否则雷达无法按时发射下一帧；而元策略层需要完成 12 维特征提取与分类器推理，其耗时并不天然地小于帧周期。若采用同步实现，即执行层在每个决策周期到来时阻塞等待元策略层返回结果，则一旦元策略层的推理耗时超过帧周期，雷达的发射时序即被破坏。

为此，本文采用双线程非阻塞的异步协同机制，如图 2-9 所示。执行层与元策略层运行于两个独立的执行线程：
- **执行线程**按帧周期严格定时运行，每帧读取一次配置缓冲区中的当前偏置向量，与自身网络输出叠加后选择动作并发射，全程不等待元策略层；
- **元策略线程**按 K 帧的决策周期被触发，自共享的观测历史缓冲区中读取最近 W 帧的 SINR 与动作记录，完成特征提取与分类器推理，将新的策略标签与置信度换算为偏置向量后写入配置缓冲区。

两个线程通过配置缓冲区解耦。实现时必须保证执行线程读取到的是一份完整快照，可采用不可变对象的原子引用替换，或用极短临界区完成加锁读写；不能在缺少并发语义证明的情况下直接声称“无锁读取”必然安全。若元策略线程未在当前周期内完成，执行线程继续使用上一份完整偏置向量，使控制循环不因等待上层结果而阻塞。该设计只能保证控制流连续，不能保证过期偏置不会降低性能；过期时间及其影响仍需在目标运行平台上测试。

本文设置的帧周期为 7.68 ms，元策略每 K = 3 帧触发一次，因此名义决策周期为 3 × 7.68 = 23.04 ms（文中取 23.0 ms）；最小策略保持时间为 5 帧，即 38.4 ms。三者描述的是执行、判别与切换约束，不能据此推出元策略结果一定能在一个周期内更新：当前端到端实测约 99.6 ms，已超过 23.0 ms，异步实现只是不阻塞执行线程，实际生效时延仍需如实计入。

### 2.4.1 仿真平台搭建与动态干扰建模

本文的仿真平台工作在信号级：不直接生成“目标已被检测到”的抽象观测，而是依据 2.1.2 节所推导的解析式逐 chirp 地生成射频信号，并完整走通雷达的信号处理链路。每一帧的仿真流程如下：
1. 场景初始化（每幕开始时执行一次）：依据表 2-4 所给定的分布随机生成若干点目标与干扰源，确定各自的幅度、距离（或到达延迟）、相对速度与反射相位；
2. 信号生成：依据式(2-22)～(2-25)逐 chirp 地生成参考信号与各目标回波，依据式(2-30)～(2-34)生成各干扰信号并按各自的 t\_d^intf(0) 作整体时移，将所有目标回波与干扰按幅度加权叠加；
3. 加噪：向接收信号加入加性高斯白噪声以模拟雷达系统噪声，噪声等级依表 2-4 所列 SNR 确定；
4. 解调与滤波：将接收信号与参考信号混频完成 Dechirp，并依据 f\_ref(t) 与各分量瞬时频率之差作理想低通滤波，即将频率差超过 f\_bmax 的成分直接置零；
5. 距离多普勒处理：对拍频信号在快时间维与慢时间维各作一次 FFT 得到 RDM；
6. SINR 估计与指标统计：依据式(2-16)由 RDM 上目标分量与干扰噪声分量的能量之比估计本帧 SINR，并统计本帧的干扰重叠情况等信息，作为强化学习的观测与奖励依据。

### 2.4.2 性能评估指标设计

为刻画抗干扰策略在稳态性能、鲁棒性、资源代价、收敛速度与非平稳适应能力五个维度上的表现，本文定义如下六项评估指标，第三、四章共用这一套定义。

**（1）平均 SINR 及其标准差。** 对测试中所有幕的所有帧求 SINR 的均值与标准差。均值反映策略的稳态抗干扰性能；标准差反映策略在不同干扰分布下性能的一致性，标准差大意味着策略的表现依赖于干扰恰好落在何处，带有较强的偶然性。

**（2）避开率。** 定义为一幕之内 SINR 大于 0 dB 的帧数占总帧数的比例

r\_avoid = ( SINR \> 0 的帧数 ) / ( 总帧数 ) (2-57)

由于 SINR = 0 dB 意味着目标能量与干扰噪声能量相当，该阈值可近似视为目标可被稳定检测的临界条件，故避开率直接反映策略完全避开干扰的能力。平均 SINR 与避开率共同使用可以区分两类不同的失效：避开率高而平均 SINR 不高，说明策略能避开干扰但未能优选最干净的配置；避开率低而平均 SINR 尚可，说明策略在无法完全避开时能够避重就轻，优先避开强度大的干扰。

**（3）动作代价总和。** 对一幕之内各帧的动作代价（式(2-50)）求和，反映策略实施所需的参数切换开销。该指标衡量的是抗干扰增益的成本：频繁的参数切换会带来硬件负担（如锁相环重新锁定的时间开销），也会使雷达输出的距离—速度估计在帧间缺乏一致性，不利于后续的目标跟踪。

**（4）T80 收敛帧数。** 定义为自一幕开始至 SINR 首次达到该幕最终稳态 SINR 的 80% 所需的帧数，反映策略面对新的干扰分布时的收敛速度。该指标对性能本身很差的方案不具备可比性：若某方案全程维持在低水平，其最终稳态值本身很低，达到该低值的 80% 自然很快，T80 反而显得很小。因此使用该指标时必须与平均 SINR 联合解读，本文在 4.4.2 节报告固定参数基线的 T80 时将明确指出这一点。

**（5）早期 AUC。** 定义为一幕前 10 帧的 SINR 时序曲线下面积，即

AUC\_early = Σ\_\{n=1..10\} SINR(t\_n) (2-58)

该指标是对收敛速度的另一种度量，相比 T80 的优势在于它同时反映了上升速度与上升过程中的累积收益，且不依赖于最终稳态值这一需要事后确定的量，因而对不同性能水平的方案具有更好的可比性。

**（6）跳频恢复帧数。** 用于非平稳场景的专项评估。在一幕的中途令全部干扰源同时重新分配其中心频点，记录自该扰动发生至 SINR 恢复到扰动前稳态水平所需的帧数。该指标直接刻画策略对干扰模式突变的适应能力，是第四章 Exp-D 实验的核心指标。

## 2.5 本章小结

本章完成了面向相干干扰的雷达抗干扰分层决策系统的建模与架构设计，主要工作包括四个方面。

其一，建立了 FMCW 雷达与干扰的仿真模型，给出参考信号、目标回波、拍频信号以及运动场景下时变延迟、相位与频率的表达。在本文采用理想 LPF 的仿真模型中，超出截止频率的差频成分被滤除，这为时、频域参数调整提供了一个关键机理；该结论依赖理想滤波与信号模型。高相干干扰使仅依赖样式差异的接收端处理更困难，但不能推出全部接收端方法失效或发射参数调整是唯一方案。

其二，以帧为单位设置决策粒度。帧内中心频率与发射时延保持不变，有助于维持该帧慢时间处理的一致条件；SINR 由该帧 RDM 估计。当前材料尚未以检测概率、虚警率、多普勒误差或跨帧处理实验验证参数切换不影响目标检测，因此不再使用“不牺牲目标检测性能”的结论。

其三，将抗干扰策略的执行过程建模为部分可观测马尔可夫决策过程。给出了状态、动作与奖励的设定；论证了由于雷达只能感知当前通带内的标量 SINR、无法直接观测干扰的完整时频分布，问题实质上是 POMDP，并据此引入时序扩展状态以历史观测近似真实状态。

其四，构造监督学习元策略控制器与深度强化学习执行器组成的混合分层架构，并以 DAM 统一策略标签到动作偏置的接口。该接口降低了模块耦合，但不意味着两层在数据、时序和性能上完全独立，也不能仅凭接口形式证明上层可自由替换。双线程与缓冲区可避免同步阻塞发射线程；然而当前端到端约 99.6 ms 高于 23.0 ms 元决策周期，仍存在策略陈旧与工程实时性问题。

本章所建立的模型、架构与仿真平台是后续两章工作的共同基础。第三章将实现并优化其中的深度强化学习执行层，第四章将实现并优化其中的元策略控制器。

# 第三章 基于深度强化学习的抗干扰策略执行层优化

本章实现第二章架构中的深度强化学习执行层，给出逐帧闭环、算法选型、Double DQN、GRU 网络、奖励与动作约束，并在场景 A 的受控仿真样本上比较联合、单维度与固定参数方案。实验结果用于描述当前实现的样本性能；GRU 的连续序列回放与隐状态处理仍需代码核对，多随机种子、置信区间和更完整消融尚未补齐，因此本章不把现有数字表述为统计显著或工程有效性证明。

## 3.1 抗干扰策略执行层的优化目标

第二章 2.3.2 节已界定了两层架构的职责边界：元策略层判断"当前处于什么干扰场景、应当在哪个维度上重点搜索"，执行层则负责"在给定的动作子空间内尽快找到最优的 (f\_c, t\_d) 配置并稳定维持"。本章的全部工作都服务于后一个问题。执行层的设计必须在不依赖元策略层的条件下独立成立。一方面，这是分层架构可分阶段验证的前提；另一方面，依据 2.3.2 节所述的容错性质，当元策略层判别失准或尚未启用时，系统的行为退化为纯执行层的行为，执行层自身的性能水平因而决定了整个系统的性能下界。

据此，本章的优化目标可以拆解为两点。

**其一，环境感知能力。** 依据 2.2.3 节的分析，雷达在每一帧只能观测到一个标量 SINR，无法直接获知干扰源在时、频域上的分布。这意味着若智能体仅对当前帧的 SINR 数值作出反应，其决策必然是盲目的：同一个 SINR 数值既可能出现在"干扰分布稀疏、只是恰好当前配置被占用"的情形下，也可能出现在"干扰密集、所有配置都不理想"的情形下，而这两种情形的最优动作截然不同。因此执行层必须能够从 SINR 的时间序列中推断干扰分布结构。例如，若连续数帧内无论如何切换频点 SINR 都很低，则可推断频域已被大量占用；若某次切换时延后 SINR 显著改善，则可推断时域尚有余量。本章通过门控循环单元对观测序列建模来获得这一能力。

**其二，样本学习效率。** 本文的联合动作空间规模为 9，绝对数值不大，但强化学习所面对的困难并不只在于动作空间的规模：由于每一幕开始时目标与干扰均被随机初始化，同一个状态在不同幕中所对应的最优动作可以完全不同，采样数据的方差很大，训练过程因而既缓慢又不稳定。为此需要在探索策略、奖励设计、目标值计算与优化过程等多个环节采取措施，使智能体能在有限的交互帧数内收敛到近最优策略，并且收敛后的策略表现稳定、不发生持续抖动。

执行层的输出为每一帧所使用的参数状态索引 a ∈ \{0, 1, …, 8\}，其向上层提供的接口为第 3.3.2 节所定义的动作掩码接口：上层通过下发 Q 值偏置向量对执行层实施策略级调控，而执行层的网络结构、训练方式与推理流程均不因上层是否存在而改变。

**① 发射。** 以当前参数状态 (f\_c, t\_d) 发射一帧 FMCW 信号，该帧含 L = 128 个 chirp，帧内参数保持不变。

**② 接收与解调。** 接收由目标回波、干扰信号与噪声叠加构成的混合信号，与参考信号混频完成 Dechirp，再经低通滤波得到拍频信号。依据 2.1.4 节的机制，凡与参考信号频率差超过 f\_bmax 的干扰成分在此环节即被滤除，不进入后续处理。

### 3.2.2 从 Q-Learning 到 Double Q-Learning

#### 3.2.2.1 强化学习算法的选型

依据 2.2.1 节的分析，求解最优策略可以转化为求解式(2-46)所定义的最优状态—动作价值函数 q\_*(s, a)。一般而言，求解 q\_* 有三类方法：动态规划法、蒙特卡洛法与时序差分法。

**动态规划法**属于基于模型（Model-Based）的方法，它需要完整的状态转移概率分布，通过迭代求解贝尔曼最优方程组得到 q\_\*。**蒙特卡洛法**与**时序差分法**（Temporal Difference，TD）均属于无模型（Model-Free）方法，二者不需要显式的状态转移概率，而是直接从与环境交互所采集的样本中学习。其区别在于：蒙特卡洛法需要完整的采样轨迹来更新价值估计，这要求每一幕都有明确的终止状态；而时序差分法只需一步转移即可利用自举（Bootstrap）进行更新。

本文选择时序差分法是工程取舍，而非“场景决定只能如此”。动态规划通常依赖已知或可求的转移模型，本文难以满足；蒙特卡洛方法可以通过有限幕截断、平均回报等方式处理持续任务，并非原理上不可用，但其更新要等待完整轨迹、样本利用方式与本文的逐步在线更新目标不匹配。因此，本章采用可逐步自举、适合与经验回放结合的时序差分方法。

在时序差分方法中，可按行为策略与目标策略是否相同区分为同策略（On-Policy）与异策略（Off-Policy）方法。“Off-Policy”不应译为“离线策略”，因为离线强化学习（Offline RL）特指仅使用固定数据集、训练期间不再与环境交互的另一类问题。Q-Learning 属于异策略方法：行为策略可用 ε-贪心采样，而更新目标使用贪心动作。异策略方法能够配合经验回放重复利用历史转移，但重复利用并非没有代价，仍需关注分布偏移、函数逼近与自举共同导致的不稳定性；同策略方法也不等同于“样本只能使用一次”，不能以此作为排除依据。

综合而言，本章的选择依据可归纳为四点：状态转移模型未知，因而采用无模型方法；任务虽持续运行，但训练以有限幕截断，采用时序差分自举更便于逐步更新；希望通过经验回放提高样本利用率，因而选择异策略方法；动作空间离散且规模较小，适合采用基于动作价值的方法。在这些条件下，本文选择 Q-Learning 族算法，并用深度神经网络近似动作价值函数。该选择是工程取舍，不表示蒙特卡洛法、同策略算法或策略梯度方法在原理上不可用。

#### 3.2.2.2 Q-Learning 与深度 Q-Learning

传统的 Q-Learning 属于表格型求解法（Tabular Solution Method），它维护一个称为 Q 表（Q Table）的数组，其中存放所有状态—动作对的价值估计 Q(s, a)。在任一状态下只需查表即可得到各动作的价值，若执行贪心策略，则按

a\_t = argmax\_\{a∈A\} Q(s\_t, a) (3-1)

选择动作。Q-Learning 以如下方式更新价值函数

Q(s\_t, a\_t) ← Q(s\_t, a\_t) \+ β·δ\_t (3-2)

其中 β 为学习率（或称更新步长），δ\_t 为时序差分误差

δ\_t = r\_\{t\+1\} \+ γ·max\_\{a′∈A\} Q(s\_\{t\+1\}, a′) − Q(s\_t, a\_t) (3-3)

式(3-3)中的 max 操作使更新目标对应贪心目标策略，而实际采样动作可由含探索的行为策略产生，因此 Q-Learning 属于异策略（Off-Policy）方法。这里的“异策略”不等同于离线强化学习；本文训练过程中仍持续与仿真环境交互。

尽管表格型 Q-Learning 的收敛性有理论保证，但它只能处理离散且规模有限的状态空间。对于本章的 MDP 模型，状态中的 SINR 取值是连续的，加之 2.2.3 节所引入的历史观测，状态空间是高维且不可数的，无法用 Q 表枚举。为此，采用深度神经网络来拟合 Q 表，即以网络参数 θ 所确定的函数 Q(s, a; θ) 近似真实的价值函数，该方法称为**深度 Q-Learning**，所使用的网络称为深度 Q 网络（Deep Q Network，DQN）。深度 Q-Learning 的动作选择与时序差分误差在形式上与式(3-1)、式(3-3)一致，而训练时网络的更新目标即为最小化时序差分误差的平方。

深度 Q-Learning 在训练中依赖三项关键技巧，本文均予采用。

**（1）ε-贪心探索（ε-Greedy Exploration）。** 强化学习面临探索—利用困境（Exploration–Exploitation Dilemma）：探索指尝试尚未充分评估的动作，利用指按式(3-1)选择当前价值估计最大的动作。在训练前期智能体尝试过的动作较少，若自始至终只执行贪心策略，则容易形成"先入为主"的偏差，即因缺乏探索而无法对所有状态—动作对形成正确的价值评估，从而陷入次优动作。ε-贪心探索以概率 ε 随机选择动作以缓解该困境

a\_t = argmax\_\{a∈A\} Q(s\_t, a)，以概率 (1 − ε)； a\_t ~ U(A)，以概率 ε (3-4)

训练中一般需要前期以探索为主、后期以利用为主，故 ε 的初值取较大值并随训练逐渐衰减至一个较小值。

（2）序列经验回放（Sequential Experience Replay）。循环 Q 网络的回放单元应为同一幕内的连续片段，而不是彼此独立的随机单步转移。每个片段包含连续的 (s\_t, a\_t, r\_t, s\_\{t\+1\}) 序列；在片段起点重置隐状态，或用 burn-in 前缀恢复隐状态，再对后续时间步计算损失。不同片段之间可以随机抽样，以降低批次间相关性并复用历史数据。若当前代码仍按普通 DQN 从缓冲区随机抽取 256 个独立转移并保持 stateful 状态，则回放样本与隐状态历史不匹配，需要先修正实现再采信 GRU 消融结论。正文中的“批大小 256”也应明确是序列条数还是时间步总数。

**（3）双网络与延迟更新。** 在提出 DQN 的工作中，作者即使用了两个结构相同的网络：估计网络 Q\_eval 与目标网络 Q\_tar，其参数分别记为 θ 与 θ⁻。采样与动作选择时使用 Q\_eval 计算动作价值，而计算时序差分目标值时使用 Q\_tar。经验回放直接更新 Q\_eval，其损失函数为

L(θ) = E\_\{(S,a,r,S′)~D\} \[ ( r \+ γ·max\_\{a′\} Q(S′, a′; θ⁻) − Q(S, a; θ) )² \] (3-5)

而 Q\_tar 每隔若干时间步同步至 Q\_eval，即 θ⁻ ← θ，称为延迟更新（Delayed Update）。双网络的作用在于稳定学习目标：若只用单个网络同时产生预测值与目标值，则每次更新在改变预测值的同时也改变了目标值，等效于在追逐一个不断移动的靶子，训练难以收敛。

#### 3.2.2.3 价值过估计与 Double Q-Learning

深度 Q-Learning 存在一个系统性偏差，即**价值过估计**（Overestimation）。其根源在于式(3-3)中的 max 操作与自举的组合。设 Q(S′, a′; θ⁻) 是对真实价值 q(S′, a′) 的无偏估计，即对每个 a′ 有 E\[Q(S′, a′; θ⁻)\] = q(S′, a′)，但由于最大值函数是凸函数，依据 Jensen 不等式有

E\[ max\_\{a′\} Q(S′, a′; θ⁻) \] ≥ max\_\{a′\} E\[ Q(S′, a′; θ⁻) \] = max\_\{a′\} q(S′, a′) (3-6)

即使每个动作的价值估计都是无偏的，取最大值这一操作本身也会引入正偏差。其直观解释是，max 操作总是选中那个恰好被估计得偏高的动作，把估计噪声系统性地转化为向上的偏差。在自举机制下，这一偏差会随目标值被反复代入而在时间上累积传播，导致训练时策略不稳定、收敛速度慢、智能体对某些动作过度自信，最终使策略性能下降。

Double Q-Learning 将动作的选择与该动作价值的评估相分离，以抑制这一偏差。其在双网络的基础上仅对目标值的计算作了简单改动，时序差分目标值改为

y = r \+ γ·Q( S′, argmax\_\{a′\} Q(S′, a′; θ) ; θ⁻ ) (3-7)

即先用估计网络 Q\_eval 选出后继状态下的贪心动作 a′\* = argmax\_\{a′\} Q(S′, a′; θ)，再用目标网络 Q\_tar 评估该动作的价值。由于选择与评估使用了两套不同的参数，"恰好被 Q\_eval 估计得偏高"的动作并不必然也被 Q\_tar 估计得偏高，正偏差因而被显著削弱。相应地，式(3-5)的损失函数改写为

L(θ) = E\_\{(S,a,r,S′)~D\} \[ ( r \+ γ·Q(S′, argmax\_\{a′\} Q(S′, a′; θ); θ⁻) − Q(S, a; θ) )² \] (3-8)

本章采用 Double DQN 作为执行层的强化学习算法，并在训练中使用上述三项技巧。本章还对目标网络采用软更新而非硬同步、对损失函数采用 Huber 损失而非平方损失，相关设计在 3.2.4 节说明。

### 3.2.3 GRU 时序建模与 Q 网络结构设计

#### 3.2.3.1 全连接层与激活函数

DQN 最常用的网络形式是由多层全连接层（Fully Connected Layer，FCL）堆叠而成的深度神经网络（Deep Neural Network，DNN）。对于单层全连接层，设其输入向量为 x ∈ ℝ^d、权重矩阵为 W ∈ ℝ^\{d×h\}、偏置为 b ∈ ℝ^h，则该层的输出为

y = Wᵀx \+ b (3-9)

显然上式为线性变换，若仅单纯堆叠线性变换，其复合结果仍为线性变换，模型的表征能力十分有限。因此通常在全连接层之后使用激活函数（Activation Function）对输出作非线性变换，以提升网络的函数拟合能力。本章所使用的激活函数为

sigmoid(x) = 1 / (1 \+ e^\{−x\}) (3-10)

tanh(x) = (1 − e^\{−2x\}) / (1 \+ e^\{−2x\}) (3-11)

ReLU(x) = max(x, 0) (3-12)

其中 ReLU 用于 DNN 的隐层，sigmoid 与 tanh 用于下述 GRU 的门控与候选状态计算。

#### 3.2.3.2 门控循环单元

依据 2.2.3 节的分析，执行层需要利用历史观测序列来缓解部分可观测性，而普通的全连接网络无法体现输入之间的时序关系。为此本章采用门控循环单元（Gated Recurrent Unit，GRU），它是循环神经网络（Recurrent Neural Network，RNN）的一种改进形式，通过门控机制缓解了朴素 RNN 在长序列上的梯度消失与遗忘问题。

如图 3-2 所示，GRU 含两个门，即重置门（Reset Gate）与更新门（Update Gate）。两个门的输入均由当前时间步的输入与前一时间步的隐状态共同给出，输出由使用 sigmoid 激活函数的全连接层产生。设时间步 t 的输入为 X\_t ∈ ℝ^\{n×d\}（样本数即批大小为 n，输入向量维度为 d），上一时间步的隐状态（Hidden State）为 H\_\{t−1\} ∈ ℝ^\{n×h\}（隐藏单元个数为 h），则重置门 R\_t ∈ ℝ^\{n×h\} 与更新门 Z\_t ∈ ℝ^\{n×h\} 的计算为

R\_t = sigmoid( X\_t·W\_xr \+ H\_\{t−1\}·W\_hr \+ b\_r ) (3-13)

Z\_t = sigmoid( X\_t·W\_xz \+ H\_\{t−1\}·W\_hz \+ b\_z ) (3-14)

其中 W\_xr, W\_xz ∈ ℝ^\{d×h\} 与 W\_hr, W\_hz ∈ ℝ^\{h×h\} 为权重参数，b\_r, b\_z ∈ ℝ^\{1×h\} 为偏置参数。接着，重置门 R\_t 参与候选隐状态（Candidate Hidden State）H̃\_t ∈ ℝ^\{n×h\} 的计算

H̃\_t = tanh( X\_t·W\_xh \+ (R\_t ⊙ H\_\{t−1\})·W\_hh \+ b\_h ) (3-15)

其中 W\_xh ∈ ℝ^\{d×h\}、W\_hh ∈ ℝ^\{h×h\} 为权重参数，b\_h ∈ ℝ^\{1×h\} 为偏置参数，⊙ 表示 Hadamard 积（按元素乘积）。最后，更新门 Z\_t 在旧隐状态 H\_\{t−1\} 与候选隐状态 H̃\_t 之间作按元素的凸组合，得到新的隐状态

H\_t = Z\_t ⊙ H\_\{t−1\} \+ (1 − Z\_t) ⊙ H̃\_t (3-16)

H\_t 同时也是 GRU 在该时间步的输出。两个门的作用可以这样理解：重置门决定在计算新的候选状态时对旧记忆的参考程度，当 R\_t 趋于 0 时候选状态几乎只由当前输入决定，等效于丢弃历史；更新门决定新的隐状态对旧记忆的保留程度，当 Z\_t 趋于 1 时隐状态几乎不变，等效于让信息跨越多个时间步无损传递。正是后一机制使 GRU 能够在较长的时间跨度上保持记忆。

对于本章的抗干扰问题，这两个门具有明确的物理对应：当干扰分布发生突变（例如干扰源集体跳频）时，历史观测所反映的干扰结构已经失效，此时重置门应当关闭以丢弃过时记忆；而当干扰分布稳定、智能体已找到干净配置时，更新门应当保持开启以维持对"当前配置可用"这一判断的记忆，避免因单帧的噪声波动而作出无谓的切换。

#### 3.2.3.3 Q 网络结构

本章所使用的 Q 网络结构如图 3-3 所示，由输入编码层、时序建模层与价值估计层三部分构成。

**输入层（三通道）。** 网络在每一帧接收三路输入：
- 动作通道：上一帧所采取动作的独热编码，维度等于动作空间大小，即 9 维；
- SINR 通道：当前帧由 RDM 估计所得的 SINR 标量，1 维；
- 隐状态通道：GRU 在上一帧的隐状态，32 维。

三通道设计与第二章修订后的状态定义一致：网络每帧接收上一动作的 9 维独热编码和当前 SINR 标量，共 10 维；历史信息由 GRU 隐状态承载，不再额外输入上一帧奖励。这样，编码层第一层参数量为 10×16 \+ 16 = 176，网络总参数量约 7.8×10³。需要强调的是，隐状态只有在样本顺序与真实时间顺序一致时才具有意义；训练阶段不能把互不相邻的随机单步样本直接接到同一个 stateful 隐状态之后。

**编码层。** 动作通道与 SINR 通道拼接为 10 维向量后，经两个全连接层 Dense(16, ReLU) \+ Dense(16, ReLU) 编码为 16 维的中间特征表示。设置编码层的作用在于：独热编码是稀疏的，而 SINR 是连续标量，二者的数值尺度与稀疏性差异很大，直接送入 GRU 会使循环层同时承担"特征变换"与"时序建模"两项任务；先经全连接层将其映射到稠密的中间表示，可使 GRU 专注于时序建模。编码结果经 Lambda 层扩展时间维度后送入 GRU 层。

**时序建模层。** GRU 层配置 32 个隐藏单元，并采用 **stateful 模式**，即隐状态在同一幕内跨帧持续传递，仅在每一幕开始时显式重置。这一配置是执行层获得环境感知能力的关键：若采用非 stateful 模式，则每帧推理时隐状态被清零，网络退化为只能看到当帧观测的无记忆模型，无法从 SINR 序列中推断干扰分布。3.4.3 节的消融实验将定量验证这一组件的贡献。

**价值估计层。** GRU 的输出经 Dense(64, ReLU) 作高维特征映射，最后经 Dense(9, Linear) 输出各动作的 Q 值估计。输出层不使用激活函数，因为动作价值的取值范围由奖励函数与折扣率共同决定，可正可负，不应受激活函数的值域限制。

各层的参数量可依式(3-9)与式(3-13)～(3-16)逐层计算：编码层第一层为 10×16 \+ 16 = 176，第二层为 16×16 \+ 16 = 272；GRU 层含三组权重与偏置，为 3×\[(16×32) \+ (32×32) \+ 32\] = 4704；价值估计层第一层为 32×64 \+ 64 = 2112，输出层为 64×9 \+ 9 = 585。合计约 7.8×10³ 个可训练参数。该参数规模远小于常见的深度视觉或语言模型，其单次前向推理的计算量相对于 7.68 ms 的帧周期余量充足（实测值见第二章表 2-2）。

### 3.2.4 训练机制与超参数设置

除 3.2.2 节所述的三项基本技巧与 Double Q-Learning 之外，本章在训练机制上还采用了四项稳定化措施。这些措施针对的是同一个困难：每幕随机初始化干扰分布使采样数据的方差极大，训练过程既缓慢又易发散。四项措施分别从目标值的平滑性、损失函数的稳健性、梯度的有界性与计算效率四个角度加以应对。

**（1）目标网络软更新。** 3.2.2 节所述的延迟更新采取每隔 C 步将 θ⁻ 硬同步至 θ 的方式，其缺点是在同步时刻目标值会发生跳变，训练损失曲线因而呈现周期性的尖峰。本章改用软更新（Soft Update）

θ⁻ ← τ·θ \+ (1 − τ)·θ⁻ (3-17)

在每一步更新后执行，软更新系数取 τ = 0.005。软更新使目标网络以指数滑动的方式平滑跟随估计网络，其等效时间常数约为 1/τ = 200 步，与硬同步间隔 C = 200 步大致相当，但目标值的变化是连续的，不产生跳变。

**（2）Huber 损失。** 式(3-8)所使用的平方损失对异常样本敏感：当某条转移的时序差分误差很大时（在本文场景中，这既可能源自干扰分布的突然变化，也可能源自随机初始化所带来的极端样本），平方损失所产生的梯度与误差成正比，会对网络参数造成过大的扰动。本章改用 Huber 损失

Huber(e) = ½·e², \|e\| ≤ δ； δ·(\|e\| − ½·δ), \|e\| \> δ (3-18)

取 δ = 1.0。即在误差较小时与平方损失一致以保证梯度的平滑性，在误差较大时退化为与绝对值误差成正比、其梯度被限制为常数 δ，从而抑制异常样本的影响。相应地，一个小批次上的损失为

L(θ) = (1/\|B\|)·Σ\_\{i∈B\} Huber( Q(S\_i, a\_i; θ) − y\_i ) (3-19)

其中 y\_i 为按式(3-7)计算的目标值，B 为该小批次。

**（3）梯度范数裁剪。** 在反向传播之后、参数更新之前，若梯度的 L2 范数超过阈值则按比例缩放至该阈值，本章取阈值为 1.0。该措施与 Huber 损失互补：Huber 损失限制的是单个样本对损失的贡献，梯度裁剪限制的是整个小批次所产生的参数更新幅度，二者共同防止训练过程中损失函数的爆炸。

**（4）混合精度训练。** 采用 FP16 与 FP32 混合精度进行前向与反向计算，在利用 GPU 的 Tensor Core 加速计算的同时降低显存占用。需要说明的是，该措施只影响训练效率而不改变算法本身。

优化器采用 RMSprop，学习率自 1×10⁻³ 按 episode 指数衰减至 1×10⁻⁵。学习率衰减与 ε 衰减在动机上是一致的：训练前期需要较大的步长以快速接近较优的参数区域，后期需要较小的步长以精细收敛并避免在最优解附近震荡。

关于折扣率的选取。本文取 γ = 0.95。1/(1−γ)=20 步（约 153.6 ms）只能作为折扣权重衰减尺度的直观近似，不能据此证明它与环境的真实时间常数“恰好匹配”，因为本文尚未测得该时间常数。γ 过小会弱化跨帧收益，过大可能增加价值估计方差，但 0.95 是否最优仍需通过 γ 的敏感性实验或验证集选择说明；在补充该实验前，应把 γ = 0.95 作为沿用的训练超参数，而不是由物理时间尺度严格推导出的数值。

## 3.3 策略训练效率机制设计

本节设计两项面向训练效率的机制。奖励函数决定了智能体"追求什么"，其形状直接影响价值函数的可学习性；动作掩码决定了智能体"在哪里搜索"，直接影响探索的有效性。二者共同构成执行层在有限交互帧数内收敛的保障，其中后者同时承担了向上层元策略提供调控接口的职能。

### 3.3.1 自适应分段激励的奖励函数设计

依据式(2-49)，即时奖励由信号质量奖励 r\_S 与动作切换代价奖励 r\_AC 两部分构成

r = r\_S \+ r\_AC (3-20)

**信号质量奖励的分段设计。** r\_S 依据当前帧的 SINR 分段计算

r\_S = α₁·(SINR − SINR₁) / \[ (SINR − SINR₁) \+ (SINR₂ − SINR₁) \], SINR ≥ SINR₁ (3-21)

r\_S = α₂·(SINR − SINR₁), SINR \< SINR₁ (3-22)

其中 SINR₁ 为正负奖励的判断阈值，实际中可依目标探测的要求设定；SINR₂ 为用于奖励归一化的 SINR 参考点，其取值通常与噪声等级（如 SNR）相关。本章取 SINR₁ = 0 dB、SINR₂ = 11 dB、α₁ = 1.0、α₂ = 0.1。奖励函数的形状如图 3-4 所示。

这一分段设计的动机在于，抗干扰问题中"SINR 的改善"在不同区间内具有截然不同的价值。

在 SINR ≥ SINR₁ 的正奖励区间，式(3-21)是一个双曲饱和型函数：其值自 SINR = SINR₁ 处的 0 单调递增，在 SINR = SINR₂ 处取得 α₁/2 = 0.5，并随 SINR → ∞ 渐近趋于 α₁ = 1.0。即 SINR₂ 是该函数的半饱和点。其边际收益为

dr\_S/d(SINR) = α₁·(SINR₂ − SINR₁) / \[ (SINR − SINR₁) \+ (SINR₂ − SINR₁) \]² (3-23)

随 SINR 的增大单调递减。这一形状对应了明确的工程意图：SINR 自 0 dB 提升至 11 dB 时，目标自"勉强可检测"变为"可靠检测"，这一段的改善直接决定目标探测性能，故奖励快速上升；SINR 超过 11 dB 之后，进一步提升对检测性能的边际贡献很小，奖励增长因而趋缓，以免智能体为追求无实际意义的更高 SINR 而付出额外的切换代价。

在 SINR \< SINR₁ 的负奖励区间，式(3-22)采用线性惩罚。此处不采用与正区间对称的饱和形式，是因为负区间的目标不是"精细区分有多差"，而是提供一个方向明确、幅度有界的驱动力，使智能体尽快逃离该区间。惩罚系数 α₂ = 0.1 取值较小，既对低 SINR 状态施加了负向激励，又避免了在极低 SINR（本文场景中 SINR 最低可达 −20 dB 量级）时产生过大的奖励绝对值，进而导致时序差分误差与梯度过大、训练不稳定。

正区间在分段点处的导数为 α₁/(SINR₂ − SINR₁) = 1/11 ≈ 0.0909，与负区间的斜率 α₂ = 0.1 十分接近。因此奖励函数在 SINR₁ 处连续，且近似一阶连续，不存在梯度的突变。这一性质对价值函数的拟合是有利的：若分段点处斜率相差悬殊，则该点附近的价值函数会出现难以被平滑网络拟合的折点。

**动作切换代价。** r\_AC 用于抑制策略的频繁抖动

r\_AC = −α₃·AC (3-24)

其中 AC 为式(2-50)所定义的动作代价，取值为 0、1 或 2；本章取 α₃ = 0.05，故 r\_AC ∈ \{0, −0.05, −0.10\}。

将式(3-24)与式(3-23)联立，可以给出该惩罚强度的定量解读：一次单维度切换的代价所"折算"的 SINR 当量，等于 α₃ 除以当前 SINR 处的边际收益。在 SINR ≈ 0 dB 处，该当量为 0.05 / 0.0909 ≈ 0.55 dB；而在 SINR ≈ 11 dB 处，边际收益降至 α₁·11/22² ≈ 0.0227，该当量升至 0.05 / 0.0227 ≈ 2.2 dB。这一随 SINR 升高而增大的切换门槛具有明确的行为学含义：智能体处于低 SINR 时，只要预期能带来 0.55 dB 以上的改善便值得尝试切换，反应因而积极；而当智能体已处于高 SINR 的稳态时，需要预期 2 dB 以上的改善才值得切换，行为因而趋于稳定。动作代价机制与饱和型信号奖励的组合，使智能体自发地表现出"低 SINR 时积极搜索、高 SINR 时稳定保持"的行为模式，而这一模式并未被显式编码到规则中，是奖励函数形状所诱导的结果。

### 3.3.2 动态动作掩码机制

#### 3.3.2.1 机制定义

动态动作掩码（Dynamic Action Masking，DAM）在动作空间上定义一个二值向量 m ∈ \{0, 1\}^\{\|A\|\}，用以标识在当前时刻哪些动作被"允许"、哪些被"限制"。本章定义三种掩码模式，与第四章的三种元策略一一对应：
- **freq\_only（频域）**：固定当前的发射时延索引不变，仅允许切换中心频点，即允许 3 个动作；
- **time\_only（时域）**：固定当前的中心频点索引不变，仅允许切换发射时延，即允许 3 个动作；
- **joint（联合）**：全部 9 个动作均被允许。

此处需着重说明"动态"二字的含义：掩码并非在动作空间上固定划分出的三个子集，而是相对于当前所处参数状态动态生成的。以当前动作索引 a = 4（即 f\_c 索引为 1、t\_d 索引为 1，对应 76.75 GHz 与 0.8 μs）为例：freq\_only 模式下 t\_d 索引固定为 1，允许的动作集合为 \{1, 4, 7\}；time\_only 模式下 f\_c 索引固定为 1，允许的动作集合为 \{3, 4, 5\}。若下一帧智能体转移至 a = 7，则 freq\_only 模式下允许的集合仍为 \{1, 4, 7\}，而 time\_only 模式下允许的集合变为 \{6, 7, 8\}。因此，同一种模式在不同参数状态下所对应的允许集合不同，掩码需在每一帧依当前状态重新计算。

单维度模式虽然只允许 3 个动作，但网络的输出层维度仍保持为 9，未被允许的动作在动作选择环节被处理，而非通过改变网络结构来实现。这一实现方式保证了三种模式共享同一套网络参数与同一份经验回放缓冲区，掩码模式因而可以在推理过程中随时切换而无需重新加载模型。第四章元策略层得以逐周期下发不同的策略标签，正以此为前提。

#### 3.3.2.2 训练阶段的作用：探索空间裁剪

在训练阶段，DAM 用于构造 3.4.1 节所定义的单维度对照智能体。其对样本效率的提升可以定量估计：依据式(3-4)，ε-贪心探索以概率 ε 在允许集合上均匀随机选择动作，故在联合模式下随机探索命中某个特定动作的概率为 1/9，而在单维度模式下为 1/3。因此在同等探索预算下，单维度智能体对其 3 维子空间的覆盖速度约为联合智能体覆盖 9 维空间速度的 3 倍。这解释了 3.4.2 节中所观察到的现象：两个单维度智能体的收敛速度明显快于联合智能体，但由于其可达的参数配置受限，最终性能低于联合智能体。

#### 3.3.2.3 推理阶段的作用：层间调控接口

在推理阶段，DAM 作为元策略层向执行层下发指令的标准化通道。元策略层输出策略标签 ℓ 与置信度 p，DAM 将其转换为长度为 9 的 Q 值偏置向量并叠加至网络输出，即第二章式(2-54)。偏置的具体形式有两种可选方案，其对比列于表 3-2。

### 3.4.2 训练收敛与性能对比

**训练收敛过程。** 三个具备学习能力的方案在 15000 幕训练过程中的 SINR 收敛曲线如图 3-6 所示（50 幕滑动平均）。三者呈现出显著不同的收敛特征。

freq\_only 收敛最快，约 2000 幕即达到稳态。这与 3.3.2.2 节的分析一致：其动作空间仅为 3 维，ε-贪心探索对子空间的覆盖速度约为联合方案的 3 倍，探索负担最轻。然而其最终 SINR 约为 8.2 dB，标准差较大（约 3.2 dB），说明其性能在不同干扰分布下的一致性较差。具体原因是在频域密集型的干扰场景中，若多个干扰源同时占据不同频点，仅切换频率无法完全规避，而此时 freq\_only 因时延被固定而无从改善。

time\_only 收敛速度居中，约 3000 幕达到稳态，最终 SINR 约 7.8 dB，标准差约 4.6 dB，为三者中最大。其标准差更大的原因有两点：其一，时域策略的效果依赖于干扰到达延迟与雷达发射时延之间的相对关系，而依据式(2-55)、(2-56)，目标的移动会改变回波延迟、干扰源的移动会改变干扰到达延迟，时延维度上的场景变化比频域更为频繁；其二，本文场景中干扰到达延迟在 U(0, 3τ\_max) 上连续分布，而可选时延只有三个离散值，时域上"完全避开"的余量本身较小。

joint 收敛最慢，但最终性能最优。前 3000 幕其 SINR 低于两个单维度方案，这是在 9 维动作空间中探索所必须付出的代价；约 4000 幕之后其性能超越两个单维度方案，最终 SINR 约 9.5 dB，标准差仅约 0.57 dB。

结论三，频域维度的干扰多样性略高于时延维度。freq\_only 的平均 SINR 比 time\_only 高 0.46 dB，且标准差更小。这一差异虽不大，但与前述关于 time\_only 标准差的分析相互印证：在本文的仿真参数下，干扰在频域上的分布相对更为离散（三个频点各占 500 MHz 带宽，干扰中心频率的随机分布使其较难同时覆盖多个频点），而在时延维度上，干扰到达延迟在 U(0, 2.4 μs) 上连续分布、且三个可选时延仅覆盖 \{0, 0.8, 1.6\} μs，时域上的可回避余量相对更小。因此频域自适应所带来的收益略大于时域自适应。该结论与仿真参数相关：若改变频点间隔、时延档位或干扰的分布范围，两个维度的相对优劣可能反转，故不宜将其推广为一般性判断。

### 3.4.3 时序建模组件的消融实验

3.2.3.3 节指出，stateful 模式的 GRU 是执行层获得环境感知能力的关键组件。本节通过消融实验定量验证这一判断。

**实验设置。** 以性能最优的 joint 方案为基准，将其网络中的 GRU 层替换为参数量相当的全连接层，其余结构、奖励函数、训练机制与超参数保持不变，重新训练 15000 幕后按 3.4.1 节的方式评估。替换之后网络不再具备跨帧的记忆能力，每帧的动作选择只能依据当帧的观测（上一动作的独热编码与当前 SINR）作出，因而退化为对瞬时 SINR 的反应式决策。

## 3.5 本章小结

本章实现并优化了分层抗干扰决策框架中的深度强化学习执行层，主要工作与结论如下。

其一，论证了强化学习算法的选型并实现了 Double DQN 执行层。本文场景难以获得显式状态转移概率，动作空间离散且规模有限，因此采用基于价值函数的时序差分方法。Q-Learning / DQN 属于异策略（off-policy）方法；“异策略”描述行为策略与目标策略不同，不等同于使用固定历史数据集训练的离线强化学习。经验回放提高样本复用率，Double Q-Learning 通过分离动作选择与动作评估抑制 max 自举造成的价值过估计。

其二，以 stateful 模式的 GRU 实现了对干扰环境的时序感知。采用"单帧观测输入 \+ 隐状态承载记忆"的三通道网络结构，以 32 维 GRU 隐状态跨帧持续传递，使智能体能够从 SINR 的时间序列中推断干扰的分布结构，而非仅对瞬时 SINR 作反应式决策。消融实验表明，该组件对性能的贡献约为 2.3 dB，其重要性超过动作空间自 3 维扩展至 9 维所带来的收益，从而印证了部分可观测性是本问题的主要困难来源。

其三，设计了自适应分段激励的奖励函数。SINR 不低于阈值时采用双曲饱和型奖励以鼓励达标而不鼓励过度优化，低于阈值时采用有界的线性惩罚以驱动智能体尽快逃离干扰区域；并证明了在本章参数下奖励函数在分段点处近似一阶连续，有利于价值函数的拟合。进一步给出了动作切换代价的定量解读：一次单维度切换所折算的 SINR 当量随当前 SINR 的升高而自 0.55 dB 增至 2.2 dB，智能体因而自发呈现"低 SINR 时积极搜索、高 SINR 时稳定保持"的行为模式，该模式并非被显式编码的规则，而是奖励函数形状所诱导的结果。

其四，动态动作掩码在训练阶段将单维度方案的候选动作从 9 个减少为 3 个，在推理阶段作为元策略标签到动作偏置的统一接口。候选数减少并不自动等于覆盖速度提升 3 倍；探索效率需由相同样本预算的学习曲线证明。接口可降低模块耦合，但并非数据与时序上的完全解耦。硬掩码与软引导共用叠加位置，具体数值和边界行为仍应由代码与测试确认。

其五，在场景 A 的 100 幕测试样本中，joint 方案得到 9.50 ± 0.57 dB 的平均 SINR 与 91% 的避开率；freq\_only、time\_only 与固定参数基线分别为 8.24 ± 3.20 dB、7.78 ± 4.62 dB 和 2.59 ± 9.85 dB。上述结果支持联合动作空间在该样本集上的均值与稳定性优势，但当前材料未给出多随机种子重复实验、置信区间或显著性检验，因此不使用“显著优于”的统计表述。若 GRU 训练代码未采用连续序列回放与隐状态对齐，这组结果还不能归因于可靠的时序建模。

本章结果是第四章 Pure DRL 的对照基线，不是整个分层框架的理论性能下界：元策略偏置若发生误导，同样可能使分层方案低于该基线。现有实验显示，纯执行层仅依赖当前配置下的标量 SINR，在部分密集或突变仿真场景中出现较多切换与试探；第四章据此引入元策略控制器，并通过对照实验检验其在当前 oracle 辅助设置下能否带来增量。

# 第四章 基于模式识别的抗干扰策略决策层优化

本章构造监督学习元策略控制器，给出三类策略、软引导、策略持久化、十二维特征、随机森林及四组受控仿真实验。维度敏感性特征与初始化使用逐配置 oracle 信息；随机森林投票比例尚未校准，MDI 重要性只能作描述性分析；无 oracle 对照、机制消融与多随机种子统计尚不完整。因此，本章评估的是“元策略层 \+ oracle 信息”整体在当前仿真生成器中的样本表现，而不是已隔离的元策略净增量、通用泛化或工程实时性。

## 4.1 分层决策框架的元控制器设计

### 4.1.1 引入元控制器的动机与分层决策框架

第三章的实验表明，Double DQN \+ GRU 执行层在场景 A 中已取得 9.50 ± 0.57 dB 的平均 SINR 与 91% 的避开率。然而该方案存在两项结构性局限，它们源于单层结构本身，并非通过增大网络规模或延长训练即可消除。

局限一是标量反馈所承载的信息不足。执行层在每一帧只能获得一个标量 SINR，该标量反映的是当前 (f\_c, t\_d) 配置下的聚合信号质量，无法揭示干扰源在频域与时域上的分布结构。换言之，它回答不了这样一个问题：当前 SINR 低，究竟是因为频域已被大量占用，还是因为时延不匹配。智能体唯一的信息获取方式是切换到另一个配置、观测新的 SINR，再据此间接推断。

完整判断 3×3 配置在当前时刻的性能需要 9 个数，而执行层每帧只能观测其中一个；若逐个配置扫描一轮，至少需要 9 帧，即 69.1 ms。该事实说明纯试探存在观测延迟，但原稿将其进一步表述为“永远追不上环境变化”缺少依据：正常车辆运动在 30 帧内造成的到达延迟变化较小，环境变化时间常数也未由数据测得。更稳妥的结论是，当干扰分布变化与扫描耗时处于相近量级时，部分观测会在扫描完成前变旧，定向搜索可能比盲目遍历更有效；这一假设由后续受控跳频实验验证，而非由 69.1 ms 本身证明。

局限二是非平稳环境下探索—利用矛盾的加剧。相干干扰环境具有明显的非平稳性：干扰车辆的相对运动、新干扰源的进入、既有干扰源的频率跳变，都会使环境分布持续改变。此时 ε-贪心策略面临两难：ε 取值过小，则智能体在环境变化后缺乏足够的探索以发现新的最优配置，长时间停留在已失效的旧策略上；ε 取值过大，则即便已找到干净的配置，智能体仍会以固定概率随机切换，导致稳态 SINR 持续振荡。第三章通过 ε 的逐幕衰减在训练期缓解了这一矛盾，但在推理期 ε 固定为 0.05，该矛盾依然存在。

这一两难的根本原因在于，单层结构把“是否需要改变搜索策略”与“具体选择哪个动作”这两类决策绑定在了同一个 Q 网络上，而这两类决策所需的信息基础与决策频率截然不同。前者需要跨越数十帧的统计信息，其判断结果在数十帧内应当保持稳定；后者需要逐帧的即时响应，必须允许逐帧改变。

为此，本章在执行层之上引入元策略控制器，其信息流如图 4-1 所示：

SINR 帧序列与动作记录 → 滑动窗口特征提取 → 场景分类 → 元策略标签与置信度 → DAM 转换为 Q 值偏置 → 执行层动作选择

元策略层的作用是把执行层无法从标量反馈中获得的结构性信息显式地计算出来。具体而言，4.2.1 节所设计的维度敏感性特征通过指数移动平均在线估计各频点与各时延下的信号质量，从而直接回答“频域与时域哪一维存在更大的优化空间”。有了这一判断，9 维的搜索问题即被降维为“先判断该往哪一维走、再在该维的 3 个选项中搜索”的两步问题：判断维度所需的 EMA 更新只需 3 ～ 4 帧（约 23 ～ 31 ms，见 4.2.2 节），在该维内扫遍 3 个选项只需 3 帧（23 ms），合计远快于盲目扫描 9 个配置所需的 69.1 ms。分层结构带来增益的机理正在于此：它并不替代执行层的逐帧决策，而是把盲目搜索转化为定向搜索。

元策略层以 K 帧为决策周期运行，特征提取的滑动窗口长度为 W 帧。二者在训练与测试阶段取不同值：训练阶段取 W = 50 帧（384 ms）、K = 8 帧（61.4 ms），以确保分类器基于充分的统计信息作出稳定的判断，从而降低训练标签的噪声；测试阶段取 W = 12 帧（92.2 ms）、K = 3 帧（23.0 ms），以换取更快的响应速度。配合 4.1.3 节的策略持久化机制（最小保持步数 5 帧，即 38.4 ms），在每幕 30 帧之内可完成约 6 次有效的策略决策。

### 4.1.2 三种核心元策略的定义

本章定义三种核心元策略，与 3.3.2 节所定义的三种掩码模式一一对应，其定义与适用场景列于表 4-1。

**表 4-1 三种核心元策略的定义**

| 元策略 | 动作空间 | 物理含义 | 适用场景 | 触发条件 |
|---------|------------|------------|------------|------------|
| 频域优先（freq\_only） | 固定当前 t\_d，3 个频点可选 | 当前时延位置已足够好，仅需换频点即可规避干扰 | 频域干扰分布不均、时域相对干净 | fc\_td\_ratio \> 0 |
| 时域优先（time\_only） | 固定当前 f\_c，3 个时延可选 | 当前载频已足够好，仅需调时延即可规避干扰 | 时域干扰分布不均、频域相对干净 | fc\_td\_ratio \< 0 |
| 联合探索（joint） | 9 个动作全开放 | 单维度策略的收益均不足，需时、频联合优化 | 高动态或密集干扰，两个维度均需调整 | 两维度期望收益接近且均不足 |

三种元策略的判定分为两步。第一步比较 joint\_best 与最优单维度策略的期望收益，只有联合策略优势超过式(4-26)的阈值时才选择 joint。第二步仅在不选 joint 时执行，根据 fc\_td\_ratio 的符号在 freq\_only 与 time\_only 之间选择。若两个维度的潜在收益都很小或 fc\_td\_ratio 接近 0，则联合策略没有足够的额外收益；本文采用 time\_only 作为确定性的默认规则，以减少频点切换与频谱占用。该默认规则是人为约定，不是随机森林必然学习到的物理规律，实验中应单独报告其触发比例。

三种元策略的设计依据在于：依据第三章结论一的分析，单维度策略之所以性能受限，是因为它在“另一维度恰是瓶颈”的场景中无能为力；反过来说，当某一维度确实存在明显更大的优化空间时，把搜索限制在该维度之内并不损失性能，且因搜索空间缩小而提高了效率。因此三种元策略并非“三个不同的算法”，而是同一个执行层在三种不同搜索范围下的运行模式，元策略层的任务就是判断当前场景属于哪一种情形。

本章没有设置“仅调整某一维度到某个具体值”这样更细粒度的元策略，这是有意的设计取舍：元策略层只作维度层面的判断而不介入具体取值的选择，具体取值仍交由执行层依据 Q 值决定。这样既保持了两层职责的清晰划分（战略层判断方向、战术层选择动作），也避免了元策略层因需要输出更精细的指令而不得不承担更高的分类难度与更大的误判后果。

### 4.1.3 软引导机制与策略持久化

#### 4.1.3.1 自硬掩码到软引导

将元策略标签转换为执行层可消费的偏置向量，最直接的方式是硬掩码，即把被限制动作的 Q 值直接置为一个极大的负数（如 −1×10⁹），使其在 argmax 中不可能被选中。然而这一方式存在严重的鲁棒性缺陷。分类器的判断并非总是正确的：4.3.2 节的实验表明，本章随机森林分类器在测试集上的准确率约为 80% ～ 85%，即误判率约为 15% ～ 20%。在硬掩码下，一旦分类器误判，最优动作即被从候选集合中彻底排除，执行层无论其 Q 网络的估计多么准确都无法选中它，性能退化不可恢复。更糟的是，误判往往集中发生在场景发生变化的时刻，而这恰恰是最需要正确决策的时刻。

为此本章采用**纯软引导**机制：对元策略标签所允许的动作施加一个正的 Q 值偏置，而被限制的动作保持其原始 Q 值不变

bonus(a) = base\_bonus × p², 若 a 被当前元策略允许； bonus(a) = 0, 否则 (4-1)

其中 base\_bonus = 12.0，p 为分类器输出的置信度。执行层实际用于动作选择的价值即为第二章式(2-54)所给出的 Q̃(S\_t, a) = Q(S\_t, a) \+ bonus(a)。

这一机制具有两项关键性质。

性质一是保留纠错通道，而不是提供性能下界。被限制动作保持原始 Q 值，因此当其 Q 值优势大于偏置时仍可能被选中；相比硬掩码，这降低了误判时彻底排除最优动作的风险。但是，只要正偏置改变了动作排序，分类器误判仍可能使执行层选择比 Pure DRL 更差的动作，并可能持续多个周期。因此，式(4-1)不能推出“最坏情况下等价于 Pure DRL”或“引入元策略层绝不退化”的保证。软引导的真实收益必须通过误判样本分析及“软引导—硬掩码—无引导”消融实验验证。

性质二是引导强度的自适应缩放。偏置幅度与置信度的平方成正比，这使引导强度在高置信度与低置信度之间平滑过渡。为定量理解 base\_bonus = 12.0 这一取值的强弱，需要的参照量不是 Q 值的绝对量程，而是不同动作之间 Q 值的典型差距，因为偏置改变动作排序的前提是它足以越过这个差距。依据 3.3.1 节的奖励函数与 γ = 0.95 可作如下估算：一个“始终维持 \+2 dB”的动作序列对应的 Q 值约为 0.154/0.05 ≈ 3.1，而一个“始终维持 −5 dB”的动作序列约为 −0.5/0.05 = −10，二者相差约 13。可见在本文场景下，“一个好动作”与“一个差动作”之间的 Q 值差距在 10 的量级。据此：
- 当 p → 1.0 时，bonus = 12.0，已超过 Q 值的整个典型量程，此时软引导在效果上接近硬掩码；
- 当 p = 0.8 时，bonus = 7.7，与 Q 值量程同量级，具有较强但非决定性的影响；
- 当 p = 0.5 时，bonus = 3.0，仅能改变本就相近的动作之间的排序；
- 当 p → 0 时，bonus → 0，元策略层实质上不作干预。

采用平方项而非线性项的意义正在于此：它使低置信度时的引导力度快速衰减，把“分类器有把握时强力引导、没把握时基本不干预”这一意图直接编码进偏置的形式之中。分类器的误判通常伴随较低的置信度，该设计因而显著削弱了误判的实际危害。这也是软引导机制在误判率约 15% ～ 20% 的条件下仍不导致性能退化的直接原因。

#### 4.1.3.2 策略持久化机制

元策略层以 K = 3 帧为周期作出判断，若每次判断的结果都立即生效，则可能出现策略标签在相邻决策周期之间反复跳变的情形，尤其是当场景处于两类之间的边界时，特征的微小波动即可使分类结果反转。这种抖动是有害的：执行层需要若干帧才能在受限的子空间内找到较优配置，若子空间被频繁改变，执行层将始终处于“刚开始搜索就被换到另一个子空间”的状态。

为此本章设计策略持久化机制。设定最小策略保持步数 min\_strategy\_steps = 5 帧，元策略控制器在每个决策周期输出新标签时按如下规则处理：
- 若新标签与当前生效的策略相同，则直接更新置信度并重置计数器；
- 若新标签与当前生效的策略不同，且当前策略已保持不少于 min\_strategy\_steps 帧，则允许切换并重置计数器；
- 若新标签不同但当前策略保持不足 min\_strategy\_steps 帧，则忽略新标签，继续执行当前策略。

该机制可视为滞回环节：元策略按固定周期判别，但只有候选标签与当前生效标签不同时，且当前标签已保持至少 5 帧，才允许切换；同标签预测应继续累计保持时长，只有实际切换时才将计数器清零。原“切换频率降低约 40%”仅是待复核日志观察，当前尚无与无持久化版本的完整对照统计，故不作为已验证结论。

三个时间常数的关系因此为：帧周期 7.68 ms（执行层动作粒度）\< 决策周期 23.0 ms（元策略判别粒度）\< 持久化窗口 38.4 ms（元策略生效粒度）。三者逐级放宽，即 2.3.1 节所论证的时间尺度分离在实现层面的具体形式。

## 4.2 基于滑动窗口的场景语义特征提取

元策略层的判别质量取决于其输入特征能否刻画干扰场景的结构。本节设计场景语义特征提取模块，将执行层产生的原始 SINR 序列与动作记录转化为十二维特征向量，作为分类模型的输入。全部特征均在长度为 W 的滑动窗口内计算，且计算复杂度均为 O(W) 或 O(1)，原则上可采用增量式滑动更新。

### 4.2.1 十二维场景语义特征设计

设当前帧为第 t 帧，滑动窗口覆盖第 t−W\+1 至第 t 帧。十二维特征分为四类。

#### 第一类：信号质量统计特征（4 维）

**窗口均值** 反映窗口内的平均信号质量水平

μ = (1/W)·Σ\_\{i=t−W\+1..t\} SINR\_i (4-2)

**标准差** 反映信号质量的波动程度，间接反映干扰环境的动态性

σ = sqrt\[ (1/W)·Σ\_\{i=t−W\+1..t\} (SINR\_i − μ)² \] (4-3)

**线性趋势斜率** 由窗口内 SINR 序列对帧序号作最小二乘线性回归得到

Δ = Σ\_i (i − ī)·(SINR\_i − μ) / Σ\_i (i − ī)² (4-4)

其中 ī 为窗口内帧序号的均值。Δ \> 0 表示信号质量正在改善，Δ \< 0 表示正在恶化。该特征用以区分“当前 SINR 低但正在好转”与“当前 SINR 低且持续恶化”这两种需要不同响应的情形。

**窗口最小值** 刻画窗口内的最坏情况

SINR\_min = min\_\{i∈\[t−W\+1, t\]\} SINR\_i (4-5)

#### 第二类：执行层动作行为特征（3 维）

这一类特征不描述环境，而描述执行层自身的行为。其依据在于，智能体的行为模式本身携带了关于环境难度的信息：一个“找不到稳定策略、不断切换”的执行层，其行为本身即是“当前场景困难”的信号。

**动作熵** 定义为窗口内动作分布的信息熵

H\_action = − Σ\_\{a=0..8\} p(a)·log p(a) (4-6)

其中 p(a) 为动作 a 在窗口内出现的频率。H\_action 的上界为 log 9 ≈ 2.20，当智能体在 9 个动作之间均匀切换时取得；当智能体稳定停留于单一动作时 H\_action = 0。熵值高说明执行层在频繁切换、未能找到稳定策略，可直接作为场景困难的指示。

**频域动作切换率**与**时域动作切换率**分别定义为

r\_freq\_switch = ( 窗口内 f\_c 索引发生变化的次数 ) / (W − 1) (4-7)

r\_time\_switch = ( 窗口内 t\_d 索引发生变化的次数 ) / (W − 1) (4-8)

二者与 H\_action 的区别在于：动作熵刻画切换的总体无序程度，而两个切换率区分切换发生在哪一个维度上，从而提供了维度层面的行为信息。

#### 第三类：避干扰效能特征（2 维）

**避开率** 即第二章式(2-57)所定义的指标在窗口内的取值

r\_avoid = ( 窗口内 SINR \> 0 的帧数 ) / W (4-9)

**SINR 增益** 定义为窗口后半段与前半段的均值之差

SINR\_gain = μ\_后半窗 − μ\_前半窗 (4-10)

该特征与趋势斜率 Δ 在动机上相近但侧重不同：Δ 是对整个窗口作线性拟合所得的瞬时变化率，对窗口两端的异常值较为敏感；SINR\_gain 则是两个半窗均值之差，对噪声更稳健，反映的是当前策略是否正在起效这一较为宏观的判断。

#### 第四类：维度敏感性特征（3 维）

前三类特征共九维，共同点是都在描述“现状好不好”：信号质量如何、行为是否稳定、策略是否在起效。然而依据 4.1.1 节的分析，元策略层真正需要回答的问题不是“现状好不好”，而是“哪个维度还有多大的提升空间”。第四类特征即为回答这一问题而设计。

设 SINR\_EMA\_fc(f\_c^i) 与 SINR\_EMA\_td(t\_d^j) 分别表示第 i 个频点与第 j 个时延下信号质量的在线估计（其计算方式见 4.2.2 节），则定义

fc\_gap = max\_i SINR\_EMA\_fc(f\_c^i) − min\_i SINR\_EMA\_fc(f\_c^i) (4-11)

td\_gap = max\_j SINR\_EMA\_td(t\_d^j) − min\_j SINR\_EMA\_td(t\_d^j) (4-12)

fc\_td\_ratio = log( fc\_gap / td\_gap ) (4-13)

fc\_gap 为各频点信号质量估计的极差，其含义是“如果切换频点，最好与最差之间能相差多少 dB”，即切换频点的潜在收益；td\_gap 同理表示调整时延的潜在收益。二者的对数比 fc\_td\_ratio 则直接给出两个维度的相对优劣：其值为正表示频域的优化空间更大，为负表示时域的优化空间更大。这三个特征正是 4.1.2 节表 4-1 中触发条件的计算依据。

此处取极差而非方差或均值作为潜在收益的度量，是因为决策所关心的是“最好的那个选项能带来多大改善”，这是一个关于极值的问题而非关于分布集中程度的问题。式(4-13)取对数而非直接取比值，则是为了使该特征关于两个维度对称：交换 fc\_gap 与 td\_gap 只改变其符号而不改变其绝对值，分类器对两类单维度策略的判别边界因而自然地落在零点附近。

综上，时间步 t 的场景语义特征向量为

f\_t = \[ μ, σ, Δ, SINR\_min, H\_action, r\_freq\_switch, r\_time\_switch, r\_avoid, SINR\_gain, fc\_gap, td\_gap, fc\_td\_ratio \] ∈ ℝ¹² (4-14)

### 4.2.2 指数移动平均在线估计与 oracle 种子化

#### 4.2.2.1 逐配置的指数移动平均估计

第四类特征依赖于对各参数配置信号质量的估计。为此，对 9 个 (f\_c, t\_d) 组合各维护一个指数移动平均（Exponential Moving Average，EMA）估计值

SINR\_EMA^\{(i,j)\}(t) = α·SINR^\{(i,j)\}(t) \+ (1 − α)·SINR\_EMA^\{(i,j)\}(t−1) (4-15)

其中平滑系数取 α = 0.30。各频点与各时延的信号质量估计则由该维度下的最优取值聚合而得

SINR\_EMA\_fc(f\_c^i) = max\_j SINR\_EMA^\{(i,j)\} (4-16)

SINR\_EMA\_td(t\_d^j) = max\_i SINR\_EMA^\{(i,j)\} (4-17)

此处取 max 而非取均值，其理由与 4.2.1 节取极差同源：判断“换到某个频点是否值得”时，所关心的是在该频点下能达到的最好结果（因为时延仍可由执行层继续优化），而非在该频点下随机选取时延的平均结果。

关于 EMA 的响应速度，依据式(4-15)，EMA 对输入阶跃变化的响应为指数收敛，其等效时间常数为 1/\[−ln(1 − α)\] ≈ 2.8 帧（约 21.5 ms），达到阶跃响应 90% 约需 6.5 帧（约 50 ms）。工程上通常以 3 ～ 4 帧（约 23 ～ 31 ms）作为其有效响应时间的估计。这一响应速度是 4.4.2 节 Exp-D 中跳频恢复更快的直接机理：当干扰源集体跳频后，EMA 只需 3 ～ 4 帧即可反映出新的维度敏感性，元策略层在下一个决策周期（K = 3 帧）即可输出与新干扰模式匹配的策略标签。

该估计方式存在一项限制必须说明。由于雷达在每一帧只能使用一个参数配置，式(4-15)对某个配置的更新只在该配置被实际使用的帧才发生，其余 8 个配置的 EMA 在该帧保持不变。这带来两个后果：其一，长期未被执行层访问的配置，其 EMA 估计将逐渐陈旧，所计算出的 fc\_gap 与 td\_gap 相应失真；其二，在一幕开始时全部 9 个 EMA 均无有效初值，存在**冷启动问题**。这两点正是下述 warmup 扫描与 oracle 种子化机制的必要性所在。

#### 4.2.2.2 oracle 替代与种子化

训练阶段使用仿真 oracle 生成标签，并以 oracle 表计算 fc\_gap、td\_gap 与 fc\_td\_ratio。这样可以构造较干净的监督学习数据，但也意味着三个最重要特征与标签来自同一张 3×3 性能表，分类准确率部分反映的是规则复现能力，而不是仅凭在线可观测量识别场景的能力。为避免过度解释，本文把该分类器视为 oracle 辅助的策略映射器；后续必须增加仅使用可观测 EMA 特征训练的对照，并按场景而非按同分布样本随机划分训练/测试集，以检查是否存在数据泄漏或同源特征带来的乐观偏差。

测试阶段原稿采用 oracle 表直接初始化 9 个 EMA 状态。该做法解决了冷启动并缩小训练—测试特征分布差异，但真实车载系统无法获得仿真“上帝视角”，因此也会向 Meta-RF 注入 Pure DRL 基线没有使用的特权信息。本文保留该设置时，所有 Meta-RF 指标都必须明确标注为“oracle 初始化条件下的仿真结果/性能上界”，不能作为可部署在线算法的直接证据。公平性验证至少应增加三组对照：零初始化、9 配置实测 warmup 初始化、以及不使用 oracle 特征训练的模型；同时报告 cold-start 阶段损失与长期未访问配置的估计陈旧。

oracle 表的可得性是本文方法的一项假设性前提，这一点必须明确指出。在仿真环境中，由于目标与干扰的全部参数均为已知，可以直接解析计算任意配置下的 SINR，故 oracle 表唾手可得；但在实际车载系统中并不存在这样的“上帝视角”。实车部署时有两条可行的替代路径：其一，以 warmup 阶段对 9 个配置的实测扫描结果替代 oracle 表，其代价是扫描期间的探测性能受损，且所得估计带有测量噪声；其二，借助独立的干扰参数估计模块推算各配置下的预期 SINR，其可行性取决于干扰参数估计的精度。本文对上述替代路径的效果未作评估，相关讨论列入第 5.2 节。

### 4.2.3 特征有效性预验证

在训练分类器之前，本节先验证所设计特征是否确实具备区分不同干扰场景的能力。这一预验证有两重作用：其一，若某些特征在各场景下的分布高度重叠，则说明其信息增益有限，应予以简化；其二，预验证所形成的先验预期将与 4.3.3 节实测的特征重要性排序相互对照，若二者吻合，则说明分类器所学到的规律与物理直觉一致，其决策依据是可信的而非偶然的数据关联。

## 4.3 基于随机森林的元策略分类与可解释性分析

### 4.3.1 随机森林原理与选型依据

#### 4.3.1.1 分类树与不纯度准则

随机森林（Random Forest，RF）是以分类回归树（Classification And Regression Tree，CART）为基学习器的集成学习方法。对于分类任务，CART 采用基尼不纯度（Gini Impurity）作为节点分裂的评价准则。设节点上的样本集为 D，第 c 类样本所占比例为 p\_c，则该节点的基尼不纯度为

Gini(D) = 1 − Σ\_c p\_c² (4-18)

其取值在样本全属同一类别时为 0、在各类别均匀分布时取得最大值。对某个特征的某个取值作二分裂，将 D 划分为左右子集 D\_L 与 D\_R，则分裂后的加权不纯度与不纯度下降量分别为

Gini\_split = (\|D\_L\|/\|D\|)·Gini(D\_L) \+ (\|D\_R\|/\|D\|)·Gini(D\_R)

ΔGini = Gini(D) − Gini\_split (4-19)

CART 在每个节点上遍历候选特征与候选分裂点，选取使 ΔGini 最大的分裂方式，递归地生长直至达到预设的最大深度或叶节点最小样本数等停止条件。

#### 4.3.1.2 自助采样与特征随机化

单棵决策树的方差较大，即训练集的微小扰动可能导致树结构显著变化。随机森林通过两重随机化与集成来抑制方差：其一是**自助采样（Bootstrap）**，即对原训练集有放回地抽样构造 B 个子集，每个子集训练一棵树；其二是**特征随机化**，即每个节点分裂时只在随机选取的特征子集上寻找最优分裂。

集成降方差的效果可作如下估计：设单棵树的预测方差为 s²、任意两棵树预测之间的相关系数为 ρ，则 B 棵树平均预测的方差为

Var = ρ·s² \+ (1 − ρ)·s² / B (4-20)

由式(4-20)可见，增大 B 只能消去第二项，方差的下界由树间相关性 ρ 决定。特征随机化的意义正在于此：它强制不同的树使用不同的特征，由此降低 ρ，也就降低了集成方差的下界。这一机制对本章任务尤有必要，因为 4.2.3 节已指出十二维特征之间存在明显的相关性（如 σ 与 H\_action、两个切换率之间），若不作特征随机化，各棵树将倾向于反复选用同一组强特征，ρ 居高不下。

分类时，随机森林以各棵树的投票结果决定类别，并以获胜类别的得票比例作为该判别的置信度

p = ( 投票给获胜类别的树数 ) / B (4-21)

式(4-21)所给出的 p 即直接用作式(4-1)中软引导偏置的置信度。

#### 4.3.1.3 特征重要性

随机森林可自然地给出特征重要性度量：将某特征在森林中所有以其作为分裂特征的节点上所带来的不纯度下降 ΔGini 按节点样本数加权求和，再对全部特征归一化，即得该特征的重要性

Imp(k) = Σ\_\{所有以特征 k 分裂的节点\} (\|D\_node\|/\|D\|)·ΔGini\_node ，再对 k 归一化使 Σ\_k Imp(k) = 1 (4-22)

#### 4.3.1.4 选型依据

本章之所以选用随机森林而非神经网络分类器（如 GRU \+ Softmax），基于以下五点考虑。

（1）小样本条件下的泛化性。本章的训练集仅 4000 条样本（见 4.3.2 节），而生成每条样本都需要完整运行一次 60 帧的 warmup 仿真，采集成本较高。在这一数据规模下，随机森林凭借自助采样与集成机制不易过拟合，而神经网络分类器则需要更强的正则化与更精细的调参。

（2）推理耗时。随机森林的推理为 B 棵树的路径遍历，其单次推理耗时在亚毫秒量级，相对 23.0 ms 的决策周期余量约 46 倍（见第二章表 2-2），完全满足实时约束。

（3）投票比例可直接计算，但不等于已校准概率。随机森林中支持某标签的树比例具有直观含义，可用于构造引导强度；然而它仍可能过度或不足自信，必须通过可靠性图、Brier 分数、期望校准误差等指标检验，并在需要时使用 Platt scaling 或 isotonic regression 校准。由于软引导直接使用该数值，本章不能仅凭“树的投票比例”就宣称置信度可靠。

（4）可解释性。式(4-22)所给出的特征重要性使元策略层的决策依据可以被定量地审视与解释，而这对于行车安全相关部件是必要的。4.3.3 节将据此验证分类器所学到的规律是否与物理直觉一致。

（5）对特征尺度不敏感。表 4-2 中的十二维特征量纲各异（dB、dB/帧、无量纲比例、信息熵），量级差异可达两个数量级。基于树的模型只依据特征取值的序作分裂，对特征的尺度与单调变换不敏感，因而无需归一化预处理，也避免了归一化统计量在训练与推理之间可能产生的不一致。

### 4.3.2 训练数据自动生成与分类器训练

#### 4.3.2.1 自动标注流程

元策略分类器采用监督学习训练，其训练数据由仿真环境自动生成，无需人工标注。对 5 个干扰数量档位（6、9、12、15、18 个干扰源）各采集 800 个随机场景，共计 4000 条样本。每个场景的采集流程如下。

第一步，环境重置。依据第二章表 2-4 的场景 B 设置随机初始化目标与干扰源的数量、幅度、距离、速度与到达延迟。

第二步，warmup（60 帧）。前 54 帧对全部 9 个 (f\_c, t\_d) 配置作系统性扫描，每个配置各使用 6 帧（9 × 6 = 54）；后 6 帧由执行层以随机策略探索。设置 warmup 的目的有两个：其一，如 4.2.2.1 节所述，EMA 只在配置被实际使用时才更新，系统性扫描保证了 9 个配置的 EMA 均获得有效观测；其二，每个配置重复 6 帧而非仅 1 帧，是为了通过多次观测平滑掉热噪声与目标幅度随机性所带来的单帧波动。

第三步，计算各元策略的期望 SINR。自 oracle 表读取 3×3 无噪声 SINR 值，分别计算三种元策略的期望性能

joint\_best = max\_\{i,j\} SINR(i, j) (4-23)

freq\_best = mean\_j \[ max\_i SINR(i, j) \] (4-24)

time\_best = mean\_i \[ max\_j SINR(i, j) \] (4-25)

其中式(4-24)的含义是：频域优先策略固定当前时延、仅在频点间搜索，故在给定时延 j 下其可达的最优结果为 max\_i SINR(i, j)；由于标注时当前所处的时延未定，故对 j 取平均以得到该策略的期望性能。式(4-25)同理。
> 口径修正：本文以策略定义为准。freq\_only 固定时延 j、在频点 i 上搜索，因此应为 freq\_best = mean\_j\[max\_i SINR(i,j)\]；time\_only 固定频点 i、在时延 j 上搜索，因此应为 time\_best = mean\_i\[max\_j SINR(i,j)\]。专利说明书中的文字恰好写反，应在后续专利文本中同步更正。代码必须按上述公式核对；若历史训练代码采用了相反定义，则两类单维度标签被互换，随机森林准确率、特征重要性与第四章全部 Meta-RF 结果均需重新训练和复算，在完成前只能视为暂定结果。   

第四步，标签生成。以联合探索相对最优单维度策略的优势作为判据

标签 = joint, 若 joint\_best − max(freq\_best, time\_best) \> 0.3 dB
 标签 = argmax\{freq\_best, time\_best\} 所对应的单维度策略, 否则 (4-26)

其含义是：只有当联合探索确实比最好的单维度策略高出 0.3 dB 以上时，才认为值得付出在 9 维空间中搜索的代价；否则宁可选择搜索空间更小的单维度策略。0.3 dB 这一阈值可与第 3.3.1 节所导出的切换当量相对照：一次单维度切换所折算的 SINR 当量在低 SINR 处约为 0.55 dB，故 0.3 dB 的阈值略为偏低，即标签生成准则相对偏向选择联合探索，是一个保守（更倾向于不限制执行层）的设定。

第五步，特征替换。依 4.2.2.2 节的说明，以 oracle 值替代 EMA 估计来计算 fc\_gap、td\_gap 与 fc\_td\_ratio 三个特征，消除标签噪声。

### 4.3.3 特征重要性与可解释性分析

依式(4-22)提取十二维特征的重要性，结果如图 4-8 所示，其排序与数值可归纳为四条结论。

结论一，决策的核心是比较两个维度的机会大小。fc\_td\_ratio 的重要性最高（约 0.32），表明元控制器首要判断的是“频域与时域哪一个潜在收益更大”，并据此决定把搜索资源投向哪一维。这与 4.1.2 节表 4-1 中以 fc\_td\_ratio 的符号作为触发条件的设计完全吻合，即分类器自主学到的判别依据与人工设计的策略语义一致。

结论二，决策依据是“改善上限”而非“当前水平”。fc\_gap 与 td\_gap 的重要性次之（各约 0.22），三个维度敏感性特征合计约占 0.76。这说明元控制器的判断主要基于“调整某一维度能带来多大的极限提升”，而非基于当前的平均信号水平。这一点与执行层形成了鲜明对照：执行层的输入是当前 SINR，其决策必然是对现状的响应；而元策略层的输入以潜在收益为主，其决策是对机会的评估。

结论三，当前 MDI 重要性结果显示维度敏感性特征占主导，但不能据此推出“战略层已从战术细节中抽离”或形成因果解释。按已给的四舍五入数值，fc\_td\_ratio、fc\_gap 与 td\_gap 合计约 0.76，r\_avoid 与 H\_action 分别约 0.07 与 0.05，余下 7 个特征合计仅约 0.12；因此原稿再称“σ、H\_action 与两个切换率合计约 0.12～0.15”既重复计入 H\_action，也与总和上限冲突。更重要的是，随机森林的基于不纯度下降的重要性会受到特征尺度、取值数目与相关性的影响，只能作为模型内部的描述性指标。定稿时应补充置换重要性或 SHAP，并在独立数据上验证排序稳定性。

结论四，整体呈现“机会驱动”的战略思维。综合前三条，元控制器的决策链条围绕“哪个维度存在更好的干扰空穴”展开，而非被动地响应信号恶化。这是一种主动寻优而非被动响应的高层认知模式，与执行层的反应式决策构成互补。

预验证结论与实测重要性之间存在一处张力，需加解释。4.2.3 节的预验证指出 σ 与 H\_action 具有最强的场景区分能力，而本节的实测重要性中二者却分别低于 0.04 与仅为 0.05。这两个结论看似矛盾，实则回答的是不同的问题，其原因有两点。

其一，二者所区分的类别不同。σ 与 H\_action 能够很好地区分“稳定”与“动态”两大类场景，即回答“是否需要联合探索”；但它们无法区分“频域密集”与“时域密集”，即无法回答“两类单维度策略选哪一个”。而在三分类任务中，后一个判别问题涉及两类标签、样本占比更大且边界更难，因此在整体不纯度下降中占据更大的份额。式(4-22)所度量的是特征在整个三分类任务中的总贡献，故在“单维度二选一”上具有决定作用的三个维度敏感性特征自然获得更高的权重。

预验证与 MDI 排序回答的问题不同，相关特征之间也可能分摊重要性，因此不能仅凭单个特征权重较低就删除特征。不过，在没有完整 feature\_importances\_ 数组之前，不再给出“某四项合计 0.12～0.15”这一无法由现有数值自洽推出的范围。是否移除切换率特征，应通过交叉验证性能、置换重要性与特征提取耗时的联合消融决定。

依据上述分析，后续可从三个方向进一步优化。一是特征精简，两个切换率特征的信息增益有限且存在信息循环，可考虑移除以降低特征提取的计算开销，这亦有助于缓解第二章表 2-2 所反映的端到端耗时问题。二是关键特征强化，既然维度敏感性特征是决策核心，则提升其估计精度（如改进 EMA 的聚合方式或引入更长的观测窗）应能直接提升分类精度。三是鲁棒性调优，针对 fc\_td\_ratio 接近 0 时类别边界模糊的问题，可考虑引入“两维度收益接近”作为第四类标签、直接映射为联合探索，从而把边界模糊区从二选一问题中剥离出去。

### 4.4.3 计算开销与消融分析

元策略层的计算开销已在第二章表 2-2 中给出，此处重述其要点并作定位。随机森林单次推理耗时约 0.3 ～ 0.5 ms，相对 K = 3 帧（23.0 ms）的决策周期余量约 46 倍，算法本身的推理环节完全满足实时约束。而在当前实现下，12 维特征提取与随机森林推理的端到端总耗时约 99.6 ms，超出决策周期约 4.3 倍。该数值反映的是当前 Python 仿真实现的计算开销，不表示本文方法已满足 23.0 ms 决策周期下的工程实时部署要求，这一点必须明确说明。其瓶颈在于特征提取的实现方式：现有实现在每个决策周期对整个长度为 W 的窗口重新计算全部统计量，而这些统计量原则上均可增量式滑动更新（其单次更新的计算量与 W 无关），因此该开销属于实现层面的工程问题而非算法层面的固有瓶颈。4.3.3 节所提出的特征精简（移除两个信息增益有限的切换率特征）亦可直接减少这一开销。

本文未构建大语言模型基线，也没有在同一硬件与相同任务条件下测量其端到端时延、分类准确率或置信度校准。因此，本节删除“100～500 ms”以及“轻量模式识别一定优于大模型”的无来源比较。当前随机森林方案的可复现实测结论应限于本方法自身：分类器单次推理约 0.3～0.5 ms，但特征提取与推理端到端约 99.6 ms，后者尚不满足 23.0 ms 的名义决策周期。

## 4.5 本章小结

本章在第三章深度强化学习执行层之上引入基于模式识别的元策略控制器，形成“场景感知 → 特征提取 → 策略分类 → 软引导 → 执行层”的分层决策闭环。主要工作与结论如下。

其一，明确了元策略层试图弥补的信息缺口。执行层每帧只观测当前配置下的标量 SINR，而完整比较 9 个配置至少需要 9 次观测；69.1 ms 只是顺序扫描的时间下界。它是否与环境变化时间尺度同量级，必须由干扰动态模型或实测数据证明，不能据此断言“试探永远追不上环境变化”。当前元策略的维度敏感性特征由逐配置仿真值构造，属于 oracle 辅助信息；工程实现需改为可在线观测的估计量，并重新训练与验证。

其二，设计了十二维场景语义特征。特征分为信号质量统计、执行层行为、避干扰效能与维度敏感性四类。前三类共九维描述“现状好不好”，第四类三维回答“哪个维度还有多大提升空间”，后者是 DRL 从标量反馈中无法获得的结构性信息。维度敏感性特征借助逐配置的指数移动平均在线估计，其等效时间常数约 2.8 帧、有效响应时间约 3 ～ 4 帧（23 ～ 31 ms）。本章亦如实指出了该机制的两项限制：EMA 只在配置被实际访问时才更新，故需 warmup 阶段的系统性扫描；以及 oracle 表的可得性是一项假设性前提，实车部署需以实测扫描或干扰参数估计替代。

其三，设计了软引导与策略持久化两项层间协同机制。软引导以 bonus = base\_bonus × p² 对允许动作施加正偏置而不删除其他动作，能够保留执行层的候选集合与纠错通道；但正偏置可能改变动作排序，不能推出最坏情况下等价于或不劣于 Pure DRL。策略持久化中，同标签预测继续累计保持时长，只有实际切换才重置计数。关于切换频率降低约 40% 的说法尚缺完整对照日志，当前仅列为待验证观察。

其四，随机森林在当前数据集上取得约 80%～85% 的分类准确率，并能输出投票比例与基于不纯度的特征重要性。但投票比例未经校准时不能直接视为可靠概率；MDI 重要性对特征基数、相关性与训练样本分布敏感，只能作描述性分析。fc\_td\_ratio 约 0.32、三个维度敏感性特征合计约 0.76，说明模型在当前 oracle 生成数据上主要依赖这些特征。由于训练标签与这些特征来自同一逐配置 oracle 规则，二者一致并不是独立的可解释性或可信性证明，仍需以置换重要性、SHAP、外部测试集及可在线观测特征验证。

其五，在当前 oracle 辅助仿真设置下，Meta-RF 在场景 B 的样本均值为 −1.32 dB、避开率为 90.0%，相对 Pure DRL 高 5.10 dB 与 4.5 个百分点；在训练未覆盖的两个干扰数量档位上高 2.4～3.8 dB；Exp-D 中恢复帧数约为 5 帧对 8 帧。上述数字是同一仿真生成器下的描述性结果，而不是独立元策略净增量、统计显著性、通用分布外泛化或工程部署的证明。定稿前须补无 oracle、相同 warmup、机制消融、多随机种子与外部场景验证。

至此，全文已给出执行层与元策略层的方案、仿真实现和初步样本结果，但仍存在 oracle 信息依赖、GRU 回放实现待核、T80 统计口径冲突、机制消融不完整以及端到端时延超周期等问题。下一章据此总结已完成工作，并明确不能由现有证据支持的结论与后续验证方向。

# 第五章 总结与展望

## 5.1 总结

汽车雷达相互干扰会降低目标探测可靠性。本文聚焦调频斜率与脉冲重复周期相同或接近时的高相干干扰：此类干扰可能在处理域中与真实回波高度相似，使仅依赖样式差异的接收端分离方法面临困难。但接收端重建、联合估计、多通道处理等方法并非原理上全部失效；发射参数调整是本文选取的一条技术路径，而不是唯一可能方案。

本文研究 FMCW 雷达高相干干扰环境下的时、频域联合参数调整方法，建立信号级仿真平台，将决策过程建模为部分可观测马尔可夫决策过程，并构造监督学习元控制器与深度强化学习执行器组成的两层混合框架。本文仅在受控仿真中评估该框架；实验仍受 oracle 信息、GRU 回放实现、消融完备性与多随机种子统计不足等限制，不能视为实车有效性或工程实时性的证明。

**（1）面向相干干扰的分层抗干扰决策架构与时间尺度分离机制**

本文建立 FMCW 雷达与干扰的仿真模型，并以一帧为决策单位。帧内保持 f\_c 与 t\_d 不变有助于保留帧内慢时间相干性，但不能据此推出跨帧处理、目标检测性能或工程波形连续性完全不受影响。战术与战略两个更新周期的差异为设置执行层与元策略层提供了设计动机；由于上层是监督学习分类器、下层才是强化学习执行器，本文更准确的定位是“受 HRL 时间抽象思想启发的混合分层框架”，而非经典端到端分层强化学习。双线程与配置缓冲区可避免上层计算阻塞发射线程，但当前端到端约 99.6 ms 高于 23.0 ms 元决策周期，仍会造成策略陈旧，需经增量更新和硬件验证。

**（2）基于 Double DQN 与 GRU 的抗干扰策略执行层及其训练效率机制**

执行层的算法选择基于四项工程条件：转移模型未知、训练采用有限幕截断、希望借助经验回放复用样本、动作空间离散且规模较小。本文据此采用基于价值函数的异策略时序差分方法。这里的 Off-Policy 统一译为“异策略”，不使用会与 Offline RL 混淆的“离线策略”；同策略或蒙特卡洛方法并非原理上不可用。Double Q-Learning 用于减轻 max 操作与估计噪声共同造成的价值过估计。网络采用单帧观测配合 GRU 隐状态承载历史信息，但其与经验回放结合时必须使用连续序列并正确处理隐状态；该实现细节仍需代码证据确认。

在场景 A 的 100 幕测试样本中，时、频域联合策略取得 9.50 ± 0.57 dB 的平均 SINR 与 91% 的避开率；仅频域与仅时域方案分别为 8.24 ± 3.20 dB 与 7.78 ± 4.62 dB。该结果显示联合方案在当前样本集上的均值更高、波动更小，但未提供多随机种子重复实验、置信区间或显著性检验。时序建模贡献约 2.3 dB 的消融解释，还需先确认 GRU 使用连续序列回放并正确处理隐状态；否则不能把差值归因于可靠的时序记忆。

**（3）基于场景语义特征与随机森林的元策略控制器及软引导协同机制**

本文将执行层的信息缺口表述为：每帧只观测当前配置的一个标量 SINR，而完整比较 9 个配置至少需要 9 次观测。69.1 ms 只是顺序扫描的时间下界，是否足以落后于环境变化需由动态模型或实测数据验证。元策略使用逐配置 EMA 构造维度敏感性特征并把搜索组织为“先选维度、再在维内选择”；这些逐配置值在当前仿真中带有 oracle 信息，尚不是可直接部署的在线观测。软引导不删除候选动作，但其正偏置仍可能改变动作排序，因此不存在由公式自动给出的 Pure DRL 性能下界。策略持久化的约 40% 降频结论也需补做对照实验。

在当前 oracle 辅助仿真设置下，Meta-RF 在场景 B 的平均 SINR 样本值比 Pure DRL 高约 5.1 dB、避开率高 4.5 个百分点；在训练未覆盖的两个干扰数量档位上高 2.4～3.8 dB；Exp-D 的恢复帧数约为 5 帧对 8 帧。这些结果只支持同一仿真生成器与给定信息条件下的描述性比较，不能证明统计显著性、通用分布外泛化、独立元策略净增量或实车有效性。随机森林投票比例尚未校准，MDI 特征重要性也只能说明模型在当前 oracle 生成数据上的依赖，不能把“与人工规则一致”当作独立可解释性证明。

贯穿三项工作的更稳妥结论是：在当前受控仿真中，混合分层方案在若干均值、T80 与动态恢复指标上取得较好样本结果，但尚不能确定增益来自元策略、oracle 初始化、软引导或其他机制，也不能证明其只改善适应速度而不改变稳态性能。关于“突变场景更能体现元策略价值”的说法应视为待检验假设；本文结果也不直接外推到其他认知无线电、认知雷达或实车场景。

## 5.2 未来工作展望

本文提出并验证了面向相干干扰的两层分层抗干扰决策方法，但受研究条件与篇幅所限，仍有若干不足有待后续解决。

**（1）维度敏感性估计对 oracle 的依赖。** 本文第四章的维度敏感性特征（fc\_gap、td\_gap 与 fc\_td\_ratio）在训练阶段以仿真环境中穷举计算所得的无噪声 SINR 表替代在线估计以消除标签噪声，在测试阶段亦以该表在 warmup 结束时种子化指数移动平均状态。该表在仿真中容易得到，在实际车载系统中却无从获得，因而构成本文方法最主要的假设性前提。后续可从两条路径替代：其一，以 warmup 阶段对 9 个参数配置的实测扫描结果替代 oracle 表，此时需评估扫描期间探测性能受损的代价以及测量噪声对分类精度的影响；其二，借助独立的干扰参数估计模块推算各配置下的预期 SINR，此路径的可行性取决于干扰中心频率、到达延迟与幅度估计的精度，而相干干扰参数的精准估计本身即是一个尚未充分解决的问题。本文还假设接收信号的 SINR 可以被准确估计，该假设如何放宽亦有待研究。

**（2）时间粒度与工程实时性。** 本文以帧（7.68 ms）为决策单位，这一选择保证了帧内相干积累的完整性，代价是对突发干扰的最快响应延迟为一帧。如何在“帧内参数不变以保障多普勒处理”与“更快响应突发干扰”之间取得更好的折中，例如采用自适应帧长，或在帧内以子帧粒度作粗判而仅在帧边界执行参数切换，是值得研究的方向。实时性方面，当前实现下元策略层特征提取与推理的端到端耗时约 99.6 ms，而元策略层的决策周期为 23.0 ms，单次推理无法在一个决策周期内完成。瓶颈在于每个决策周期都对整个窗口重新计算全部统计量，而这些统计量原则上均可增量式滑动更新，故属实现层面的工程问题。后续需完成增量式滑窗改造、定点化运算以及在 C 或 FPGA 平台上的重实现，并在硬件在环条件下验证其实时性。

**（3）元策略层的端到端学习。** 如 2.3.1 节所述，本文的高层并非通过强化学习自动习得的选项，而是以监督学习方式训练的模式识别器，这一取舍出于实时性与可解释性的工程考虑。其代价是元策略的标签依赖式(4-26)所给出的人工标注准则，该准则中“联合探索相对单维度策略的优势超过 0.3 dB”这一阈值由人为设定，最优性未经论证。后续可尝试以强化学习方式端到端地训练高层策略，例如采用 option-critic 框架同时学习选项的内部策略与终止条件，或以半马尔可夫决策过程上的 Q 学习直接优化元策略的选择，从而摆脱对人工标注准则的依赖，并有可能发现人工设计之外的策略划分方式。其中的关键问题是如何在保持亚毫秒级推理耗时与决策可解释性的前提下引入学习型高层。

（4）干扰类型与可调维度的扩展。本文聚焦高相干干扰，而实际道路中还存在不同带宽、斜率与扫频时长组合造成的非相干或部分相干干扰。后续可把调频斜率、带宽等纳入动作空间，研究其对频谱重叠、拍频占用和检测性能的影响；调整斜率可能改变干扰在接收带宽内的形态，但不能预先假定其会把非相干干扰“转化为可处理的相干干扰”。动作空间从离散档位扩展到连续参数时，还需重新设计安全约束、探索机制与评价指标。

（5）多智能体场景下的协同抗干扰。现实中多部雷达同时自适应会形成非平稳博弈，可能出现配置追逐或振荡。后续可研究集中式训练、分布式执行等多智能体方法，并比较无通信、有限通信与协同调度三种信息条件。CTDE 不保证在仅有局部观测时自动达到稳定均衡；需要显式报告收敛性、频谱公平性、碰撞率和最坏车辆性能，并考虑通信时延与安全约束。

**（6）实验完备性与从仿真到实测的验证。** 本文的消融实验尚不完备：第三章仅对时序建模组件完成了消融，分段奖励、动作代价项、目标网络更新方式与损失函数形式四项的独立贡献未经实验分离；第四章仅完成了移除整个元策略层的消融，软引导相对硬掩码的实际收益、策略持久化在信干噪比层面的贡献以及窗口参数 W 与 K 的敏感性均有待补充。更为关键的是，本文所提出的方法均仅经过仿真验证，而现实世界的电磁环境与道路状况远比仿真场景复杂：多径反射、杂波、反射式干扰、非理想低通滤波与射频前端的非线性等因素本文均未予建模，方法的鲁棒性与泛化性有待实测检验。后续应搭建基于商用汽车雷达芯片的实验平台，先以硬件在环方式复现关键实验，再逐步过渡到实车道路测试。这既是本文方法走向实用的必经环节，也是雷达抗干扰方法落地时共同面对的难题。
