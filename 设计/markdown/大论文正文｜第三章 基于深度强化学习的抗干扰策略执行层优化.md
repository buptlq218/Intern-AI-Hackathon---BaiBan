## 3.1 抗干扰策略执行层的优化目标

第二章 2.3.2 节已界定了两层架构的职责边界：元策略层判断"当前处于什么干扰场景、应当在哪个维度上重点搜索"，执行层则负责"在给定的动作子空间内尽快找到最优的 (f\_c, t\_d) 配置并稳定维持"。本章的全部工作都服务于后一个问题。执行层的设计必须在不依赖元策略层的条件下独立成立。一方面，这是分层架构可分阶段验证的前提；另一方面，依据 2.3.2 节所述的容错性质，当元策略层判别失准或尚未启用时，系统的行为退化为纯执行层的行为，执行层自身的性能水平因而决定了整个系统的性能下界。

据此，本章的优化目标可以拆解为两点。

**其一，环境感知能力。** 依据 2.2.3 节的分析，雷达在每一帧只能观测到一个标量 SINR，无法直接获知干扰源在时、频域上的分布。这意味着若智能体仅对当前帧的 SINR 数值作出反应，其决策必然是盲目的：同一个 SINR 数值既可能出现在"干扰分布稀疏、只是恰好当前配置被占用"的情形下，也可能出现在"干扰密集、所有配置都不理想"的情形下，而这两种情形的最优动作截然不同。因此执行层必须能够从 SINR 的时间序列中推断干扰分布结构。例如，若连续数帧内无论如何切换频点 SINR 都很低，则可推断频域已被大量占用；若某次切换时延后 SINR 显著改善，则可推断时域尚有余量。本章通过门控循环单元对观测序列建模来获得这一能力。

**其二，样本学习效率。** 本文的联合动作空间规模为 9，绝对数值不大，但强化学习所面对的困难并不只在于动作空间的规模：由于每一幕开始时目标与干扰均被随机初始化，同一个状态在不同幕中所对应的最优动作可以完全不同，采样数据的方差很大，训练过程因而既缓慢又不稳定。为此需要在探索策略、奖励设计、目标值计算与优化过程等多个环节采取措施，使智能体能在有限的交互帧数内收敛到近最优策略，并且收敛后的策略表现稳定、不发生持续抖动。

执行层的输出为每一帧所使用的参数状态索引 a ∈ \{0, 1, …, 8\}，其向上层提供的接口为第 3.3.2 节所定义的动作掩码接口：上层通过下发 Q 值偏置向量对执行层实施策略级调控，而执行层的网络结构、训练方式与推理流程均不因上层是否存在而改变。

## 3.2 基于深度强化学习的抗干扰策略实现

### 3.2.1 抗干扰策略的执行闭环流程

执行层以帧为周期运行如图 3-1 所示的闭环。设当前为第 t 帧，其执行流程如下：

**① 发射。** 以当前参数状态 (f\_c, t\_d) 发射一帧 FMCW 信号，该帧含 L = 128 个 chirp，帧内参数保持不变。

**② 接收与解调。** 接收由目标回波、干扰信号与噪声叠加构成的混合信号，与参考信号混频完成 Dechirp，再经低通滤波得到拍频信号。依据 2.1.4 节的机制，凡与参考信号频率差超过 f\_bmax 的干扰成分在此环节即被滤除，不进入后续处理。

**③ 距离多普勒处理与 SINR 估计。** 对拍频信号在快时间维与慢时间维各作一次 FFT 得到 RDM，依据式(2-16)估计本帧的 SINR(t)。

**④ 状态更新。** 依据式(2-48)构造本帧的基础状态 s\_t = \[a(t−1), r(t−1), SINR(t)\]，其中动作分量以表 2-1 的独热编码展开；GRU 的隐状态自上一帧延续而来，与本帧观测共同构成网络的输入。

**⑤ 动作选择。** 将状态送入 Q 网络得到各动作的价值估计 Q(S\_t, a)，叠加元策略层通过 DAM 接口下发的偏置（若未启用元策略层则偏置为零向量），按 ε-greedy 策略选择下一帧所使用的动作 a\_t。

**⑥ 经验存储与网络更新。** 计算本帧的即时奖励 r\_t，将转移四元组 (S\_t, a\_t, r\_t, S\_\{t\+1\}) 存入经验回放缓冲区；自缓冲区中随机采样一个小批次进行一次梯度更新，并对目标网络作一次软更新。

上述①～③属于环境的响应过程，由 2.4.1 节所述的信号级仿真平台完成；④～⑥属于智能体的决策与学习过程。二者交替进行，构成 2.2.2 节所建模的 MDP 交互轨迹。

### 3.2.2 从 Q-Learning 到 Double Q-Learning

#### 3.2.2.1 强化学习算法的选型

依据 2.2.1 节的分析，求解最优策略可以转化为求解式(2-46)所定义的最优状态—动作价值函数 q\_*(s, a)。一般而言，求解 q\_* 有三类方法：动态规划法、蒙特卡洛法与时序差分法。

**动态规划法**属于基于模型（Model-Based）的方法，它需要完整的状态转移概率分布，通过迭代求解贝尔曼最优方程组得到 q\_\*。**蒙特卡洛法**与**时序差分法**（Temporal Difference，TD）均属于无模型（Model-Free）方法，二者不需要显式的状态转移概率，而是直接从与环境交互所采集的样本中学习。其区别在于：蒙特卡洛法需要完整的采样轨迹来更新价值估计，这要求每一幕都有明确的终止状态；而时序差分法只需一步转移即可利用自举（Bootstrap）进行更新。

本文选择时序差分法是工程取舍，而非“场景决定只能如此”。动态规划通常依赖已知或可求的转移模型，本文难以满足；蒙特卡洛方法可以通过有限幕截断、平均回报等方式处理持续任务，并非原理上不可用，但其更新要等待完整轨迹、样本利用方式与本文的逐步在线更新目标不匹配。因此，本章采用可逐步自举、适合与经验回放结合的时序差分方法。

在时序差分方法中，可按行为策略与目标策略是否相同区分为同策略（On-Policy）与异策略（Off-Policy）方法。“Off-Policy”不应译为“离线策略”，因为离线强化学习（Offline RL）特指仅使用固定数据集、训练期间不再与环境交互的另一类问题。Q-Learning 属于异策略方法：行为策略可用 ε-贪心采样，而更新目标使用贪心动作。异策略方法能够配合经验回放重复利用历史转移，但重复利用并非没有代价，仍需关注分布偏移、函数逼近与自举共同导致的不稳定性；同策略方法也不等同于“样本只能使用一次”，不能以此作为排除依据。

综合而言，本章的选择依据可归纳为四点：状态转移模型未知，因而采用无模型方法；任务虽持续运行，但训练以有限幕截断，采用时序差分自举更便于逐步更新；希望通过经验回放提高样本利用率，因而选择异策略方法；动作空间离散且规模较小，适合采用基于动作价值的方法。在这些条件下，本文选择 Q-Learning 族算法，并用深度神经网络近似动作价值函数。该选择是工程取舍，不表示蒙特卡洛法、同策略算法或策略梯度方法在原理上不可用。

#### 3.2.2.2 Q-Learning 与深度 Q-Learning

传统的 Q-Learning 属于表格型求解法（Tabular Solution Method），它维护一个称为 Q 表（Q Table）的数组，其中存放所有状态—动作对的价值估计 Q(s, a)。在任一状态下只需查表即可得到各动作的价值，若执行贪心策略，则按

a\_t = argmax\_\{a∈A\} Q(s\_t, a) (3-1)

选择动作。Q-Learning 以如下方式更新价值函数

Q(s\_t, a\_t) ← Q(s\_t, a\_t) \+ β·δ\_t (3-2)

其中 β 为学习率（或称更新步长），δ\_t 为时序差分误差

δ\_t = r\_\{t\+1\} \+ γ·max\_\{a′∈A\} Q(s\_\{t\+1\}, a′) − Q(s\_t, a\_t) (3-3)

式(3-3)中的 max 操作使更新目标对应贪心目标策略，而实际采样动作可由含探索的行为策略产生，因此 Q-Learning 属于异策略（Off-Policy）方法。这里的“异策略”不等同于离线强化学习；本文训练过程中仍持续与仿真环境交互。

尽管表格型 Q-Learning 的收敛性有理论保证，但它只能处理离散且规模有限的状态空间。对于本章的 MDP 模型，状态中的 SINR 取值是连续的，加之 2.2.3 节所引入的历史观测，状态空间是高维且不可数的，无法用 Q 表枚举。为此，采用深度神经网络来拟合 Q 表，即以网络参数 θ 所确定的函数 Q(s, a; θ) 近似真实的价值函数，该方法称为**深度 Q-Learning**，所使用的网络称为深度 Q 网络（Deep Q Network，DQN）。深度 Q-Learning 的动作选择与时序差分误差在形式上与式(3-1)、式(3-3)一致，而训练时网络的更新目标即为最小化时序差分误差的平方。

深度 Q-Learning 在训练中依赖三项关键技巧，本文均予采用。

**（1）ε-贪心探索（ε-Greedy Exploration）。** 强化学习面临探索—利用困境（Exploration–Exploitation Dilemma）：探索指尝试尚未充分评估的动作，利用指按式(3-1)选择当前价值估计最大的动作。在训练前期智能体尝试过的动作较少，若自始至终只执行贪心策略，则容易形成"先入为主"的偏差，即因缺乏探索而无法对所有状态—动作对形成正确的价值评估，从而陷入次优动作。ε-贪心探索以概率 ε 随机选择动作以缓解该困境

a\_t = argmax\_\{a∈A\} Q(s\_t, a)，以概率 (1 − ε)； a\_t ~ U(A)，以概率 ε (3-4)

训练中一般需要前期以探索为主、后期以利用为主，故 ε 的初值取较大值并随训练逐渐衰减至一个较小值。

（2）序列经验回放（Sequential Experience Replay）。循环 Q 网络的回放单元应为同一幕内的连续片段，而不是彼此独立的随机单步转移。每个片段包含连续的 (s\_t, a\_t, r\_t, s\_\{t\+1\}) 序列；在片段起点重置隐状态，或用 burn-in 前缀恢复隐状态，再对后续时间步计算损失。不同片段之间可以随机抽样，以降低批次间相关性并复用历史数据。若当前代码仍按普通 DQN 从缓冲区随机抽取 256 个独立转移并保持 stateful 状态，则回放样本与隐状态历史不匹配，需要先修正实现再采信 GRU 消融结论。正文中的“批大小 256”也应明确是序列条数还是时间步总数。

**（3）双网络与延迟更新。** 在提出 DQN 的工作中，作者即使用了两个结构相同的网络：估计网络 Q\_eval 与目标网络 Q\_tar，其参数分别记为 θ 与 θ⁻。采样与动作选择时使用 Q\_eval 计算动作价值，而计算时序差分目标值时使用 Q\_tar。经验回放直接更新 Q\_eval，其损失函数为

L(θ) = E\_\{(S,a,r,S′)~D\} \[ ( r \+ γ·max\_\{a′\} Q(S′, a′; θ⁻) − Q(S, a; θ) )² \] (3-5)

而 Q\_tar 每隔若干时间步同步至 Q\_eval，即 θ⁻ ← θ，称为延迟更新（Delayed Update）。双网络的作用在于稳定学习目标：若只用单个网络同时产生预测值与目标值，则每次更新在改变预测值的同时也改变了目标值，等效于在追逐一个不断移动的靶子，训练难以收敛。

#### 3.2.2.3 价值过估计与 Double Q-Learning

深度 Q-Learning 存在一个系统性偏差，即**价值过估计**（Overestimation）。其根源在于式(3-3)中的 max 操作与自举的组合。设 Q(S′, a′; θ⁻) 是对真实价值 q(S′, a′) 的无偏估计，即对每个 a′ 有 E\[Q(S′, a′; θ⁻)\] = q(S′, a′)，但由于最大值函数是凸函数，依据 Jensen 不等式有

E\[ max\_\{a′\} Q(S′, a′; θ⁻) \] ≥ max\_\{a′\} E\[ Q(S′, a′; θ⁻) \] = max\_\{a′\} q(S′, a′) (3-6)

即使每个动作的价值估计都是无偏的，取最大值这一操作本身也会引入正偏差。其直观解释是，max 操作总是选中那个恰好被估计得偏高的动作，把估计噪声系统性地转化为向上的偏差。在自举机制下，这一偏差会随目标值被反复代入而在时间上累积传播，导致训练时策略不稳定、收敛速度慢、智能体对某些动作过度自信，最终使策略性能下降。

Double Q-Learning 将动作的选择与该动作价值的评估相分离，以抑制这一偏差。其在双网络的基础上仅对目标值的计算作了简单改动，时序差分目标值改为

y = r \+ γ·Q( S′, argmax\_\{a′\} Q(S′, a′; θ) ; θ⁻ ) (3-7)

即先用估计网络 Q\_eval 选出后继状态下的贪心动作 a′\* = argmax\_\{a′\} Q(S′, a′; θ)，再用目标网络 Q\_tar 评估该动作的价值。由于选择与评估使用了两套不同的参数，"恰好被 Q\_eval 估计得偏高"的动作并不必然也被 Q\_tar 估计得偏高，正偏差因而被显著削弱。相应地，式(3-5)的损失函数改写为

L(θ) = E\_\{(S,a,r,S′)~D\} \[ ( r \+ γ·Q(S′, argmax\_\{a′\} Q(S′, a′; θ); θ⁻) − Q(S, a; θ) )² \] (3-8)

本章采用 Double DQN 作为执行层的强化学习算法，并在训练中使用上述三项技巧。本章还对目标网络采用软更新而非硬同步、对损失函数采用 Huber 损失而非平方损失，相关设计在 3.2.4 节说明。

### 3.2.3 GRU 时序建模与 Q 网络结构设计

#### 3.2.3.1 全连接层与激活函数

DQN 最常用的网络形式是由多层全连接层（Fully Connected Layer，FCL）堆叠而成的深度神经网络（Deep Neural Network，DNN）。对于单层全连接层，设其输入向量为 x ∈ ℝ^d、权重矩阵为 W ∈ ℝ^\{d×h\}、偏置为 b ∈ ℝ^h，则该层的输出为

y = Wᵀx \+ b (3-9)

显然上式为线性变换，若仅单纯堆叠线性变换，其复合结果仍为线性变换，模型的表征能力十分有限。因此通常在全连接层之后使用激活函数（Activation Function）对输出作非线性变换，以提升网络的函数拟合能力。本章所使用的激活函数为

sigmoid(x) = 1 / (1 \+ e^\{−x\}) (3-10)

tanh(x) = (1 − e^\{−2x\}) / (1 \+ e^\{−2x\}) (3-11)

ReLU(x) = max(x, 0) (3-12)

其中 ReLU 用于 DNN 的隐层，sigmoid 与 tanh 用于下述 GRU 的门控与候选状态计算。

#### 3.2.3.2 门控循环单元

依据 2.2.3 节的分析，执行层需要利用历史观测序列来缓解部分可观测性，而普通的全连接网络无法体现输入之间的时序关系。为此本章采用门控循环单元（Gated Recurrent Unit，GRU），它是循环神经网络（Recurrent Neural Network，RNN）的一种改进形式，通过门控机制缓解了朴素 RNN 在长序列上的梯度消失与遗忘问题。

如图 3-2 所示，GRU 含两个门，即重置门（Reset Gate）与更新门（Update Gate）。两个门的输入均由当前时间步的输入与前一时间步的隐状态共同给出，输出由使用 sigmoid 激活函数的全连接层产生。设时间步 t 的输入为 X\_t ∈ ℝ^\{n×d\}（样本数即批大小为 n，输入向量维度为 d），上一时间步的隐状态（Hidden State）为 H\_\{t−1\} ∈ ℝ^\{n×h\}（隐藏单元个数为 h），则重置门 R\_t ∈ ℝ^\{n×h\} 与更新门 Z\_t ∈ ℝ^\{n×h\} 的计算为

R\_t = sigmoid( X\_t·W\_xr \+ H\_\{t−1\}·W\_hr \+ b\_r ) (3-13)

Z\_t = sigmoid( X\_t·W\_xz \+ H\_\{t−1\}·W\_hz \+ b\_z ) (3-14)

其中 W\_xr, W\_xz ∈ ℝ^\{d×h\} 与 W\_hr, W\_hz ∈ ℝ^\{h×h\} 为权重参数，b\_r, b\_z ∈ ℝ^\{1×h\} 为偏置参数。接着，重置门 R\_t 参与候选隐状态（Candidate Hidden State）H̃\_t ∈ ℝ^\{n×h\} 的计算

H̃\_t = tanh( X\_t·W\_xh \+ (R\_t ⊙ H\_\{t−1\})·W\_hh \+ b\_h ) (3-15)

其中 W\_xh ∈ ℝ^\{d×h\}、W\_hh ∈ ℝ^\{h×h\} 为权重参数，b\_h ∈ ℝ^\{1×h\} 为偏置参数，⊙ 表示 Hadamard 积（按元素乘积）。最后，更新门 Z\_t 在旧隐状态 H\_\{t−1\} 与候选隐状态 H̃\_t 之间作按元素的凸组合，得到新的隐状态

H\_t = Z\_t ⊙ H\_\{t−1\} \+ (1 − Z\_t) ⊙ H̃\_t (3-16)

H\_t 同时也是 GRU 在该时间步的输出。两个门的作用可以这样理解：重置门决定在计算新的候选状态时对旧记忆的参考程度，当 R\_t 趋于 0 时候选状态几乎只由当前输入决定，等效于丢弃历史；更新门决定新的隐状态对旧记忆的保留程度，当 Z\_t 趋于 1 时隐状态几乎不变，等效于让信息跨越多个时间步无损传递。正是后一机制使 GRU 能够在较长的时间跨度上保持记忆。

对于本章的抗干扰问题，这两个门具有明确的物理对应：当干扰分布发生突变（例如干扰源集体跳频）时，历史观测所反映的干扰结构已经失效，此时重置门应当关闭以丢弃过时记忆；而当干扰分布稳定、智能体已找到干净配置时，更新门应当保持开启以维持对"当前配置可用"这一判断的记忆，避免因单帧的噪声波动而作出无谓的切换。

#### 3.2.3.3 Q 网络结构

本章所使用的 Q 网络结构如图 3-3 所示，由输入编码层、时序建模层与价值估计层三部分构成。

**输入层（三通道）。** 网络在每一帧接收三路输入：
- 动作通道：上一帧所采取动作的独热编码，维度等于动作空间大小，即 9 维；
- SINR 通道：当前帧由 RDM 估计所得的 SINR 标量，1 维；
- 隐状态通道：GRU 在上一帧的隐状态，32 维。

三通道设计与第二章修订后的状态定义一致：网络每帧接收上一动作的 9 维独热编码和当前 SINR 标量，共 10 维；历史信息由 GRU 隐状态承载，不再额外输入上一帧奖励。这样，编码层第一层参数量为 10×16 \+ 16 = 176，网络总参数量约 7.8×10³。需要强调的是，隐状态只有在样本顺序与真实时间顺序一致时才具有意义；训练阶段不能把互不相邻的随机单步样本直接接到同一个 stateful 隐状态之后。

**编码层。** 动作通道与 SINR 通道拼接为 10 维向量后，经两个全连接层 Dense(16, ReLU) \+ Dense(16, ReLU) 编码为 16 维的中间特征表示。设置编码层的作用在于：独热编码是稀疏的，而 SINR 是连续标量，二者的数值尺度与稀疏性差异很大，直接送入 GRU 会使循环层同时承担"特征变换"与"时序建模"两项任务；先经全连接层将其映射到稠密的中间表示，可使 GRU 专注于时序建模。编码结果经 Lambda 层扩展时间维度后送入 GRU 层。

**时序建模层。** GRU 层配置 32 个隐藏单元，并采用 **stateful 模式**，即隐状态在同一幕内跨帧持续传递，仅在每一幕开始时显式重置。这一配置是执行层获得环境感知能力的关键：若采用非 stateful 模式，则每帧推理时隐状态被清零，网络退化为只能看到当帧观测的无记忆模型，无法从 SINR 序列中推断干扰分布。3.4.3 节的消融实验将定量验证这一组件的贡献。

**价值估计层。** GRU 的输出经 Dense(64, ReLU) 作高维特征映射，最后经 Dense(9, Linear) 输出各动作的 Q 值估计。输出层不使用激活函数，因为动作价值的取值范围由奖励函数与折扣率共同决定，可正可负，不应受激活函数的值域限制。

各层的参数量可依式(3-9)与式(3-13)～(3-16)逐层计算：编码层第一层为 10×16 \+ 16 = 176，第二层为 16×16 \+ 16 = 272；GRU 层含三组权重与偏置，为 3×\[(16×32) \+ (32×32) \+ 32\] = 4704；价值估计层第一层为 32×64 \+ 64 = 2112，输出层为 64×9 \+ 9 = 585。合计约 7.8×10³ 个可训练参数。该参数规模远小于常见的深度视觉或语言模型，其单次前向推理的计算量相对于 7.68 ms 的帧周期余量充足（实测值见第二章表 2-2）。

### 3.2.4 训练机制与超参数设置

除 3.2.2 节所述的三项基本技巧与 Double Q-Learning 之外，本章在训练机制上还采用了四项稳定化措施。这些措施针对的是同一个困难：每幕随机初始化干扰分布使采样数据的方差极大，训练过程既缓慢又易发散。四项措施分别从目标值的平滑性、损失函数的稳健性、梯度的有界性与计算效率四个角度加以应对。

**（1）目标网络软更新。** 3.2.2 节所述的延迟更新采取每隔 C 步将 θ⁻ 硬同步至 θ 的方式，其缺点是在同步时刻目标值会发生跳变，训练损失曲线因而呈现周期性的尖峰。本章改用软更新（Soft Update）

θ⁻ ← τ·θ \+ (1 − τ)·θ⁻ (3-17)

在每一步更新后执行，软更新系数取 τ = 0.005。软更新使目标网络以指数滑动的方式平滑跟随估计网络，其等效时间常数约为 1/τ = 200 步，与硬同步间隔 C = 200 步大致相当，但目标值的变化是连续的，不产生跳变。

**（2）Huber 损失。** 式(3-8)所使用的平方损失对异常样本敏感：当某条转移的时序差分误差很大时（在本文场景中，这既可能源自干扰分布的突然变化，也可能源自随机初始化所带来的极端样本），平方损失所产生的梯度与误差成正比，会对网络参数造成过大的扰动。本章改用 Huber 损失

Huber(e) = ½·e², \|e\| ≤ δ； δ·(\|e\| − ½·δ), \|e\| \> δ (3-18)

取 δ = 1.0。即在误差较小时与平方损失一致以保证梯度的平滑性，在误差较大时退化为与绝对值误差成正比、其梯度被限制为常数 δ，从而抑制异常样本的影响。相应地，一个小批次上的损失为

L(θ) = (1/\|B\|)·Σ\_\{i∈B\} Huber( Q(S\_i, a\_i; θ) − y\_i ) (3-19)

其中 y\_i 为按式(3-7)计算的目标值，B 为该小批次。

**（3）梯度范数裁剪。** 在反向传播之后、参数更新之前，若梯度的 L2 范数超过阈值则按比例缩放至该阈值，本章取阈值为 1.0。该措施与 Huber 损失互补：Huber 损失限制的是单个样本对损失的贡献，梯度裁剪限制的是整个小批次所产生的参数更新幅度，二者共同防止训练过程中损失函数的爆炸。

**（4）混合精度训练。** 采用 FP16 与 FP32 混合精度进行前向与反向计算，在利用 GPU 的 Tensor Core 加速计算的同时降低显存占用。需要说明的是，该措施只影响训练效率而不改变算法本身。

优化器采用 RMSprop，学习率自 1×10⁻³ 按 episode 指数衰减至 1×10⁻⁵。学习率衰减与 ε 衰减在动机上是一致的：训练前期需要较大的步长以快速接近较优的参数区域，后期需要较小的步长以精细收敛并避免在最优解附近震荡。

关于折扣率的选取。本文取 γ = 0.95。1/(1−γ)=20 步（约 153.6 ms）只能作为折扣权重衰减尺度的直观近似，不能据此证明它与环境的真实时间常数“恰好匹配”，因为本文尚未测得该时间常数。γ 过小会弱化跨帧收益，过大可能增加价值估计方差，但 0.95 是否最优仍需通过 γ 的敏感性实验或验证集选择说明；在补充该实验前，应把 γ = 0.95 作为沿用的训练超参数，而不是由物理时间尺度严格推导出的数值。

## 3.3 策略训练效率机制设计

本节设计两项面向训练效率的机制。奖励函数决定了智能体"追求什么"，其形状直接影响价值函数的可学习性；动作掩码决定了智能体"在哪里搜索"，直接影响探索的有效性。二者共同构成执行层在有限交互帧数内收敛的保障，其中后者同时承担了向上层元策略提供调控接口的职能。

### 3.3.1 自适应分段激励的奖励函数设计

依据式(2-49)，即时奖励由信号质量奖励 r\_S 与动作切换代价奖励 r\_AC 两部分构成

r = r\_S \+ r\_AC (3-20)

**信号质量奖励的分段设计。** r\_S 依据当前帧的 SINR 分段计算

r\_S = α₁·(SINR − SINR₁) / \[ (SINR − SINR₁) \+ (SINR₂ − SINR₁) \], SINR ≥ SINR₁ (3-21)

r\_S = α₂·(SINR − SINR₁), SINR \< SINR₁ (3-22)

其中 SINR₁ 为正负奖励的判断阈值，实际中可依目标探测的要求设定；SINR₂ 为用于奖励归一化的 SINR 参考点，其取值通常与噪声等级（如 SNR）相关。本章取 SINR₁ = 0 dB、SINR₂ = 11 dB、α₁ = 1.0、α₂ = 0.1。奖励函数的形状如图 3-4 所示。

这一分段设计的动机在于，抗干扰问题中"SINR 的改善"在不同区间内具有截然不同的价值。

在 SINR ≥ SINR₁ 的正奖励区间，式(3-21)是一个双曲饱和型函数：其值自 SINR = SINR₁ 处的 0 单调递增，在 SINR = SINR₂ 处取得 α₁/2 = 0.5，并随 SINR → ∞ 渐近趋于 α₁ = 1.0。即 SINR₂ 是该函数的半饱和点。其边际收益为

dr\_S/d(SINR) = α₁·(SINR₂ − SINR₁) / \[ (SINR − SINR₁) \+ (SINR₂ − SINR₁) \]² (3-23)

随 SINR 的增大单调递减。这一形状对应了明确的工程意图：SINR 自 0 dB 提升至 11 dB 时，目标自"勉强可检测"变为"可靠检测"，这一段的改善直接决定目标探测性能，故奖励快速上升；SINR 超过 11 dB 之后，进一步提升对检测性能的边际贡献很小，奖励增长因而趋缓，以免智能体为追求无实际意义的更高 SINR 而付出额外的切换代价。

在 SINR \< SINR₁ 的负奖励区间，式(3-22)采用线性惩罚。此处不采用与正区间对称的饱和形式，是因为负区间的目标不是"精细区分有多差"，而是提供一个方向明确、幅度有界的驱动力，使智能体尽快逃离该区间。惩罚系数 α₂ = 0.1 取值较小，既对低 SINR 状态施加了负向激励，又避免了在极低 SINR（本文场景中 SINR 最低可达 −20 dB 量级）时产生过大的奖励绝对值，进而导致时序差分误差与梯度过大、训练不稳定。

正区间在分段点处的导数为 α₁/(SINR₂ − SINR₁) = 1/11 ≈ 0.0909，与负区间的斜率 α₂ = 0.1 十分接近。因此奖励函数在 SINR₁ 处连续，且近似一阶连续，不存在梯度的突变。这一性质对价值函数的拟合是有利的：若分段点处斜率相差悬殊，则该点附近的价值函数会出现难以被平滑网络拟合的折点。

**动作切换代价。** r\_AC 用于抑制策略的频繁抖动

r\_AC = −α₃·AC (3-24)

其中 AC 为式(2-50)所定义的动作代价，取值为 0、1 或 2；本章取 α₃ = 0.05，故 r\_AC ∈ \{0, −0.05, −0.10\}。

将式(3-24)与式(3-23)联立，可以给出该惩罚强度的定量解读：一次单维度切换的代价所"折算"的 SINR 当量，等于 α₃ 除以当前 SINR 处的边际收益。在 SINR ≈ 0 dB 处，该当量为 0.05 / 0.0909 ≈ 0.55 dB；而在 SINR ≈ 11 dB 处，边际收益降至 α₁·11/22² ≈ 0.0227，该当量升至 0.05 / 0.0227 ≈ 2.2 dB。这一随 SINR 升高而增大的切换门槛具有明确的行为学含义：智能体处于低 SINR 时，只要预期能带来 0.55 dB 以上的改善便值得尝试切换，反应因而积极；而当智能体已处于高 SINR 的稳态时，需要预期 2 dB 以上的改善才值得切换，行为因而趋于稳定。动作代价机制与饱和型信号奖励的组合，使智能体自发地表现出"低 SINR 时积极搜索、高 SINR 时稳定保持"的行为模式，而这一模式并未被显式编码到规则中，是奖励函数形状所诱导的结果。

### 3.3.2 动态动作掩码机制

#### 3.3.2.1 机制定义

动态动作掩码（Dynamic Action Masking，DAM）在动作空间上定义一个二值向量 m ∈ \{0, 1\}^\{\|A\|\}，用以标识在当前时刻哪些动作被"允许"、哪些被"限制"。本章定义三种掩码模式，与第四章的三种元策略一一对应：
- **freq\_only（频域）**：固定当前的发射时延索引不变，仅允许切换中心频点，即允许 3 个动作；
- **time\_only（时域）**：固定当前的中心频点索引不变，仅允许切换发射时延，即允许 3 个动作；
- **joint（联合）**：全部 9 个动作均被允许。

此处需着重说明"动态"二字的含义：掩码并非在动作空间上固定划分出的三个子集，而是相对于当前所处参数状态动态生成的。以当前动作索引 a = 4（即 f\_c 索引为 1、t\_d 索引为 1，对应 76.75 GHz 与 0.8 μs）为例：freq\_only 模式下 t\_d 索引固定为 1，允许的动作集合为 \{1, 4, 7\}；time\_only 模式下 f\_c 索引固定为 1，允许的动作集合为 \{3, 4, 5\}。若下一帧智能体转移至 a = 7，则 freq\_only 模式下允许的集合仍为 \{1, 4, 7\}，而 time\_only 模式下允许的集合变为 \{6, 7, 8\}。因此，同一种模式在不同参数状态下所对应的允许集合不同，掩码需在每一帧依当前状态重新计算。

单维度模式虽然只允许 3 个动作，但网络的输出层维度仍保持为 9，未被允许的动作在动作选择环节被处理，而非通过改变网络结构来实现。这一实现方式保证了三种模式共享同一套网络参数与同一份经验回放缓冲区，掩码模式因而可以在推理过程中随时切换而无需重新加载模型。第四章元策略层得以逐周期下发不同的策略标签，正以此为前提。

#### 3.3.2.2 训练阶段的作用：探索空间裁剪

在训练阶段，DAM 用于构造 3.4.1 节所定义的单维度对照智能体。其对样本效率的提升可以定量估计：依据式(3-4)，ε-贪心探索以概率 ε 在允许集合上均匀随机选择动作，故在联合模式下随机探索命中某个特定动作的概率为 1/9，而在单维度模式下为 1/3。因此在同等探索预算下，单维度智能体对其 3 维子空间的覆盖速度约为联合智能体覆盖 9 维空间速度的 3 倍。这解释了 3.4.2 节中所观察到的现象：两个单维度智能体的收敛速度明显快于联合智能体，但由于其可达的参数配置受限，最终性能低于联合智能体。

#### 3.3.2.3 推理阶段的作用：层间调控接口

在推理阶段，DAM 作为元策略层向执行层下发指令的标准化通道。元策略层输出策略标签 ℓ 与置信度 p，DAM 将其转换为长度为 9 的 Q 值偏置向量并叠加至网络输出，即第二章式(2-54)。偏置的具体形式有两种可选方案，其对比列于表 3-2。

## 3.4 仿真实验

本节通过仿真实验验证本章所提出的深度强化学习执行层的有效性。

### 3.4.1 实验设置

**场景配置。** 本章实验采用第二章 2.4.1 节所定义的场景 A（稀疏干扰），即干扰源数量服从截断至 1 ～ 20 的泊松分布（λ = 2），其余目标与干扰参数依表 2-4 随机初始化。选用稀疏场景的原因如 2.4.1 节所述：本章要考察的是不同动作空间所带来的搜索能力差异，稀疏场景下大多数时刻都存在若干"干净"的参数配置，因而能够清晰地区分单维度策略与联合策略的能力边界。

**对比方案。** 本章设置四个对比方案，其区别仅在于可用的动作空间，其余的网络结构、奖励函数、训练机制与超参数完全一致，如表 3-3 所示。

### 3.4.2 训练收敛与性能对比

**训练收敛过程。** 三个具备学习能力的方案在 15000 幕训练过程中的 SINR 收敛曲线如图 3-6 所示（50 幕滑动平均）。三者呈现出显著不同的收敛特征。

freq\_only 收敛最快，约 2000 幕即达到稳态。这与 3.3.2.2 节的分析一致：其动作空间仅为 3 维，ε-贪心探索对子空间的覆盖速度约为联合方案的 3 倍，探索负担最轻。然而其最终 SINR 约为 8.2 dB，标准差较大（约 3.2 dB），说明其性能在不同干扰分布下的一致性较差。具体原因是在频域密集型的干扰场景中，若多个干扰源同时占据不同频点，仅切换频率无法完全规避，而此时 freq\_only 因时延被固定而无从改善。

time\_only 收敛速度居中，约 3000 幕达到稳态，最终 SINR 约 7.8 dB，标准差约 4.6 dB，为三者中最大。其标准差更大的原因有两点：其一，时域策略的效果依赖于干扰到达延迟与雷达发射时延之间的相对关系，而依据式(2-55)、(2-56)，目标的移动会改变回波延迟、干扰源的移动会改变干扰到达延迟，时延维度上的场景变化比频域更为频繁；其二，本文场景中干扰到达延迟在 U(0, 3τ\_max) 上连续分布，而可选时延只有三个离散值，时域上"完全避开"的余量本身较小。

joint 收敛最慢，但最终性能最优。前 3000 幕其 SINR 低于两个单维度方案，这是在 9 维动作空间中探索所必须付出的代价；约 4000 幕之后其性能超越两个单维度方案，最终 SINR 约 9.5 dB，标准差仅约 0.57 dB。

结论二，联合策略在当前测试中的主要数值优势是波动更小。joint 的标准差为 0.57 dB，分别约为 freq\_only（3.20 dB）、time\_only（4.62 dB）与 Baseline（9.85 dB）的 1/5.6、1/8.1 与 1/17.3。由于正文尚未给出重复随机种子、置信区间或显著性检验，不能使用“显著优于”这一统计术语；这里仅陈述本次样本统计量。标准差较小提示策略对测试场景变化更稳定，但是否能外推到行车安全性能仍需更接近真实分布的实验。

结论三，频域维度的干扰多样性略高于时延维度。freq\_only 的平均 SINR 比 time\_only 高 0.46 dB，且标准差更小。这一差异虽不大，但与前述关于 time\_only 标准差的分析相互印证：在本文的仿真参数下，干扰在频域上的分布相对更为离散（三个频点各占 500 MHz 带宽，干扰中心频率的随机分布使其较难同时覆盖多个频点），而在时延维度上，干扰到达延迟在 U(0, 2.4 μs) 上连续分布、且三个可选时延仅覆盖 \{0, 0.8, 1.6\} μs，时域上的可回避余量相对更小。因此频域自适应所带来的收益略大于时域自适应。该结论与仿真参数相关：若改变频点间隔、时延档位或干扰的分布范围，两个维度的相对优劣可能反转，故不宜将其推广为一般性判断。

### 3.4.3 时序建模组件的消融实验

3.2.3.3 节指出，stateful 模式的 GRU 是执行层获得环境感知能力的关键组件。本节通过消融实验定量验证这一判断。

**实验设置。** 以性能最优的 joint 方案为基准，将其网络中的 GRU 层替换为参数量相当的全连接层，其余结构、奖励函数、训练机制与超参数保持不变，重新训练 15000 幕后按 3.4.1 节的方式评估。替换之后网络不再具备跨帧的记忆能力，每帧的动作选择只能依据当帧的观测（上一动作的独热编码与当前 SINR）作出，因而退化为对瞬时 SINR 的反应式决策。

## 3.5 本章小结

本章实现并优化了分层抗干扰决策框架中的深度强化学习执行层，主要工作与结论如下。

其一，论证了强化学习算法的选型并实现了 Double DQN 执行层。本文场景难以获得显式状态转移概率，动作空间离散且规模有限，因此采用基于价值函数的时序差分方法。Q-Learning / DQN 属于异策略（off-policy）方法；“异策略”描述行为策略与目标策略不同，不等同于使用固定历史数据集训练的离线强化学习。经验回放提高样本复用率，Double Q-Learning 通过分离动作选择与动作评估抑制 max 自举造成的价值过估计。

其二，以 stateful 模式的 GRU 实现了对干扰环境的时序感知。采用"单帧观测输入 \+ 隐状态承载记忆"的三通道网络结构，以 32 维 GRU 隐状态跨帧持续传递，使智能体能够从 SINR 的时间序列中推断干扰的分布结构，而非仅对瞬时 SINR 作反应式决策。消融实验表明，该组件对性能的贡献约为 2.3 dB，其重要性超过动作空间自 3 维扩展至 9 维所带来的收益，从而印证了部分可观测性是本问题的主要困难来源。

其三，设计了自适应分段激励的奖励函数。SINR 不低于阈值时采用双曲饱和型奖励以鼓励达标而不鼓励过度优化，低于阈值时采用有界的线性惩罚以驱动智能体尽快逃离干扰区域；并证明了在本章参数下奖励函数在分段点处近似一阶连续，有利于价值函数的拟合。进一步给出了动作切换代价的定量解读：一次单维度切换所折算的 SINR 当量随当前 SINR 的升高而自 0.55 dB 增至 2.2 dB，智能体因而自发呈现"低 SINR 时积极搜索、高 SINR 时稳定保持"的行为模式，该模式并非被显式编码的规则，而是奖励函数形状所诱导的结果。

其四，动态动作掩码在训练阶段将单维度方案的候选动作从 9 个减少为 3 个，在推理阶段作为元策略标签到动作偏置的统一接口。候选数减少并不自动等于覆盖速度提升 3 倍；探索效率需由相同样本预算的学习曲线证明。接口可降低模块耦合，但并非数据与时序上的完全解耦。硬掩码与软引导共用叠加位置，具体数值和边界行为仍应由代码与测试确认。

其五，在场景 A 的 100 幕测试样本中，joint 方案得到 9.50 ± 0.57 dB 的平均 SINR 与 91% 的避开率；freq\_only、time\_only 与固定参数基线分别为 8.24 ± 3.20 dB、7.78 ± 4.62 dB 和 2.59 ± 9.85 dB。上述结果支持联合动作空间在该样本集上的均值与稳定性优势，但当前材料未给出多随机种子重复实验、置信区间或显著性检验，因此不使用“显著优于”的统计表述。若 GRU 训练代码未采用连续序列回放与隐状态对齐，这组结果还不能归因于可靠的时序建模。

本章结果是第四章 Pure DRL 的对照基线，不是整个分层框架的理论性能下界：元策略偏置若发生误导，同样可能使分层方案低于该基线。现有实验显示，纯执行层仅依赖当前配置下的标量 SINR，在部分密集或突变仿真场景中出现较多切换与试探；第四章据此引入元策略控制器，并通过对照实验检验其在当前 oracle 辅助设置下能否带来增量。
