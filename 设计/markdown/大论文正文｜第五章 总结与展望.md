# 第五章 总结与展望

## 5.1 总结

汽车雷达相互干扰会降低目标探测可靠性。本文聚焦调频斜率与脉冲重复周期相同或接近时的高相干干扰：此类干扰可能在处理域中与真实回波高度相似，使仅依赖样式差异的接收端分离方法面临困难。但接收端重建、联合估计、多通道处理等方法并非原理上全部失效；发射参数调整是本文选取的一条技术路径，而不是唯一可能方案。

本文研究 FMCW 雷达高相干干扰环境下的时、频域联合参数调整方法，建立信号级仿真平台，将决策过程建模为部分可观测马尔可夫决策过程，并构造监督学习元控制器与深度强化学习执行器组成的两层混合框架。本文仅在受控仿真中评估该框架；实验仍受 oracle 信息、GRU 回放实现、消融完备性与多随机种子统计不足等限制，不能视为实车有效性或工程实时性的证明。

**（1）面向相干干扰的分层抗干扰决策架构与时间尺度分离机制**

本文建立 FMCW 雷达与干扰的仿真模型，并以一帧为决策单位。帧内保持 f\_c 与 t\_d 不变有助于保留帧内慢时间相干性，但不能据此推出跨帧处理、目标检测性能或工程波形连续性完全不受影响。战术与战略两个更新周期的差异为设置执行层与元策略层提供了设计动机；由于上层是监督学习分类器、下层才是强化学习执行器，本文更准确的定位是“受 HRL 时间抽象思想启发的混合分层框架”，而非经典端到端分层强化学习。双线程与配置缓冲区可避免上层计算阻塞发射线程，但当前端到端约 99.6 ms 高于 23.0 ms 元决策周期，仍会造成策略陈旧，需经增量更新和硬件验证。

**（2）基于 Double DQN 与 GRU 的抗干扰策略执行层及其训练效率机制**

执行层的算法选择基于四项工程条件：转移模型未知、训练采用有限幕截断、希望借助经验回放复用样本、动作空间离散且规模较小。本文据此采用基于价值函数的异策略时序差分方法。这里的 Off-Policy 统一译为“异策略”，不使用会与 Offline RL 混淆的“离线策略”；同策略或蒙特卡洛方法并非原理上不可用。Double Q-Learning 用于减轻 max 操作与估计噪声共同造成的价值过估计。网络采用单帧观测配合 GRU 隐状态承载历史信息，但其与经验回放结合时必须使用连续序列并正确处理隐状态；该实现细节仍需代码证据确认。

在场景 A 的 100 幕测试样本中，时、频域联合策略取得 9.50 ± 0.57 dB 的平均 SINR 与 91% 的避开率；仅频域与仅时域方案分别为 8.24 ± 3.20 dB 与 7.78 ± 4.62 dB。该结果显示联合方案在当前样本集上的均值更高、波动更小，但未提供多随机种子重复实验、置信区间或显著性检验。时序建模贡献约 2.3 dB 的消融解释，还需先确认 GRU 使用连续序列回放并正确处理隐状态；否则不能把差值归因于可靠的时序记忆。

**（3）基于场景语义特征与随机森林的元策略控制器及软引导协同机制**

本文将执行层的信息缺口表述为：每帧只观测当前配置的一个标量 SINR，而完整比较 9 个配置至少需要 9 次观测。69.1 ms 只是顺序扫描的时间下界，是否足以落后于环境变化需由动态模型或实测数据验证。元策略使用逐配置 EMA 构造维度敏感性特征并把搜索组织为“先选维度、再在维内选择”；这些逐配置值在当前仿真中带有 oracle 信息，尚不是可直接部署的在线观测。软引导不删除候选动作，但其正偏置仍可能改变动作排序，因此不存在由公式自动给出的 Pure DRL 性能下界。策略持久化的约 40% 降频结论也需补做对照实验。

在当前 oracle 辅助仿真设置下，Meta-RF 在场景 B 的平均 SINR 样本值比 Pure DRL 高约 5.1 dB、避开率高 4.5 个百分点；在训练未覆盖的两个干扰数量档位上高 2.4～3.8 dB；Exp-D 的恢复帧数约为 5 帧对 8 帧。这些结果只支持同一仿真生成器与给定信息条件下的描述性比较，不能证明统计显著性、通用分布外泛化、独立元策略净增量或实车有效性。随机森林投票比例尚未校准，MDI 特征重要性也只能说明模型在当前 oracle 生成数据上的依赖，不能把“与人工规则一致”当作独立可解释性证明。

贯穿三项工作的更稳妥结论是：在当前受控仿真中，混合分层方案在若干均值、T80 与动态恢复指标上取得较好样本结果，但尚不能确定增益来自元策略、oracle 初始化、软引导或其他机制，也不能证明其只改善适应速度而不改变稳态性能。关于“突变场景更能体现元策略价值”的说法应视为待检验假设；本文结果也不直接外推到其他认知无线电、认知雷达或实车场景。

## 5.2 未来工作展望

本文提出并验证了面向相干干扰的两层分层抗干扰决策方法，但受研究条件与篇幅所限，仍有若干不足有待后续解决。

**（1）维度敏感性估计对 oracle 的依赖。** 本文第四章的维度敏感性特征（fc\_gap、td\_gap 与 fc\_td\_ratio）在训练阶段以仿真环境中穷举计算所得的无噪声 SINR 表替代在线估计以消除标签噪声，在测试阶段亦以该表在 warmup 结束时种子化指数移动平均状态。该表在仿真中容易得到，在实际车载系统中却无从获得，因而构成本文方法最主要的假设性前提。后续可从两条路径替代：其一，以 warmup 阶段对 9 个参数配置的实测扫描结果替代 oracle 表，此时需评估扫描期间探测性能受损的代价以及测量噪声对分类精度的影响；其二，借助独立的干扰参数估计模块推算各配置下的预期 SINR，此路径的可行性取决于干扰中心频率、到达延迟与幅度估计的精度，而相干干扰参数的精准估计本身即是一个尚未充分解决的问题。本文还假设接收信号的 SINR 可以被准确估计，该假设如何放宽亦有待研究。

**（2）时间粒度与工程实时性。** 本文以帧（7.68 ms）为决策单位，这一选择保证了帧内相干积累的完整性，代价是对突发干扰的最快响应延迟为一帧。如何在“帧内参数不变以保障多普勒处理”与“更快响应突发干扰”之间取得更好的折中，例如采用自适应帧长，或在帧内以子帧粒度作粗判而仅在帧边界执行参数切换，是值得研究的方向。实时性方面，当前实现下元策略层特征提取与推理的端到端耗时约 99.6 ms，而元策略层的决策周期为 23.0 ms，单次推理无法在一个决策周期内完成。瓶颈在于每个决策周期都对整个窗口重新计算全部统计量，而这些统计量原则上均可增量式滑动更新，故属实现层面的工程问题。后续需完成增量式滑窗改造、定点化运算以及在 C 或 FPGA 平台上的重实现，并在硬件在环条件下验证其实时性。

**（3）元策略层的端到端学习。** 如 2.3.1 节所述，本文的高层并非通过强化学习自动习得的选项，而是以监督学习方式训练的模式识别器，这一取舍出于实时性与可解释性的工程考虑。其代价是元策略的标签依赖式(4-26)所给出的人工标注准则，该准则中“联合探索相对单维度策略的优势超过 0.3 dB”这一阈值由人为设定，最优性未经论证。后续可尝试以强化学习方式端到端地训练高层策略，例如采用 option-critic 框架同时学习选项的内部策略与终止条件，或以半马尔可夫决策过程上的 Q 学习直接优化元策略的选择，从而摆脱对人工标注准则的依赖，并有可能发现人工设计之外的策略划分方式。其中的关键问题是如何在保持亚毫秒级推理耗时与决策可解释性的前提下引入学习型高层。

（4）干扰类型与可调维度的扩展。本文聚焦高相干干扰，而实际道路中还存在不同带宽、斜率与扫频时长组合造成的非相干或部分相干干扰。后续可把调频斜率、带宽等纳入动作空间，研究其对频谱重叠、拍频占用和检测性能的影响；调整斜率可能改变干扰在接收带宽内的形态，但不能预先假定其会把非相干干扰“转化为可处理的相干干扰”。动作空间从离散档位扩展到连续参数时，还需重新设计安全约束、探索机制与评价指标。

（5）多智能体场景下的协同抗干扰。现实中多部雷达同时自适应会形成非平稳博弈，可能出现配置追逐或振荡。后续可研究集中式训练、分布式执行等多智能体方法，并比较无通信、有限通信与协同调度三种信息条件。CTDE 不保证在仅有局部观测时自动达到稳定均衡；需要显式报告收敛性、频谱公平性、碰撞率和最坏车辆性能，并考虑通信时延与安全约束。

**（6）实验完备性与从仿真到实测的验证。** 本文的消融实验尚不完备：第三章仅对时序建模组件完成了消融，分段奖励、动作代价项、目标网络更新方式与损失函数形式四项的独立贡献未经实验分离；第四章仅完成了移除整个元策略层的消融，软引导相对硬掩码的实际收益、策略持久化在信干噪比层面的贡献以及窗口参数 W 与 K 的敏感性均有待补充。更为关键的是，本文所提出的方法均仅经过仿真验证，而现实世界的电磁环境与道路状况远比仿真场景复杂：多径反射、杂波、反射式干扰、非理想低通滤波与射频前端的非线性等因素本文均未予建模，方法的鲁棒性与泛化性有待实测检验。后续应搭建基于商用汽车雷达芯片的实验平台，先以硬件在环方式复现关键实验，再逐步过渡到实车道路测试。这既是本文方法走向实用的必经环节，也是雷达抗干扰方法落地时共同面对的难题。
